1선형회귀와 같은 원리

다중회귀와 MLP는 목표가 같습니다. 둘 다 예측값과 실제값의 차이를 제곱해 평균한 MSE를 가장 작게 만드는 파라미터를 찾습니다.

\[\mathcal L(\theta)=\frac1n\sum_{i=1}^{n}\bigl(\hat y_i(\theta)-y_i\bigr)^2\;\longrightarrow\;\min_\theta\]

모형ŷ = b₀ + b₁x₁ + b₂x₂ (평면)ReLU로 꺾인 조각별 선형 곡면

은닉층 없이 입력 2개 → 출력 1개인 "신경망"은 곧 선형회귀입니다. 이것을 아래와 같은 경사하강법(학습률 0.05, 2000회)으로 학습하면, 표준화 단위의 가중치는 \(w_1=0.4648,\;w_2=0.6902,\;b=0\)로 수렴합니다. 원래 단위로 되돌리면

\[b_j=w_j\cdot\frac{\sigma_y}{\sigma_{x_j}},\qquad b_0=\bar y+b\,\sigma_y-b_1\bar x_1-b_2\bar x_2\]
\[b_0=16.1325,\quad b_1=1.4306,\quad b_2=2.4422\]

정규방정식으로 구한 \(16.1325,\;1.4306,\;2.4422\)와 같습니다. 경사하강법은 정규방정식과 같은 답을 반복으로 찾아가는 방법이고, 은닉층과 ReLU를 넣으면 닫힌 해를 쓸 수 없으니 반복만 남는다는 것이 이 노트의 출발점입니다.

2네트워크 구조

행 벡터 표기로 층별 계산은 다음과 같습니다.

\[\begin{aligned} \mathbf z^{(1)}&=\tilde{\mathbf x}\,W^{(1)}+\mathbf b^{(1)}, & \mathbf a^{(1)}&=\operatorname{ReLU}(\mathbf z^{(1)})\\ \mathbf z^{(2)}&=\mathbf a^{(1)}W^{(2)}+\mathbf b^{(2)}, & \mathbf a^{(2)}&=\operatorname{ReLU}(\mathbf z^{(2)})\\ \hat o&=\mathbf a^{(2)}W^{(3)}+b^{(3)} \end{aligned} \qquad \operatorname{ReLU}(z)=\max(0,z),\quad \operatorname{ReLU}'(z)=\begin{cases}1&z>0\\0&z\le 0\end{cases}\]

파라미터 수는 \((2\times3+3)+(3\times2+2)+(2\times1+1)=9+8+3=20\)개입니다. 학습 데이터가 10개뿐이라 파라미터가 데이터보다 많고, 이 점이 12장의 결과에 영향을 줍니다.

4가중치 초기화

가중치는 정규분포 난수(seed 13, ReLU에 맞춘 He 초기화 계열 분산)로 뽑고 손계산하기 쉽게 소수 둘째 자리로 반올림했습니다. 편향은 모두 0에서 시작합니다.

\[W^{(1)}=\begin{bmatrix}1.83&-3.08&0.96\\0.07&1.32&0.39\end{bmatrix},\quad W^{(2)}=\begin{bmatrix}1.49&0.03\\-0.42&0.47\\0.35&-0.29\end{bmatrix},\quad W^{(3)}=\begin{bmatrix}-0.25\\0.72\end{bmatrix}\]
\[\mathbf b^{(1)}=\begin{bmatrix}0.00&0.00&0.00\end{bmatrix},\quad \mathbf b^{(2)}=\begin{bmatrix}0.00&0.00\end{bmatrix},\quad b^{(3)}=\begin{bmatrix}0.00\end{bmatrix}\]

초기값이 중요한 이유 — 선형회귀는 해가 하나라 어디서 시작해도 같은 답에 도달하지만, MLP는 손실 곡면이 울퉁불퉁해 초기값마다 결과가 다릅니다. 같은 구조로 seed 0~19를 시험했을 때 3개(seed 0, 8, 17)는 모든 뉴런이 학습 데이터 전체에서 0만 출력하는 "죽은 ReLU" 상태에 빠져 손실이 1.0(평균만 예측하는 수준)에서 멈췄습니다.

5순전파 — 학생 1 한 명

학생 1(출석 18일, 공부 6시간, 점수 55)을 초기 가중치로 통과시킵니다. 표준화된 입력은 \(\tilde{\mathbf x}=(-1.8029,\;-0.8553)\)입니다.

은닉층 1

\[\begin{aligned}z^{(1)}_1&=(-1.8029)(1.83)+(-0.8553)(0.07)+0=-3.3593&\Rightarrow\;a^{(1)}_1&=\max(0,-3.3593)=0.0000\\z^{(1)}_2&=(-1.8029)(-3.08)+(-0.8553)(1.32)+0=4.4240&\Rightarrow\;a^{(1)}_2&=\max(0,4.4240)=4.4240\\z^{(1)}_3&=(-1.8029)(0.96)+(-0.8553)(0.39)+0=-2.0644&\Rightarrow\;a^{(1)}_3&=\max(0,-2.0644)=0.0000\end{aligned}\]

은닉층 2

\[\begin{aligned}z^{(2)}_1&=(0.0000)(1.49)+(4.4240)(-0.42)+(0.0000)(0.35)+0=-1.8581&\Rightarrow\;a^{(2)}_1&=\max(0,-1.8581)=0.0000\\z^{(2)}_2&=(0.0000)(0.03)+(4.4240)(0.47)+(0.0000)(-0.29)+0=2.0793&\Rightarrow\;a^{(2)}_2&=\max(0,2.0793)=2.0793\end{aligned}\]

음수가 된 \(z\)는 ReLU를 지나며 0이 됩니다. 0이 된 뉴런은 이 학생에 대해서는 신호를 전달하지 않고, 역전파 때도 기울기가 0이 되어 해당 경로의 가중치는 이 학생 때문에 바뀌지 않습니다.

출력층

\[\hat o_1=(0.0000)(-0.25)+(2.0793)(0.72)+0=1.4971\]

표준화 단위의 예측 \(1.4971\)을 점수로 바꾸면 \(1.4971\times10.7559+71.9=88.00\)점입니다. 실제 55점과 거리가 멀지만, 아직 학습 전이므로 당연합니다.

7역전파 — 연쇄법칙

역전파는 손실을 각 가중치로 미분한 값을 출력층부터 거꾸로 계산하는 과정입니다. 각 층에서 "뒤에서 넘어온 기울기 δ"만 알면 그 층의 가중치 기울기가 나옵니다.

\[\begin{aligned} \frac{\partial\mathcal L}{\partial\hat o_i}&=\frac{2}{n}(\hat o_i-\tilde y_i) &&\text{(출력 기울기)}\\ \frac{\partial\mathcal L}{\partial W^{(3)}}&=\mathbf a^{(2)\top}\frac{\partial\mathcal L}{\partial\hat o}, & \boldsymbol\delta^{(2)}&=\Bigl(\frac{\partial\mathcal L}{\partial\hat o}W^{(3)\top}\Bigr)\odot\operatorname{ReLU}'(\mathbf z^{(2)})\\ \frac{\partial\mathcal L}{\partial W^{(2)}}&=\mathbf a^{(1)\top}\boldsymbol\delta^{(2)}, & \boldsymbol\delta^{(1)}&=\bigl(\boldsymbol\delta^{(2)}W^{(2)\top}\bigr)\odot\operatorname{ReLU}'(\mathbf z^{(1)})\\ \frac{\partial\mathcal L}{\partial W^{(1)}}&=\tilde{\mathbf x}^{\top}\boldsymbol\delta^{(1)}, & \frac{\partial\mathcal L}{\partial\mathbf b^{(l)}}&=\textstyle\sum_i\boldsymbol\delta^{(l)}_i \end{aligned}\]

선형회귀의 정규방정식도 사실 \(\partial\mathcal L/\partial b_j=0\)이라는 같은 미분에서 나왔습니다. 차이는 ReLU 미분이 끼어들어 식을 0으로 놓고 풀 수 없다는 점뿐입니다.

학생 1의 기여분

\[\frac{\partial\mathcal L}{\partial\hat o_1}=\frac{2}{10}\times(3.0683)=0.6137\]

출력층 가중치 기울기는 은닉층 2 출력에 이 값을 곱합니다.

\[\mathbf a^{(2)}_1=\begin{bmatrix}0.0000&2.0793\end{bmatrix}\;\Rightarrow\;\frac{\partial\mathcal L_1}{\partial W^{(3)}}=\mathbf a^{(2)\top}_1\times0.6137=\begin{bmatrix}0.0000\\1.2760\end{bmatrix}\]

은닉층 2로 기울기를 보낸 뒤, ReLU 미분(켜진 뉴런은 1, 꺼진 뉴런은 0)으로 거릅니다.

\[0.6137\cdot W^{(3)\top}=\begin{bmatrix}-0.1534&0.4418\end{bmatrix},\qquad \operatorname{ReLU}'(\mathbf z^{(2)}_1)=\begin{bmatrix}0&1\end{bmatrix}\;\Rightarrow\;\boldsymbol\delta^{(2)}_1=\begin{bmatrix}-0.0000&0.4418\end{bmatrix}\]
\[\mathbf a^{(1)}_1=\begin{bmatrix}0.0000&4.4240&0.0000\end{bmatrix}\;\Rightarrow\;\frac{\partial\mathcal L_1}{\partial W^{(2)}}=\mathbf a^{(1)\top}_1\boldsymbol\delta^{(2)}_1=\begin{bmatrix}0.0000&0.0000\\0.0000&1.9547\\0.0000&0.0000\end{bmatrix}\]

같은 방법으로 은닉층 1까지 내려갑니다.

\[\boldsymbol\delta^{(2)}_1W^{(2)\top}=\begin{bmatrix}0.0133&0.2077&-0.1281\end{bmatrix},\qquad \operatorname{ReLU}'(\mathbf z^{(1)}_1)=\begin{bmatrix}0&1&0\end{bmatrix}\;\Rightarrow\;\boldsymbol\delta^{(1)}_1=\begin{bmatrix}0.0000&0.2077&-0.0000\end{bmatrix}\]
\[\frac{\partial\mathcal L_1}{\partial W^{(1)}}=\tilde{\mathbf x}^{\top}_1\boldsymbol\delta^{(1)}_1=\begin{bmatrix}0.0000&-0.3744&0.0000\\0.0000&-0.1776&0.0000\end{bmatrix}\]

13Python 검증

numpy만으로 순전파·역전파를 직접 구현한 코드입니다. 그대로 실행하면 이 노트의 수치가 재현됩니다.

import numpy as np

# 학습 데이터 10개: [출석일수, 공부시간], 점수
X = np.array([[18, 6], [20, 10], [22, 4], [23, 8], [24, 12],
              [25, 5], [26, 9], [27, 14], [28, 7], [30, 11]], dtype=float)
y = np.array([55, 72, 60, 65, 82, 61, 77, 85, 74, 88], dtype=float)
X_test = np.array([[21, 7], [25, 10], [29, 13]], dtype=float)
y_test = np.array([66, 73, 92], dtype=float)

# 1) 표준화 (학습 데이터의 평균·표준편차만 사용)
mu, sd = X.mean(0), X.std(0)
ym, ys = y.mean(), y.std()
Z, yz = (X - mu) / sd, (y - ym) / ys

# 2) 가중치 초기화: 2-3-2-1 구조, 소수 둘째 자리로 반올림해 손계산하기 쉽게
rng = np.random.default_rng(13)
W1 = np.round(rng.normal(0, 1, (2, 3)), 2); b1 = np.zeros(3)
W2 = np.round(rng.normal(0, np.sqrt(2 / 3), (3, 2)), 2); b2 = np.zeros(2)
W3 = np.round(rng.normal(0, 1, (2, 1)), 2); b3 = np.zeros(1)

def forward(A):
    z1 = A @ W1 + b1; a1 = np.maximum(z1, 0)      # 은닉층 1 (ReLU)
    z2 = a1 @ W2 + b2; a2 = np.maximum(z2, 0)     # 은닉층 2 (ReLU)
    out = (a2 @ W3 + b3).ravel()                   # 출력층 (항등)
    return z1, a1, z2, a2, out

# 3) 전체 배치 경사하강법
lr, epochs, n = 0.05, 2000, len(y)
for epoch in range(epochs):
    z1, a1, z2, a2, out = forward(Z)
    loss = np.mean((out - yz) ** 2)
    if epoch in (0, 1, 10, 100, 500, 1000, epochs - 1):
        print(f"epoch {epoch:4d}  loss {loss:.4f}")
    g = (2 / n * (out - yz))[:, None]              # dL/d(out)
    gW3 = a2.T @ g;  gb3 = g.sum(0)
    d2 = (g @ W3.T) * (z2 > 0)                     # ReLU 미분 = 1(z>0)
    gW2 = a1.T @ d2; gb2 = d2.sum(0)
    d1 = (d2 @ W2.T) * (z1 > 0)
    gW1 = Z.T @ d1;  gb1 = d1.sum(0)
    W3 -= lr * gW3; b3 -= lr * gb3
    W2 -= lr * gW2; b2 -= lr * gb2
    W1 -= lr * gW1; b1 -= lr * gb1

# 4) 원래 점수 단위로 되돌려 평가
def predict(A):
    return forward((A - mu) / sd)[4] * ys + ym

yhat_tr = predict(X)
print("학습 R^2   :", round(1 - np.sum((y - yhat_tr) ** 2) / np.sum((y - ym) ** 2), 4))
y_pred = predict(X_test)
err = y_test - y_pred
print("테스트 예측:", np.round(y_pred, 4))
print("오차       :", np.round(err, 4))
print("MAE  :", round(np.mean(np.abs(err)), 4))
print("MSE  :", round(np.mean(err ** 2), 4))
print("RMSE :", round(np.sqrt(np.mean(err ** 2)), 4))
print("MAPE :", round(np.mean(np.abs(err) / y_test) * 100, 4), "%")
print("테스트 R^2 :", round(1 - np.sum(err ** 2) / np.sum((y_test - y_test.mean()) ** 2), 4))
