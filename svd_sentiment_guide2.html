SVD 완전학습서 2 — 손으로 끝까지 풀어보기

1편의 12×5 행렬은 5차방정식이 나와 손으로 풀 수 없었습니다. 이번에는 항목을 맛 · 서비스 · 가격 3개로 줄여, 고유값이 정수(48, 30, 6)로 딱 떨어지도록 데이터를 설계했습니다. 그래서 특성방정식부터 U, Σ, V, 재조립까지 모든 단계를 계산기 없이 따라갈 수 있습니다. 모든 수치는 NumPy로 다시 검증했습니다.

행렬 12 × 3λ = 48 · 30 · 6σ = 4√3 · √30 · √6k=2 설명력 92.9%

01SVD를 한 문장으로

SVD는 "점수표를, 서로 겹치지 않는 몇 개의 '성향'으로 나누어 다시 쓰는 방법"입니다.

비유: 음악 이퀄라이저
여러 악기가 섞인 소리를 저음·중음·고음으로 나누면, 어느 대역이 큰지 한눈에 보입니다. SVD도 리뷰 점수를 "전반적으로 좋다/싫다", "서비스와 가격 중 무엇을 중시하나", "그 밖의 잔잔한 차이"라는 대역으로 나누고, 각 대역의 크기(특이값)를 알려줍니다.
이번 학습서의 결론 미리보기
① 전반 감성 — 세 점수의 합 (설명력 57.1%)
② 서비스 − 가격 — 무엇을 더 좋게 봤나 (35.7%)
③ 맛 − 나머지 — 작은 잔차 (7.1%)
①+②만으로 전체의 92.9%를 설명합니다.

03SVD의 모양과 그림

$$\underbrace{A}_{12\times3}=\underbrace{U}_{12\times3}\;\underbrace{\Sigma}_{3\times3}\;\underbrace{V^{\mathsf T}}_{3\times3}=\sigma_1\mathbf u_1\mathbf v_1^{\mathsf T}+\sigma_2\mathbf u_2\mathbf v_2^{\mathsf T}+\sigma_3\mathbf u_3\mathbf v_3^{\mathsf T}$$
기호크기쉬운 말로이 데이터에서는
V3×3항목을 섞는 "레시피" (각 성향이 어떤 항목으로 만들어지나)(1,1,1), (0,1,−1), (2,−1,−1)을 길이 1로
Σ3×3 대각성향마다 "얼마나 큰가" (볼륨)4√3, √30, √6
U12×3사람마다 각 성향을 "얼마나 가졌나"8장에서 12명 모두 계산

그림으로 보는 SVD: 돌리고 → 늘리고 → 돌리기

핵심 공식 하나만 기억
$$A\mathbf v_i=\sigma_i\mathbf u_i$$ "항목 레시피 $\mathbf v_i$를 점수표에 넣으면, 사람별 점수 $\mathbf u_i$가 $\sigma_i$배 크기로 나온다." 이 식 하나로 8장의 U를 전부 구합니다.

04Step 1 · $A^{\mathsf T}A$ 만들기

$A^{\mathsf T}A$는 "항목끼리 얼마나 같이 움직이나"를 담은 3×3 표입니다. $(j,k)$ 칸 = j열과 k열을 위아래로 곱해서 모두 더한 값.

대각선 — 같은 열끼리 (제곱합)

$$\begin{aligned} \text{맛·맛}&=2^2+1^2+2^2+0^2+0^2+1^2+0^2+(-1)^2+1^2+0^2+(-2)^2+(-2)^2=4+1+4+0+0+1+0+1+1+0+4+4=\mathbf{20}\\ \text{서비스·서비스}&=4+1+0+1+4+1+4+4+4+1+4+4=\mathbf{32}\\ \text{가격·가격}&=4+4+4+4+4+1+4+1+0+1+4+1=\mathbf{32} \end{aligned}$$

비대각 — 다른 열끼리 (곱의 합)

$$\begin{aligned} \text{맛·서비스}&=2\cdot2+1\cdot1+2\cdot0+0\cdot1+0\cdot2+1\cdot1+0\cdot(-2)+(-1)(-2)+1\cdot(-2)+0\cdot(-1)+(-2)(-2)+(-2)(-2)\\&=4+1+0+0+0+1+0+2-2+0+4+4=\mathbf{14}\\[3pt] \text{맛·가격}&=4+2+4+0+0-1+0-1+0+0+4+2=\mathbf{14}\\[3pt] \text{서비스·가격}&=4+2+0+2-4-1-4-2+0-1+4+2=\mathbf{2} \end{aligned}$$
$$M=A^{\mathsf T}A=\begin{pmatrix}20&14&14\\14&32&2\\14&2&32\end{pmatrix}\qquad(\text{행·열 순서: 맛, 서비스, 가격})$$
이 표가 이미 말해 주는 것
① 맛은 서비스·가격과 모두 +14 — 맛 점수는 다른 점수와 같이 오르내린다.
② 서비스·가격은 겨우 +2 — 둘은 거의 따로 움직인다 ("좋은데 비싸다", "싸지만 불친절"이 섞여 있어서).
③ 서비스·가격 행이 대칭(32·2·14) — 이 대칭이 곧 고유값을 쉽게 찾는 열쇠가 됩니다.

05Step 2 · 고유값 구하기 — 3차방정식을 손으로

$M\mathbf v=\lambda\mathbf v$를 만족하는 $\lambda$를 찾습니다. $(M-\lambda I)\mathbf v=\mathbf 0$에 0 아닌 해가 있으려면 행렬식이 0이어야 합니다.

$$\det(M-\lambda I)=\det\begin{pmatrix}20-\lambda&14&14\\14&32-\lambda&2\\14&2&32-\lambda\end{pmatrix}=0$$

① 3차 특성방정식의 세 계수 구하기 (지름길)

3×3이면 $\lambda^3-c_2\lambda^2+c_1\lambda-c_0=0$ 꼴이고, 계수는 이렇게 바로 계산됩니다.

계수구하는 법계산값
$c_2$대각합 (trace)20 + 32 + 3284
$c_1$2×2 주소행렬식 3개의 합(20·32−14²) + (20·32−14²) + (32·32−2²) = 444 + 444 + 10201908
$c_0$행렬식 det M20(1024−4) − 14(448−28) + 14(28−448) = 20400 − 5880 − 58808640
$$\boxed{\lambda^3-84\lambda^2+1908\lambda-8640=0}$$

② 근 하나 찾기 — 대칭을 이용

서비스와 가격이 대칭이므로 "서비스 +1, 가격 −1" 방향 $(0,1,-1)$을 넣어 봅니다.

$$M\begin{pmatrix}0\\1\\-1\end{pmatrix}=\begin{pmatrix}0+14-14\\0+32-2\\0+2-32\end{pmatrix}=\begin{pmatrix}0\\30\\-30\end{pmatrix}=30\begin{pmatrix}0\\1\\-1\end{pmatrix}\;\Rightarrow\;\lambda=30$$

검산: $30^3-84\cdot30^2+1908\cdot30-8640=27000-75600+57240-8640=0$ ✓

대칭이 안 보일 때는?
상수항 8640의 약수(1, 2, 3, …, 30, …)를 하나씩 대입하는 유리근 정리를 쓰면 됩니다. 이번 데이터는 30에서 0이 됩니다.

③ 나머지 두 근 — 인수분해 후 근의 공식

$$\lambda^3-84\lambda^2+1908\lambda-8640=(\lambda-30)(\lambda^2-54\lambda+288)$$ $$\lambda=\frac{54\pm\sqrt{54^2-4\cdot288}}{2}=\frac{54\pm\sqrt{2916-1152}}{2}=\frac{54\pm\sqrt{1764}}{2}=\frac{54\pm42}{2}\;\Rightarrow\;\lambda=48,\;6$$

④ 특이값 = 고유값의 제곱근

1번2번3번합
고유값 λ4830684 = 대각합 ✓
특이값 σ = √λ4√3 ≈ 6.928√30 ≈ 5.477√6 ≈ 2.449
검산 두 가지
λ의 합 48+30+6 = 84 = 대각합 = 모든 점수의 제곱합(20+32+32) ✓  ·  λ의 곱 48×30×6 = 8640 = det M ✓

06Step 3 · 고유벡터 구하기 — 연립방정식 3번

각 λ마다 $(M-\lambda I)\mathbf v=\mathbf 0$을 풉니다. 미지수를 $\mathbf v=(x,y,z)$ = (맛, 서비스, 가격)이라 둡니다.

λ = 48 가장 큰 성향
$$M-48I=\begin{pmatrix}-28&14&14\\14&-16&2\\14&2&-16\end{pmatrix}$$
  1. 2행 − 3행: $-18y+18z=0$ → y = z
  2. 1행: $-28x+14y+14z=0$ → $-28x+28y=0$ → x = y
  3. 따라서 $\mathbf v\propto(1,1,1)$, 길이 $\sqrt3$로 나누면 $\mathbf v_1=\frac{1}{\sqrt3}(1,1,1)=(0.577,\,0.577,\,0.577)$

세 항목을 똑같은 비율로 더하는 방향 = "전반적으로 좋은가 싫은가".

λ = 30 두 번째 성향
$$M-30I=\begin{pmatrix}-10&14&14\\14&2&2\\14&2&2\end{pmatrix}$$
  1. $s=y+z$로 두면 1행: $-10x+14s=0$, 2행: $14x+2s=0$
  2. 두 식을 동시에 만족하는 건 x = 0, s = 0뿐 → $z=-y$
  3. $\mathbf v\propto(0,1,-1)$ → $\mathbf v_2=\frac{1}{\sqrt2}(0,1,-1)=(0,\,0.707,\,-0.707)$

맛은 0, 서비스는 +, 가격은 − = "서비스를 더 좋게 봤나, 가격을 더 좋게 봤나".

λ = 6 작은 성향
$$M-6I=\begin{pmatrix}14&14&14\\14&26&2\\14&2&26\end{pmatrix}$$
  1. 1행: $x+y+z=0$
  2. 2행 − 3행: $24y-24z=0$ → y = z, 그러면 $x=-2y$
  3. $\mathbf v\propto(-2,1,1)$, 부호를 바꿔 $\mathbf v_3=\frac{1}{\sqrt6}(2,-1,-1)=(0.816,\,-0.408,\,-0.408)$

맛 vs (서비스+가격) — "맛만 유난히 다르게 평가했나". 크기 6으로 작아서 거의 잡음.

세 벡터는 서로 직각

$$\mathbf v_1\cdot\mathbf v_2\propto 0+1-1=0,\qquad \mathbf v_1\cdot\mathbf v_3\propto2-1-1=0,\qquad \mathbf v_2\cdot\mathbf v_3\propto0-1+1=0$$
$$V=\begin{pmatrix}\tfrac1{\sqrt3}&0&\tfrac2{\sqrt6}\\[2pt]\tfrac1{\sqrt3}&\tfrac1{\sqrt2}&-\tfrac1{\sqrt6}\\[2pt]\tfrac1{\sqrt3}&-\tfrac1{\sqrt2}&-\tfrac1{\sqrt6}\end{pmatrix}\qquad \Sigma=\begin{pmatrix}4\sqrt3&0&0\\0&\sqrt{30}&0\\0&0&\sqrt6\end{pmatrix}$$

07확인 · 거듭제곱법 3단계로 λ = 48 다시 찾기

행렬이 크면 특성방정식을 풀 수 없으니 컴퓨터는 반복 계산을 씁니다. 이번 3×3에서 직접 해 보고 손으로 구한 답과 비교합니다. 일부러 엉뚱한 출발점 $\mathbf x^{(0)}=(1,0,0)$ ("맛만")에서 시작합니다.

매 단계: ① M을 곱한다 → ② 길이를 잰다 → ③ 길이 1로 나눈다 → ④ 고유값을 추정한다 ($\lambda=\mathbf x\cdot M\mathbf x$)

1단계 $(1,0,0)\to\mathbf x^{(1)}$
$$M\begin{pmatrix}1\\0\\0\end{pmatrix}=\begin{pmatrix}20\\14\\14\end{pmatrix}\;(M\text{의 첫 열}),\qquad \sqrt{20^2+14^2+14^2}=\sqrt{792}=28.142$$ $$\mathbf x^{(1)}=\left(\tfrac{20}{28.142},\tfrac{14}{28.142},\tfrac{14}{28.142}\right)=(0.7107,\;0.4975,\;0.4975)$$ $$M\mathbf x^{(1)}=\begin{pmatrix}20(0.7107)+14(0.4975)+14(0.4975)\\14(0.7107)+32(0.4975)+2(0.4975)\\14(0.7107)+2(0.4975)+32(0.4975)\end{pmatrix}=\begin{pmatrix}28.143\\26.863\\26.863\end{pmatrix}$$ $$\lambda^{(1)}=0.7107(28.143)+0.4975(26.863)+0.4975(26.863)=\mathbf{46.727}$$

$\mathbf v_1$과의 각도 54.74° → 10.02°

2단계 $\mathbf x^{(1)}\to\mathbf x^{(2)}$
$$\|(28.143,\,26.863,\,26.863)\|=\sqrt{792.0+721.6+721.6}=\sqrt{2235.3}=47.279$$ $$\mathbf x^{(2)}=(0.5952,\;0.5682,\;0.5682)$$ $$M\mathbf x^{(2)}=\begin{pmatrix}20(0.5952)+28(0.5682)\\14(0.5952)+34(0.5682)\\14(0.5952)+34(0.5682)\end{pmatrix}=\begin{pmatrix}27.814\\27.652\\27.652\end{pmatrix},\qquad \lambda^{(2)}=\mathbf{47.980}$$

각도 1.27° — 벌써 거의 도착

3단계 $\mathbf x^{(2)}\to\mathbf x^{(3)}$
$$\|(27.814,\,27.652,\,27.652)\|=47.988,\qquad \mathbf x^{(3)}=(0.5796,\;0.5762,\;0.5762),\qquad \lambda^{(3)}=\mathbf{47.9997}$$

각도 0.16°. 손으로 구한 $\mathbf v_1=(0.577,0.577,0.577)$, $\lambda_1=48$과 일치 ✓

왜 매번 약 1/8씩 줄어드나
출발점을 고유벡터로 나누면 $(1,0,0)=\tfrac{1}{\sqrt3}\mathbf v_1+0\cdot\mathbf v_2+\tfrac{2}{\sqrt6}\mathbf v_3$. 서비스·가격이 0이라 $\mathbf v_2$ 성분이 처음부터 0입니다. 남은 방해꾼 $\mathbf v_3$는 한 번 곱할 때마다 $\lambda_3/\lambda_1=6/48=\tfrac18$배로 줄어듭니다. 각도의 탄젠트: $\sqrt2\to\sqrt2/8\to\sqrt2/64\to\sqrt2/512$ (= 54.74° → 10.02° → 1.27° → 0.16°).

08Step 4 · U 구하기 — 사람마다 성향 점수

$A\mathbf v_i=\sigma_i\mathbf u_i$이므로, 점수표에 레시피를 곱하면 끝입니다. $\mathbf v$가 단순해서 공식도 단순해집니다.

$$\begin{aligned} \text{요인 1 점수 } \sigma_1u_1&=A\mathbf v_1=\frac{\text{맛}+\text{서비스}+\text{가격}}{\sqrt3}\\ \text{요인 2 점수 } \sigma_2u_2&=A\mathbf v_2=\frac{\text{서비스}-\text{가격}}{\sqrt2}\\ \text{요인 3 점수 } \sigma_3u_3&=A\mathbf v_3=\frac{2\cdot\text{맛}-\text{서비스}-\text{가격}}{\sqrt6} \end{aligned}$$

U 자체는 σ로 한 번 더 나눈 값이라 더 깔끔합니다: $u_1=\frac{\text{행 합}}{12}$ (∵ $\sqrt3\cdot4\sqrt3=12$), $u_3=\frac{2\cdot\text{맛}-\text{서비스}-\text{가격}}{6}$ (∵ $\sqrt6\cdot\sqrt6=6$).

손계산 예 — R05 (맛 0, 서비스 2, 가격 −2)

$$\sigma_1u_1=\frac{0+2-2}{\sqrt3}=0,\qquad \sigma_2u_2=\frac{2-(-2)}{\sqrt2}=\frac{4}{\sqrt2}=2.828,\qquad \sigma_3u_3=\frac{0-2+2}{\sqrt6}=0$$

R05는 "전반적으로는 0(중립)인데, 서비스와 가격 차이가 아주 크다" — 정확히 "친절한데 너무 비쌈"입니다.

09Step 5 · Σ와 설명력

모든 점수의 제곱합 $\|A\|_F^2=84$가 "정보의 총량"입니다. 각 성향이 그중 $\sigma_i^2=\lambda_i$만큼을 가져갑니다.

$$\frac{48}{84}=57.1\%,\qquad\frac{30}{84}=35.7\%,\qquad\frac{6}{84}=7.1\%\qquad(\text{누적: }57.1\%\to92.9\%\to100\%)$$
읽는 법
"이 식당 리뷰를 이해하려면 2개의 질문이면 충분하다: ① 전반적으로 좋았나? ② 서비스와 가격 중 무엇이 더 좋았나?" — 3번째 질문(맛만 따로 튀었나)은 7%짜리 디테일입니다.

10Step 6 · 다시 조립하기 · 압축하기

SVD는 분해만 하는 게 아니라 다시 합치면 원본이 정확히 복원됩니다. 한 사람의 점수 = 세 성향 조각의 합입니다.

R02 (1, 1, 2)를 세 조각으로

$$\begin{aligned} \text{조각 1: }(\sigma_1u_1)\mathbf v_1&=\tfrac{4}{\sqrt3}\cdot\tfrac{1}{\sqrt3}(1,1,1)=(1.333,\;1.333,\;1.333)\quad\leftarrow\text{평균 감성}\\ \text{조각 2: }(\sigma_2u_2)\mathbf v_2&=-\tfrac{1}{\sqrt2}\cdot\tfrac{1}{\sqrt2}(0,1,-1)=(0,\;-0.5,\;+0.5)\quad\leftarrow\text{가격 쪽으로 기울기}\\ \text{조각 3: }(\sigma_3u_3)\mathbf v_3&=-\tfrac{1}{\sqrt6}\cdot\tfrac{1}{\sqrt6}(2,-1,-1)=(-0.333,\;+0.167,\;+0.167)\quad\leftarrow\text{맛 보정}\\ \text{합계}&=(1,\;1,\;2)\;✓ \end{aligned}$$

조각 1+2만 쓰면 $(1.333,\;0.833,\;1.833)$ — 원본 (1, 1, 2)와 거의 같습니다. 이것이 랭크 2 근사입니다.

그림 해석
k=1: 모든 사람이 "세 항목 같은 점수"로 뭉개짐 → R05(친절한데 비쌈)가 (0,0,0)이 되어 정보가 사라짐.
k=2: 서비스↔가격 대비가 살아나 R05가 (0, 2, −2)로 정확히 복원. 잔차가 가장 큰 사람은 R09(맛 +1.33) — 맛만 따로 튄 사람이라 3번째 성향을 버린 만큼 오차가 남습니다.

랭크 2 근사의 숨은 규칙: 맛 = (서비스 + 가격) / 2

$\mathbf v_1$과 $\mathbf v_2$의 조합 $a(1,1,1)+b(0,1,-1)=(a,\;a+b,\;a-b)$을 보면 항상 맛 = (서비스+가격)/2입니다. 즉 k=2로 줄인다는 것은 "맛 점수는 서비스와 가격의 평균으로 거의 설명된다"고 요약하는 것입니다. R02: (0.833+1.833)/2 = 1.333 ✓

오차는 버린 σ²로 정확히 계산된다 (Eckart–Young)

k=2로 줄여도 이 작은 예에선 숫자가 32개로 원본 36개와 비슷합니다. 하지만 100만 명 × 1000항목이라면 k=20만 남겨도 저장량이 약 1/50로 줄어 — SVD 압축의 진가는 큰 행렬에서 나옵니다.

11바이플롯 해석 — 12명을 지도 위에

요인 1을 가로축, 요인 2를 세로축으로 12명을 찍고, 항목은 $(\sigma_1v_{j1},\sigma_2v_{j2})$ 화살표로 함께 그립니다.

  1. 가로 위치 = 전반 감성 (행 합 ÷ √3). 오른쪽 끝 R01(+3.46), 왼쪽 끝 R11(−3.46).
  2. 세로 위치 = 서비스 − 가격. 위는 "서비스가 더 좋았다", 아래는 "가격이 더 좋았다".
  3. 맛 화살표는 정확히 가로 — $\mathbf v_2$의 맛 성분이 0이라 맛은 오직 전반 감성하고만 관련.
  4. 서비스·가격 화살표는 위아래 대칭 — 두 항목이 요인 2에서 정반대 역할.
  5. 점이 화살표 쪽에 있으면 그 항목을 좋게 평가. R05는 서비스 화살표 쪽, 가격 화살표 반대 → 서비스 +2, 가격 −2.

① 새 리뷰를 지도에 올리기 (Fold-in)

손으로 구한 λ=48·30·6, v=(1,1,1)·(0,1,−1)·(2,−1,−1)을 NumPy로 검증하고, 지금까지의 모든 수치를 출력합니다.

svd_sentiment2.py
import numpy as np

np.set_printoptions(precision=4, suppress=True)

# ── 1. 감성점수 행렬 (12명 × 3항목: 맛, 서비스, 가격 / -2 ~ +2)
A = np.array([
    [ 2,  2,  2],   # R01
    [ 1,  1,  2],   # R02
    [ 2,  0,  2],   # R03
    [ 0,  1,  2],   # R04
    [ 0,  2, -2],   # R05
    [ 1,  1, -1],   # R06
    [ 0, -2,  2],   # R07
    [-1, -2,  1],   # R08
    [ 1, -2,  0],   # R09
    [ 0, -1,  1],   # R10
    [-2, -2, -2],   # R11
    [-2, -2, -1],   # R12
], dtype=float)

# ── 2. AᵀA 와 특성방정식
M = A.T @ A
print("AᵀA =\n", M)
print("특성다항식 계수 (λ³ + aλ² + bλ + c):", np.poly(M))

# ── 3. 손으로 구한 고유값·고유벡터 검증
lam = np.array([48, 30, 6], dtype=float)
V = np.array([[1, 1, 1], [0, 1, -1], [2, -1, -1]], dtype=float).T
V = V / np.linalg.norm(V, axis=0)          # 열마다 길이 1
print("M·V - V·Λ 최대오차 =", np.abs(M @ V - V * lam).max())
sigma = np.sqrt(lam)
print("특이값 σ =", sigma)

# ── 4. U = A V / σ  (요인 점수 σu = A v)
scores = A @ V
U = scores / sigma
print("\n요인 점수 σu (= Av):")
for i, row in enumerate(scores):
    print(f"R{i+1:02d}  전반={row[0]:+.3f}  서비스-가격={row[1]:+.3f}  맛-나머지={row[2]:+.3f}")
print("UᵀU =\n", np.round(U.T @ U, 10))

# ── 5. numpy SVD와 비교 (부호만 다를 수 있음)
U_np, s_np, Vt_np = np.linalg.svd(A, full_matrices=False)
print("\nnp.linalg.svd σ =", s_np)
print("|Vᵀ| (부호 제거) =\n", np.abs(Vt_np))

# ── 6. 설명력과 저랭크 근사
print("설명력 =", lam / lam.sum(), " 누적 =", np.cumsum(lam) / lam.sum())
for k in (1, 2, 3):
    Ak = scores[:, :k] @ V[:, :k].T
    print(f"k={k}  ‖A-A_k‖_F = {np.linalg.norm(A - Ak):.4f}")
A2 = scores[:, :2] @ V[:, :2].T
print("A₂ (랭크 2 근사) =\n", A2)

# ── 7. 신규 리뷰어 fold-in: 맛 1, 서비스 2, 가격 -1
new = np.array([1, 2, -1], dtype=float)
z = new @ V[:, :2]
cos = scores[:, :2] @ z / (np.linalg.norm(scores[:, :2], axis=1) * np.linalg.norm(z))
top = np.argsort(-cos)[:3]
print("\n신규 리뷰어 좌표 =", z)
print("가장 비슷한 리뷰어 =", [(f"R{i+1:02d}", round(float(cos[i]), 4)) for i in top])

# ── 8. 결측 대치: R05의 '가격'(-2)을 숨기고 반복 SVD(k=2)
X = A.copy()
X[4, 2] = np.delete(A[:, 2], 4).mean()
start = X[4, 2]
for _ in range(40):
    u, s, vt = np.linalg.svd(X, full_matrices=False)
    X[4, 2] = (u[:, :2] @ np.diag(s[:2]) @ vt[:2])[4, 2]
print(f"R05 '가격' 추정 = {X[4, 2]:.4f}  (실제 -2, 단순평균 {start:.4f})")

확인문제

λ의 합과 곱으로 계산을 검산하는 방법은?
합 48+30+6 = 84 = 대각합(20+32+32), 곱 48×30×6 = 8640 = det M. 둘 다 맞으면 고유값 계산이 맞을 가능성이 매우 높습니다.
R09 (1, −2, 0)의 요인 1, 2 점수를 손으로 구하면?
요인1 = (1−2+0)/√3 = −0.577, 요인2 = (−2−0)/√2 = −1.414. 약간 불만이고, 가격보다 서비스를 나쁘게 봄 → "싸지만 불친절" 그룹.
k=1만 남기면 오차가 6인 이유는?
버린 성향의 σ²가 30과 6이므로 √(30+6) = √36 = 6.
새 리뷰 (−1, −2, 2) 는 지도 어디에 찍히나?
요인1 = (−1−2+2)/√3 = −0.577, 요인2 = (−2−2)/√2 = −2.828. 아래쪽 → "싸지만 불친절" 그룹(R07·R08 근처).
거듭제곱법을 (1,1,1)에서 시작하면 어떻게 될까?
(1,1,1)은 이미 $\mathbf v_1$ 방향이라 $M(1,1,1)=(48,48,48)$이 되어 1번 만에 λ=48을 얻습니다. 출발점에 $\mathbf v_1$ 성분이 많을수록 빨리 수렴합니다.
