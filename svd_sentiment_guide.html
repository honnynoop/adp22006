01개관과 로드맵

감성분석의 결과는 대개 "누가 무엇에 대해 얼마나 긍정/부정인가"라는 행렬로 쌓입니다. SVD는 이 행렬을 몇 개의 숨은 축(잠재요인)으로 분해해, 수십·수백 개 점수 뒤에 있는 감성의 구조를 드러냅니다.

02SVD의 정의

임의의 실수 행렬 $A \in \mathbb{R}^{m\times n}$은 항상 다음처럼 분해됩니다. 정방행렬이든 아니든, 랭크가 부족하든 아니든 예외가 없다는 것이 고유값분해와의 결정적 차이입니다.

$$A = U\,\Sigma\,V^{\mathsf T} = \sum_{i=1}^{r}\sigma_i\,\mathbf u_i\,\mathbf v_i^{\mathsf T},\qquad \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0$$

세 행렬은 어디서 오는가

$A^{\mathsf T}A$와 $AA^{\mathsf T}$에 SVD를 대입하면 바로 보입니다.

$$A^{\mathsf T}A = V\Sigma^{\mathsf T}U^{\mathsf T}U\Sigma V^{\mathsf T} = V\,\Sigma^2\,V^{\mathsf T},\qquad AA^{\mathsf T} = U\,\Sigma^2\,U^{\mathsf T}$$
  • $V$ = $A^{\mathsf T}A$(5×5, 항목×항목)의 고유벡터, $U$ = $AA^{\mathsf T}$(12×12, 리뷰어×리뷰어)의 고유벡터
  • $\sigma_i = \sqrt{\lambda_i}$ — 두 행렬이 공유하는 0이 아닌 고유값의 제곱근
  • 실전에서는 작은 쪽($A^{\mathsf T}A$, 5×5)만 분해하고 $\mathbf u_i = A\mathbf v_i/\sigma_i$로 $U$를 얻습니다 (8장)

꼭 기억할 성질

성질수식감성분석에서의 의미
존재성모든 $A$에 존재리뷰어 수 ≠ 항목 수여도 문제없음
직교성$U^{\mathsf T}U=V^{\mathsf T}V=I$잠재요인끼리 서로 겹치지 않음(독립적인 성향)
에너지 보존$\|A\|_F^2=\sum\sigma_i^2$감성 "총량"이 요인별로 나뉘어 담김
랭크rank$(A)$ = 0 아닌 σ의 개수진짜 독립적인 성향의 개수
최적 근사Eckart–Young 정리상위 k개 요인이 가장 좋은 요약 (10장)

03기하학적 의미 — 회전 · 늘림 · 회전

행렬 $A$를 벡터 $\mathbf x$에 곱하는 일은 세 동작의 합성입니다. 단위원(모든 방향의 길이 1 벡터)에 $A$를 적용하면 타원이 되고, 그 타원의 반축 길이가 특이값입니다.

감성분석 언어로 번역하면
Vᵀ: 5개 항목 점수를 "잠재 성향 축" 좌표로 바꿔 읽기 · Σ: 성향마다 얼마나 강하게 드러나는지 가중 · U: 그 성향을 각 리뷰어에게 배분. 핵심 등식은 $A\mathbf v_i = \sigma_i\mathbf u_i$ — "항목 방향 $\mathbf v_i$를 넣으면, 리뷰어 방향 $\mathbf u_i$가 $\sigma_i$배로 나온다."

04감성점수 데이터 (12명 × 5항목)

05Step 1 · $A^{\mathsf T}A$ 계산

$A^{\mathsf T}A$의 $(j,k)$ 원소는 항목 $j$열과 항목 $k$열의 내적입니다. 대각원소는 각 항목 감성의 제곱합(에너지), 비대각원소는 두 항목이 같은 방향으로 움직이는 정도입니다.

$$(A^{\mathsf T}A)_{jk} = \sum_{i=1}^{12} a_{ij}\,a_{ik}$$

손계산 ① 맛·맛 (대각원소)

$$(A^{\mathsf T}A)_{11} = 2^2+2^2+1^2+1^2+1^2+2^2+(-2)^2+(-1)^2+1^2+1^2+(-1)^2+0^2 = 23$$

손계산 ② 맛·가격 (비대각원소)

$$\begin{aligned}(A^{\mathsf T}A)_{14} &= 2\cdot2+2\cdot1+1\cdot(-2)+1\cdot(-2)+1\cdot2+2\cdot2+(-2)(-2)+(-1)(-1)+1\cdot0+1\cdot1+(-1)(-2)+0\cdot1\\ &= 4+2-2-2+2+4+4+1+0+1+2+0 = 16\end{aligned}$$

손계산 ③ 서비스·가격 (음수가 되는 경우)

$$(A^{\mathsf T}A)_{24} = 4+1-4-4-2-2+4+2+0+1-2-1 = -3$$

06Step 2 · 고유값 → 특이값

$A^{\mathsf T}A\,\mathbf v=\lambda\mathbf v$를 풀어야 합니다. 특성방정식 $\det(A^{\mathsf T}A-\lambda I)=0$은 5차식이라 근의 공식이 없으므로 실제로는 수치해법을 씁니다. 가장 직관적인 방법이 거듭제곱법(Power Iteration)입니다.

거듭제곱법 — 가장 큰 고유값 찾기

$$\mathbf x^{(k+1)} = \frac{A^{\mathsf T}A\,\mathbf x^{(k)}}{\|A^{\mathsf T}A\,\mathbf x^{(k)}\|},\qquad \lambda^{(k)} = \mathbf x^{(k)\mathsf T}A^{\mathsf T}A\,\mathbf x^{(k)}\;\;(\text{레일리 몫})$$

임의의 벡터를 계속 곱하면 가장 큰 고유값 방향 성분만 $(\lambda_1/\lambda_2)^k$ 비율로 살아남습니다. 시작값 $\mathbf x^{(0)}=\frac{1}{\sqrt5}(1,1,1,1,1)$.

손계산으로 따라가는 거듭제곱법 3단계

한 번의 반복은 언제나 같은 네 동작입니다: ① 행렬 × 벡터 → ② 길이(노름) 계산 → ③ 길이 1로 정규화 → ④ 레일리 몫으로 고유값 추정. 아래에서 $M = A^{\mathsf T}A$로 줄여 씁니다.

$$M=\begin{pmatrix}23&13&15&16&15\\13&26&23&-3&-1\\15&23&26&-1&0\\16&-3&-1&32&28\\15&-1&0&28&29\end{pmatrix},\qquad \mathbf x^{(0)}=\frac{1}{\sqrt5}\begin{pmatrix}1\\1\\1\\1\\1\end{pmatrix}=\begin{pmatrix}0.4472\\0.4472\\0.4472\\0.4472\\0.4472\end{pmatrix}$$

출발점의 고유값 추정: $\lambda^{(0)}=\mathbf x^{(0)\mathsf T}M\mathbf x^{(0)}=\frac{1}{5}\times(M\text{의 모든 원소 합 } 346)=\mathbf{69.2}$

10Step 6 · 저랭크 근사 (Truncated SVD)

SVD는 행렬을 랭크 1짜리 조각들의 합으로 씁니다. 상위 $k$개만 남기면 가장 좋은 요약이 됩니다.

$$A_k=\sum_{i=1}^{k}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T},\qquad \min_{\operatorname{rank}(B)\le k}\|A-B\|_F=\|A-A_k\|_F=\sqrt{\sigma_{k+1}^2+\cdots+\sigma_r^2}\quad(\text{Eckart–Young})$$

손계산 — 랭크 1 근사에서 R01의 '맛'

$$(A_1)_{11}=\sigma_1u_{11}v_{11}=8.4521\times0.4366\times0.5025=1.854\quad(\text{원래 } 2)$$

손계산 — 랭크 2 근사에서 R03의 '가격'

$$\begin{aligned}(A_2)_{34}&=\sigma_1u_{31}v_{41}+\sigma_2u_{32}v_{42}\\&=8.4521(-0.0208)(0.5675)+7.4038(-0.4943)(0.3772)\\&=-0.0999-1.3805=-1.480\quad(\text{원래 } -2)\end{aligned}$$

요인 1만으로는 R03을 "중립"(−0.1)으로밖에 못 그리지만, 요인 2를 더하면 "가격에 부정적"이라는 핵심이 살아납니다.

11바이플롯 해석 — 리뷰어와 항목을 한 평면에

리뷰어는 $(\sigma_1u_{i1},\sigma_2u_{i2})$ 점으로, 항목은 $(\sigma_1v_{j1},\sigma_2v_{j2})$ 화살표로 같은 2차원 잠재공간에 그립니다. 점과 화살표의 내적이 곧 근사 점수입니다: $(A_2)_{ij}\approx$ (점 방향) · (화살표 방향).

그래프 읽는 규칙

  1. 가로축 위치 = 전반적 감성. 오른쪽일수록 이 식당 전체를 긍정. R01(+3.69)이 가장 만족, R07(−3.97)이 가장 불만.
  2. 세로축 위치 = 무엇을 기준으로 평가하나. 위쪽은 가격·양에 관대, 아래쪽은 서비스·분위기에 관대.
  3. 화살표 방향과 같은 쪽에 있는 점은 그 항목을 좋게 평가. R12는 가격·양 화살표 쪽, 서비스·분위기 화살표 반대쪽 → 실제로 가격 +1·양 +2, 서비스 −1·분위기 −2.
  4. 화살표끼리 각도가 좁으면 같이 움직이는 항목. 가격·양이 거의 겹치고, 서비스·분위기가 거의 겹침. 두 묶음은 약 90° → 서로 독립(5장 AᵀA의 −3, −1, 0과 일치).
  5. 맛은 두 묶음 사이 오른쪽 → 맛은 어떤 유형이든 전반적 만족과 함께 움직이는 "기본" 항목.
  6. 원점에 가까운 점(R09)은 의견이 약하거나 중립 — 세그먼트 판단에서 신뢰도가 낮음.

13텍스트 감성분석으로 확장 — LSA

지금까지는 이미 만들어진 감성점수 행렬을 분해했습니다. 원문 텍스트에 직접 SVD를 쓰는 고전적 방법이 잠재의미분석(LSA, Latent Semantic Analysis)입니다.

항목이 학습서(감성점수 행렬)LSA(문서-단어 행렬)
행렬리뷰어 × 항목, 값 = 감성점수문서 × 단어, 값 = TF-IDF
V가 담는 것항목이 묶이는 감성 성향함께 등장하는 단어 묶음(주제·감성어)

장점해석이 쉬움동의어 문제 완화("불친절"·"무례"가 가까워짐), 희소→밀집

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD

model.fit(texts, labels)
실무 주의사항
① 희소 행렬은 np.linalg.svd 대신 TruncatedSVD(랜덤화/ARPACK)로 — 전체 분해는 메모리 폭발. ② 평균 중심화를 하면 PCA가 되고, 하지 않으면 첫 요인이 "전반 수준"이 된다(이 학습서처럼). ③ 항목별 척도가 다르면 표준화 후 분해. ④ 부호는 임의이므로 해석 전 통일.

import numpy as np
from sklearn.decomposition import TruncatedSVD

np.set_printoptions(precision=4, suppress=True)

# ── 1. 감성점수 행렬 (12명 × 5항목, -2=매우부정 ~ +2=매우긍정)
items = ["맛", "서비스", "분위기", "가격", "양"]
A = np.array([
    [ 2,  2,  2,  2,  1],   # R01
    [ 2,  1,  2,  1,  1],   # R02
    [ 1,  2,  2, -2, -1],   # R03
    [ 1,  2,  1, -2, -2],   # R04
    [ 1, -1, -1,  2,  2],   # R05
    [ 2, -1,  0,  2,  2],   # R06
    [-2, -2, -1, -2, -2],   # R07
    [-1, -2, -2, -1, -2],   # R08
    [ 1,  0,  1,  0,  0],   # R09
    [ 1,  1,  1,  1,  1],   # R10
    [-1,  1,  1, -2, -1],   # R11
    [ 0, -1, -2,  1,  2],   # R12
], dtype=float)

# ── 2. 직접 유도: AᵀA의 고유분해 → σ = √λ, V
AtA = A.T @ A
lam, V = np.linalg.eigh(AtA)
order = np.argsort(lam)[::-1]
lam, V = lam[order], V[:, order]
sigma = np.sqrt(lam)
print("AᵀA =\n", AtA)
print("고유값 λ =", lam)
print("특이값 σ =", sigma)
print("trace(AᵀA) =", np.trace(AtA), " ‖A‖_F² =", (A**2).sum())

# ── 3. numpy SVD (부호 통일: v1은 합이 양수, v2는 가격·양 쪽이 양수)
U, s, Vt = np.linalg.svd(A, full_matrices=False)
if Vt[0].sum() < 0:
    Vt[0] *= -1; U[:, 0] *= -1
if Vt[1, 3] + Vt[1, 4] - Vt[1, 1] - Vt[1, 2] < 0:
    Vt[1] *= -1; U[:, 1] *= -1
print("\nnp.linalg.svd σ =", s)
print("v1 =", Vt[0])
print("v2 =", Vt[1])
energy = s**2 / (s**2).sum()
print("설명력 =", energy, " 누적 =", np.cumsum(energy))

# ── 4. 저랭크 근사와 Eckart–Young 오차
for k in range(1, 6):
    Ak = U[:, :k] @ np.diag(s[:k]) @ Vt[:k]
    print(f"k={k}  ‖A-A_k‖_F = {np.linalg.norm(A - Ak):.4f}"
          f"  √(Σ버린σ²) = {np.sqrt((s[k:]**2).sum()):.4f}")

# ── 5. 리뷰어 잠재좌표 (σ·u)
US = U[:, :2] * s[:2]
for i, row in enumerate(US):
    print(f"R{i+1:02d}  요인1(전반감성)={row[0]:+.3f}  요인2(가성비↔경험)={row[1]:+.3f}")

# ── 6. 신규 리뷰어 fold-in: "가격 착하고 양 많은데 직원이 불친절"
new = np.array([1, -2, 0, 2, 2], dtype=float)
z = new @ Vt[:2].T                       # 잠재좌표 = a·V_k
cos = US @ z / (np.linalg.norm(US, axis=1) * np.linalg.norm(z))
best = np.argsort(-cos)[:3]
print("\n신규 리뷰어 잠재좌표 =", z)
print("가장 비슷한 리뷰어 =", [(f"R{i+1:02d}", round(cos[i], 4)) for i in best])

# ── 7. 결측 대치: R04의 '가격'을 숨기고 반복 SVD(k=2)로 추정
X = A.copy()
X[3, 3] = np.delete(A[:, 3], 3).mean()
for _ in range(30):
    u, ss, vt = np.linalg.svd(X, full_matrices=False)
    X[3, 3] = (u[:, :2] @ np.diag(ss[:2]) @ vt[:2])[3, 3]
print(f"R04 '가격' 추정 = {X[3, 3]:.4f}  (실제 -2, 단순평균 {np.delete(A[:, 3], 3).mean():.4f})")

# ── 8. scikit-learn TruncatedSVD 교차검증
tsvd = TruncatedSVD(n_components=2, algorithm="arpack").fit(A)
print("\nsklearn singular_values_ =", tsvd.singular_values_)
print("sklearn explained_variance_ratio_ =", tsvd.explained_variance_ratio_)

16체크리스트 · 확인문제

핵심 체크리스트

  • $A=U\Sigma V^{\mathsf T}$에서 U·Σ·V의 크기와 의미(리뷰어/세기/항목)를 말할 수 있다
  • $V$는 $A^{\mathsf T}A$의 고유벡터, $\sigma=\sqrt\lambda$, $\mathbf u_i=A\mathbf v_i/\sigma_i$를 유도할 수 있다
  • $\sum\sigma_i^2=\|A\|_F^2=\operatorname{tr}(A^{\mathsf T}A)$로 계산을 검증할 수 있다
  • 5차 이상은 거듭제곱법 같은 수치해법이 필요하다는 것과 수렴 속도가 $\lambda_2/\lambda_1$에 달려 있음을 안다
  • 적재값(V)의 부호 패턴으로 요인 이름을 붙일 수 있다 (전반 vs 대비)
  • 스크리 플롯의 팔꿈치와 누적 설명력으로 k를 정할 수 있다
  • Eckart–Young: 랭크 k 근사 오차 $=\sqrt{\sum_{i>k}\sigma_i^2}$
  • 바이플롯에서 점–화살표 방향, 화살표 사이 각도를 해석할 수 있다
  • Fold-in($\mathbf aV_k$), 코사인 유사도, 반복 SVD 대치를 설명할 수 있다
  • SVD의 부호 모호성과 중심화 여부(SVD vs PCA)의 차이를 안다

확인문제

이 데이터에서 rank(A)는 얼마이며, 그 근거는?
5. 특이값 5개(8.452, 7.404, 2.209, 1.658, 1.456)가 모두 0이 아니기 때문. 다만 "실질적인" 랭크는 σ가 급감하기 전까지인 2로 봅니다.
k=1만 남기면 R03과 R04의 '가격 불만'이 사라지는 이유는?
랭크 1 근사는 모든 행이 v₁(모두 양수)의 배수입니다. 한 리뷰어가 어떤 항목은 +, 어떤 항목은 −인 패턴을 표현할 수 없습니다. 그 대비를 담는 v₂가 있어야 복원됩니다.
σ₁=8.4521일 때 v₁ 방향만 남긴 근사의 Frobenius 오차는?
$\sqrt{136-71.4376}=\sqrt{64.5624}=8.035$. 전체 에너지에서 첫 번째 σ²를 빼고 제곱근.
새 리뷰 a = (−1, 2, 2, −2, −1)의 잠재좌표와 예상 세그먼트는?
a·v₁ = −0.5025+0.4624+0.5408−1.1350−0.5466 = −1.181, a·v₂ = 0.1833−1.2118−1.1842−0.7544−0.3261 = −3.293. 왼쪽 아래 → "가격 불만 · 경험파" (R03·R04·R11과 같은 그룹).
이 학습서처럼 평균을 빼지 않고 SVD를 하면 PCA와 무엇이 달라지나?
평균을 빼지 않으면 첫 요인이 원점에서 데이터 중심까지의 방향, 즉 "전반적 감성 수준"을 잡습니다. 열 평균을 빼면(PCA) 이 수준이 제거되고 항목 간 상대적 차이만 남습니다. 감성점수처럼 0이 의미 있는 중립점일 때는 중심화하지 않는 쪽이 해석에 유리합니다.
