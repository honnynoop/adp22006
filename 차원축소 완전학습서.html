CHAPTER 00

왜 차원을 줄이는가

데이터의 열(변수, 특성) 개수가 차원입니다. 변수가 많다고 정보가 비례해서 늘지는 않습니다. 서로 겹치는 변수, 노이즈뿐인 변수가 섞이면 모델은 오히려 느려지고, 불안정해지고, 과대적합됩니다. 차원축소는 데이터를 적은 수의 의미 있는 축으로 다시 표현하는 작업입니다.

목적무엇이 좋아지나대표 기법

방법은 크게 둘로 나뉩니다. 변수 선택은 원래 변수 중 일부를 고르므로 결과를 그대로 해석할 수 있습니다. 변수 추출은 원래 변수를 조합해 새 변수를 만들므로 정보를 더 많이 보존하지만, 새 변수의 의미는 해석이 필요합니다. 한국 통계 교재에서 말하는 변수 축약은 주로 후자(PCA, 요인분석)를 가리킵니다.

CHAPTER 01

변수 선택 (Feature Selection)

원래 변수 $p$개 중 $k$개를 고릅니다. 모든 조합을 시험하면 $2^p$가지이므로($p=30$이면 약 10억), 실제로는 아래 세 가지 전략으로 효율적으로 고릅니다.

1.1필터 · 래퍼 · 임베디드

방식원리대표 기준·알고리즘장점단점
필터모델과 무관하게 변수별 통계량으로 순위분산 임계값, 상관계수, $\chi^2$, ANOVA $F$, 상호정보량매우 빠름, 과적합 위험 낮음변수 간 상호작용·중복 무시
래퍼모델 성능으로 변수 부분집합 평가전진선택, 후진제거, 단계적 선택, RFE모델에 최적화된 조합계산량 큼, 과적합 위험
임베디드학습 과정 안에서 선택이 일어남Lasso(L1), Elastic Net, 트리 특성 중요도성능과 속도의 균형모델 종류에 종속

필터 통계량

입력 → 출력통계량수식
연속 → 연속피어슨 상관계수$r=\dfrac{\sum(x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum(x_i-\bar x)^2\sum(y_i-\bar y)^2}}$
연속 → 범주ANOVA $F$$F=\dfrac{\text{집단 간 분산}}{\text{집단 내 분산}}=\dfrac{SSB/(K-1)}{SSW/(n-K)}$
범주 → 범주카이제곱$\chi^2=\sum\dfrac{(O-E)^2}{E}$
모든 경우 (비선형 포함)상호정보량$I(X;Y)=\sum p(x,y)\log\dfrac{p(x,y)}{p(x)p(y)}$

래퍼: 단계적 선택 절차

  • 전진선택: 빈 모델에서 시작해 성능을 가장 많이 올리는 변수를 하나씩 추가, 개선이 없으면 멈춤
  • 후진제거: 전체 모델에서 시작해 가장 덜 중요한(예: p값 최대) 변수를 하나씩 제거
  • 단계적 선택: 매 단계 추가와 제거를 모두 검토 (전진 + 후진)
  • RFE(재귀적 특성 제거): 모델을 학습 → 계수·중요도가 가장 작은 변수 제거 → 반복

1.2다중공선성과 VIF

정의 · 분산팽창계수 (VIF)

변수 $x_j$를 나머지 변수 전부로 회귀했을 때의 결정계수가 $R_j^2$이면

$$\text{VIF}_j=\frac{1}{1-R_j^2}$$

$x_j$의 회귀계수 분산이 다른 변수와 독립일 때보다 몇 배 커지는지를 뜻합니다. 보통 10 이상(엄격하게는 5 이상)이면 심한 다중공선성으로 봅니다.

1.3Lasso와 정보기준

Lasso는 손실에 계수의 절댓값 합을 더해, 중요하지 않은 계수를 정확히 0으로 만듭니다. 학습과 변수 선택이 한 번에 이루어지는 임베디드 방법입니다.

$$\hat{\boldsymbol\beta}=\operatorname*{argmin}_{\boldsymbol\beta}\;\frac{1}{2n}\|\mathbf{y}-X\boldsymbol\beta\|_2^2+\lambda\|\boldsymbol\beta\|_1$$
기준수식사용법
AIC$-2\ln\hat L+2k$작을수록 좋음. 예측 성능 중시
BIC$-2\ln\hat L+k\ln n$작을수록 좋음. $n\ge8$이면 AIC보다 벌점이 커서 더 단순한 모델 선택
수정 결정계수$1-(1-R^2)\dfrac{n-1}{n-k-1}$클수록 좋음. 변수를 추가해도 무조건 증가하지 않음
Mallows $C_p$$\dfrac{SSE_k}{\hat\sigma^2}-n+2k$$C_p\approx k$ 인 모델이 적절
ch1_feature_selection.py
import numpy as np
from sklearn.datasets import load_diabetes
from sklearn.preprocessing import StandardScaler
from sklearn.feature_selection import SelectKBest, f_regression, mutual_info_regression, RFE
from sklearn.linear_model import LinearRegression, LassoCV

data = load_diabetes()
X = StandardScaler().fit_transform(data.data)
y = data.target
names = np.array(data.feature_names)

# ---- 필터: F 통계량, 상호정보량 ----
f_sel = SelectKBest(f_regression, k=4).fit(X, y)
mi = mutual_info_regression(X, y, random_state=0)
print("F검정 상위 4개 :", names[f_sel.get_support()])
print("상호정보량 순위:", names[np.argsort(-mi)][:4])

# ---- 래퍼: RFE ----
rfe = RFE(LinearRegression(), n_features_to_select=4).fit(X, y)
print("RFE 선택 4개   :", names[rfe.support_])

# ---- 임베디드: 교차검증 Lasso ----
lasso = LassoCV(cv=5, random_state=0).fit(X, y)
print(f"LassoCV λ={lasso.alpha_:.3f}, 0이 된 변수:", names[np.abs(lasso.coef_) < 1e-8])

# ---- 다중공선성: VIF ----
def vif(X):
    out = []
    for j in range(X.shape[1]):
        others = np.delete(X, j, axis=1)
        r2 = LinearRegression().fit(others, X[:, j]).score(others, X[:, j])
        out.append(1 / (1 - r2))
    return np.array(out)

v = vif(X)
for n, val in sorted(zip(names, v), key=lambda t: -t[1]):
    print(f"VIF {n:4s} {val:7.2f}", "← 다중공선성" if val >= 10 else "")

CHAPTER 02

주성분분석 (PCA)

PCA는 서로 상관된 변수들을 서로 상관없는(직교하는) 새 변수로 바꾸되, 첫 번째 새 변수가 분산을 가장 많이 담고, 두 번째가 그다음을 담도록 만듭니다. 앞의 몇 개만 남기면 정보 손실을 최소화하면서 차원을 줄일 수 있습니다.

2.1원리와 유도

유도 · 분산을 최대로 하는 방향

중심화한 데이터 $X_c$의 공분산 행렬을 $\Sigma$라 하면, 단위벡터 $\mathbf{w}$ 방향으로 사영한 값 $z=\mathbf{w}^\top\mathbf{x}$의 분산은 $\mathbf{w}^\top\Sigma\mathbf{w}$ 입니다. 이를 $\|\mathbf{w}\|=1$ 조건에서 최대화합니다.

$$\max_{\mathbf{w}}\;\mathbf{w}^\top\Sigma\mathbf{w}\quad\text{s.t.}\quad\mathbf{w}^\top\mathbf{w}=1$$

라그랑주 함수 $\mathcal{L}=\mathbf{w}^\top\Sigma\mathbf{w}-\lambda(\mathbf{w}^\top\mathbf{w}-1)$ 를 미분해 0으로 두면

$$2\Sigma\mathbf{w}-2\lambda\mathbf{w}=0\;\Longrightarrow\;\Sigma\mathbf{w}=\lambda\mathbf{w},\qquad \operatorname{Var}(z)=\mathbf{w}^\top\Sigma\mathbf{w}=\lambda$$

즉 해는 공분산 행렬의 고유벡터이고, 그 방향의 분산은 고유값입니다. 분산을 최대로 하려면 가장 큰 고유값의 고유벡터를 고르면 됩니다. 두 번째 주성분은 첫 번째와 직교한다는 조건을 더해 같은 방식으로 풀면 두 번째로 큰 고유값의 고유벡터가 나옵니다.

또 다른 관점 · 재구성 오차 최소화

각 점 $\mathbf{x}$를 $\mathbf{w}$ 방향으로 사영해 $\hat{\mathbf{x}}=(\mathbf{w}^\top\mathbf{x})\mathbf{w}$로 근사하면, 피타고라스 정리에 의해

$$\|\mathbf{x}\|^2=\underbrace{(\mathbf{w}^\top\mathbf{x})^2}_{\text{사영된 길이}^2}+\underbrace{\|\mathbf{x}-\hat{\mathbf{x}}\|^2}_{\text{재구성 오차}}$$

왼쪽(전체 분산)은 고정이므로, 사영 분산을 최대화하는 것과 재구성 오차를 최소화하는 것은 같은 문제입니다.

2.2계산 절차

단계계산비고
1. 표준화$\tilde x_{ij}=(x_{ij}-\bar x_j)/s_j$단위가 다르면 필수 (상관행렬 PCA)
2. 공분산(상관) 행렬$\Sigma=\frac{1}{n-1}\tilde X^\top\tilde X$$p\times p$ 대칭, 양반정치
3. 고유값 분해$\Sigma=W\Lambda W^\top$, $\lambda_1\ge\dots\ge\lambda_p\ge0$실무에서는 SVD로 계산 (3장)
4. 주성분 수 $k$ 결정누적 설명분산, 스크리 플롯, Kaiser2.3절
5. 주성분 점수$Z=\tilde XW_k\in\mathbb{R}^{n\times k}$새로운 변수 (서로 상관 0)
6. (선택) 복원$\hat X=ZW_k^\top$, 이후 표준화 역변환노이즈 제거, 이상탐지
주의 · 공분산 PCA와 상관 PCA

공분산 행렬로 PCA를 하면 분산이 큰 변수가 첫 주성분을 독차지합니다. 와인 데이터에서 proline(값이 수백~1,600)은 분산이 약 99,000이고 hue는 약 0.05라서, 표준화하지 않으면 PC1이 사실상 proline 하나가 됩니다. 단위가 다른 변수를 섞을 때는 반드시 표준화 후(= 상관행렬로) PCA를 하세요. 모든 변수가 같은 단위(예: 픽셀 밝기)일 때만 공분산 PCA가 자연스럽습니다.

응용 · 주성분 회귀 (PCR)

다중공선성이 심한 회귀에서 원래 변수 대신 주성분 점수 $Z_k$로 회귀합니다. 주성분은 서로 상관이 0이라 계수가 안정됩니다. 다만 PCA는 $y$를 보지 않고 축을 정하므로, $y$와 관련된 정보가 작은 분산 성분에 있으면 버려질 수 있습니다. $y$와의 공분산을 최대화하는 축을 찾는 PLS(부분최소제곱)가 그 대안입니다.

import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

wine = load_wine()
X = StandardScaler().fit_transform(wine.data)          # 상관행렬 PCA
n = len(X)

# ---- 직접 구현: 공분산 행렬 고유분해 ----
C = X.T @ X / (n - 1)
lam, W = np.linalg.eigh(C)
order = np.argsort(lam)[::-1]
lam, W = lam[order], W[:, order]
Z = X @ W[:, :2]                                       # 주성분 점수

# ---- scikit-learn ----
pca = PCA(n_components=2).fit(X)
print("고유값 (직접)  :", lam[:4].round(3))
print("고유값 (sklearn):", pca.explained_variance_.round(3))
print("설명분산 비율   :", pca.explained_variance_ratio_.round(4), "누적", pca.explained_variance_ratio_.sum().round(4))
print("부호 차이만 있음:", np.allclose(np.abs(Z), np.abs(pca.transform(X))))
print("주성분 간 상관  :", np.corrcoef(Z.T)[0, 1].round(10))

# ---- 적재값 = 원변수와 주성분의 상관계수 ----
loadings = pca.components_.T * np.sqrt(pca.explained_variance_)
for name, (l1, l2) in zip(wine.feature_names, loadings):
    print(f"{name[:22]:22s} PC1 {l1:+.3f}  PC2 {l2:+.3f}")

# ---- 누적 설명분산 기준으로 k 자동 선택 ----
pca90 = PCA(n_components=0.90).fit(X)
print("90% 설명에 필요한 주성분 수:", pca90.n_components_)

# ---- 재구성 오차 ----
for k in (2, 5, 8, 13):
    p = PCA(k).fit(X)
    X_hat = p.inverse_transform(p.transform(X))
    print(f"k={k:2d}  재구성 오차 비율 {np.sum((X - X_hat)**2) / np.sum(X**2):.4f}")

SVD와 저랭크 근사

특이값 분해(SVD)는 PCA를 실제로 계산하는 엔진이자, 정사각행렬이 아닌 데이터 행렬(문서×단어, 사용자×상품, 이미지 픽셀)을 직접 축약하는 도구입니다.

핵심 공식 · SVD와 PCA의 관계 $$X_c=U\Sigma V^\top\quad\Longrightarrow\quad \frac{X_c^\top X_c}{n-1}=V\,\frac{\Sigma^2}{n-1}\,V^\top$$
  • 오른쪽 특이벡터 $V$의 열 = 주성분 방향 (공분산 행렬의 고유벡터)
  • 고유값 $\lambda_k=\sigma_k^2/(n-1)$
  • 주성분 점수 $Z=X_cV=U\Sigma$

공분산 행렬 $X^\top X$를 만들지 않고 $X$에 바로 SVD를 하면 조건수가 제곱되는 문제를 피할 수 있어 수치적으로 더 정확합니다. scikit-learn의 PCA도 내부적으로 SVD를 씁니다.

Eckart–Young 정리

큰 특이값 $k$개만 남긴 $X_k=\sum_{i=1}^{k}\sigma_i\mathbf{u}_i\mathbf{v}_i^\top$ 는 랭크 $k$ 행렬 중 $X$에 가장 가까운 행렬이며, 오차는 버린 특이값으로 정해집니다.

$$\|X-X_k\|_F=\sqrt{\sum_{i>k}\sigma_i^2},\qquad \text{저장량: }mn\;\to\;k(m+n+1)$$

요인분석 (Factor Analysis)

요인분석은 관측된 여러 변수의 상관관계가 눈에 보이지 않는 소수의 공통 요인 때문에 생긴다고 보고, 그 요인을 찾아냅니다. 국어·영어·사회 점수가 함께 높은 이유를 "언어 능력"이라는 잠재 요인으로 설명하는 식입니다. 설문 문항을 몇 개의 개념으로 묶는 데 가장 많이 씁니다.

핵심 공식 · 요인 모형 $$\mathbf{x}=\boldsymbol\mu+\Lambda\mathbf{f}+\boldsymbol\varepsilon,\qquad \mathbf{f}\sim\mathcal{N}(0,I_k),\quad\boldsymbol\varepsilon\sim\mathcal{N}(0,\Psi),\quad\Psi=\operatorname{diag}(\psi_1,\dots,\psi_p)$$ $$\operatorname{Cov}(\mathbf{x})=\Lambda\Lambda^\top+\Psi,\qquad \underbrace{1}_{\text{표준화 분산}}=\underbrace{h_j^2=\sum_{k}\lambda_{jk}^2}_{\text{공통성}}+\underbrace{\psi_j}_{\text{고유분산}}$$
  • $\Lambda$ ($p\times k$): 요인적재값, 변수와 요인의 관계
  • 공통성 $h_j^2$: 변수 $j$의 분산 중 공통 요인이 설명하는 부분
  • 고유분산 $\psi_j$: 그 변수만의 고유한 부분 + 측정오차
주성분분석 (PCA)요인분석 (FA)
방향변수 → 성분: $z=W^\top\mathbf{x}$요인 → 변수: $\mathbf{x}=\Lambda\mathbf{f}+\boldsymbol\varepsilon$
목적전체 분산을 최대한 요약 (데이터 축약)변수 간 공분산(상관)의 원인 설명 (구조 발견)
오차 항없음 (모든 분산을 성분이 나눠 가짐)변수마다 고유분산 $\psi_j$를 따로 둠
해유일 (고유벡터)회전에 따라 무수히 많음 → 해석 쉬운 회전 선택
대표 사용처전처리, 압축, 시각화, PCR설문·심리 척도 개발, 타당도 검증, 지수 개발

분석 절차

단계내용기준
1. 적합성 검정KMO 표본 적합도, Bartlett 구형성 검정KMO ≥ 0.6 (0.8 이상 우수), Bartlett $p\lt0.05$
2. 요인 추출최대우도법(ML), 주축요인법(PAF), 주성분법요인 수: 고유값 ≥ 1, 스크리, 평행분석
3. 요인 회전직교(Varimax) 또는 사각(Promax, Oblimin)요인 간 상관을 허용할지
4. 해석·명명|적재값| ≥ 0.4~0.5인 변수로 요인 이름 붙이기교차적재(두 요인에 모두 큼) 문항은 제거 검토
5. 요인 점수회귀법, Bartlett법으로 개인별 요인 점수 산출후속 분석의 입력 변수로 사용
KMO $$\text{KMO}=\frac{\sum_{i\ne j}r_{ij}^2}{\sum_{i\ne j}r_{ij}^2+\sum_{i\ne j}a_{ij}^2}$$

$r$은 상관계수, $a$는 편상관계수. 편상관이 작을수록(공통 요인이 상관을 잘 설명할수록) 1에 가깝습니다.

Bartlett 구형성 검정 $$\chi^2=-\Big(n-1-\frac{2p+5}{6}\Big)\ln|R|$$

자유도 $p(p-1)/2$. $H_0$: 상관행렬 = 단위행렬(변수끼리 상관 없음 → 요인분석 무의미).

import numpy as np
from scipy import stats
from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler

# ---- 데이터 생성: 언어·수리 두 잠재 요인 → 6과목 ----
rng = np.random.default_rng(3)
n = 600
F = rng.multivariate_normal([0, 0], [[1, 0.3], [0.3, 1]], n)
L_true = np.array([[0.85, 0.10], [0.80, 0.15], [0.70, 0.20],
                   [0.15, 0.85], [0.20, 0.80], [0.10, 0.75]])
X = StandardScaler().fit_transform(F @ L_true.T + rng.normal(0, 0.45, (n, 6)))
items = ["국어", "영어", "사회", "수학", "물리", "화학"]
p = X.shape[1]

# ---- 1) 적합성: KMO, Bartlett ----
R = np.corrcoef(X.T)
Rinv = np.linalg.inv(R)
partial = -Rinv / np.sqrt(np.outer(np.diag(Rinv), np.diag(Rinv)))
off = ~np.eye(p, dtype=bool)
kmo = (R[off]**2).sum() / ((R[off]**2).sum() + (partial[off]**2).sum())
chi2 = -(n - 1 - (2 * p + 5) / 6) * np.log(np.linalg.det(R))
df = p * (p - 1) // 2
print(f"KMO = {kmo:.3f} | Bartlett χ² = {chi2:.1f}, df = {df}, p = {stats.chi2.sf(chi2, df):.2e}")

# ---- 2) 요인 수: 상관행렬 고유값 ≥ 1 ----
print("상관행렬 고유값:", np.sort(np.linalg.eigvalsh(R))[::-1].round(3))

# ---- 3) 추출 + 회전 ----
for rot in (None, "varimax"):
    fa = FactorAnalysis(n_components=2, rotation=rot, random_state=0).fit(X)
    L = fa.components_.T
    L = L * np.sign(L.sum(axis=0))                      # 부호 정리 (요인 부호는 임의)
    if abs(L[0, 0]) < abs(L[0, 1]):                     # 국어가 가장 크게 실린 요인을 요인1로
        L = L[:, ::-1]
    print(f"\n[회전: {rot}]")
    for name, (a, b), psi in zip(items, L, fa.noise_variance_):
        print(f"  {name}  요인1 {a:+.3f}  요인2 {b:+.3f}  공통성 {a*a + b*b:.3f}  고유분산 {psi:.3f}")

# ---- 4) 요인 점수 ----
scores = FactorAnalysis(n_components=2, rotation="varimax", random_state=0).fit_transform(X)
print("\n요인 점수 shape:", scores.shape, "| 실제 요인과의 |상관|:",
      np.abs(np.corrcoef(scores.T, F.T)[:2, 2:]).max(axis=1).round(3))

선형판별분석 (LDA)

PCA는 레이블을 보지 않고 분산이 큰 방향을 찾습니다. 그런데 분산이 크다고 클래스를 잘 나누는 것은 아닙니다. LDA는 레이블을 사용해 클래스 사이는 멀고 클래스 안은 촘촘한 방향을 찾는 지도 학습 차원축소입니다.

핵심 공식 · Fisher 기준 $$S_W=\sum_{c}\sum_{i\in c}(\mathbf{x}_i-\boldsymbol\mu_c)(\mathbf{x}_i-\boldsymbol\mu_c)^\top,\qquad S_B=\sum_c n_c(\boldsymbol\mu_c-\boldsymbol\mu)(\boldsymbol\mu_c-\boldsymbol\mu)^\top$$ $$J(\mathbf{w})=\frac{\mathbf{w}^\top S_B\mathbf{w}}{\mathbf{w}^\top S_W\mathbf{w}}=\frac{\text{클래스 간 분산}}{\text{클래스 내 분산}}$$

미분해서 0으로 두면 일반화 고유값 문제 $S_B\mathbf{w}=\lambda S_W\mathbf{w}$, 곧 $S_W^{-1}S_B$의 고유벡터가 해입니다. 두 클래스이면 닫힌 해가 있습니다.

$$\mathbf{w}^*\propto S_W^{-1}(\boldsymbol\mu_1-\boldsymbol\mu_0)$$

$S_B$의 랭크는 최대 $C-1$이므로 LDA로 얻는 축은 최대 (클래스 수 − 1)개입니다. 3품종 와인이면 2차원까지입니다.

ch5_lda.py
import numpy as np
from sklearn.datasets import load_wine
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import cross_val_score

X, y = load_wine(return_X_y=True)

# ---- 직접 구현: Fisher LDA (S_W⁻¹ S_B 고유분해) ----
Xs = StandardScaler().fit_transform(X)
mu = Xs.mean(0)
Sw = sum((Xs[y == c] - Xs[y == c].mean(0)).T @ (Xs[y == c] - Xs[y == c].mean(0)) for c in np.unique(y))
Sb = sum((y == c).sum() * np.outer(Xs[y == c].mean(0) - mu, Xs[y == c].mean(0) - mu) for c in np.unique(y))
vals, vecs = np.linalg.eig(np.linalg.solve(Sw, Sb))
order = np.argsort(-vals.real)
print("S_W⁻¹S_B 고유값 (상위 4):", vals.real[order][:4].round(4), "← 0이 아닌 것은 C-1=2개")

# ---- 2차원으로 줄인 뒤 같은 kNN 분류기로 비교 ----
for name, reducer in [("PCA 2D", PCA(2)), ("LDA 2D", LinearDiscriminantAnalysis(n_components=2))]:
    pipe = make_pipeline(StandardScaler(), reducer, KNeighborsClassifier(5))
    acc = cross_val_score(pipe, X, y, cv=5).mean()
    print(f"{name} + kNN  5-fold 정확도 {acc:.3f}")

lda = LinearDiscriminantAnalysis().fit(StandardScaler().fit_transform(X), y)

다차원척도법 (MDS)

MDS는 원래 좌표 없이 개체들 사이의 거리(또는 비유사도)만 주어졌을 때, 그 거리를 최대한 보존하는 저차원 좌표를 찾습니다. 브랜드 간 유사도 설문으로 포지셔닝 맵을 그리는 데 많이 씁니다.

유도 · 고전적(Classical) MDS

좌표 $X$가 중심화되어 있으면 거리와 내적은 $d_{ij}^2=\|\mathbf{x}_i\|^2+\|\mathbf{x}_j\|^2-2\mathbf{x}_i^\top\mathbf{x}_j$ 관계입니다. 거리 제곱 행렬 $D^{(2)}$에 이중 중심화를 하면 내적 행렬(그램 행렬)이 복원됩니다.

$$B=-\tfrac12\,J D^{(2)} J=XX^\top,\qquad J=I-\tfrac1n\mathbf{1}\mathbf{1}^\top$$

$B=V\Lambda V^\top$로 고유분해한 뒤 큰 고유값 $k$개로 좌표를 만듭니다.

$$X_k=V_k\Lambda_k^{1/2}$$

거리가 유클리드 거리이면 고전 MDS의 결과는 PCA 점수와 같습니다(회전·반사 차이만 있음).

예제 · 도시 간 직선거리만으로 지도 그리기

12개 도시의 위경도로 대권거리(km)를 계산해 12×12 거리 행렬을 만들고, 좌표 정보는 버린 채 이 거리 행렬만 MDS에 넣었습니다.

ch6_mds.py
import numpy as np
from sklearn.manifold import MDS

cities = {"서울": (37.5665, 126.9780), "인천": (37.4563, 126.7052), "강릉": (37.7519, 128.8761),
          "대전": (36.3504, 127.3845), "광주": (35.1595, 126.8526), "대구": (35.8714, 128.6014),
          "부산": (35.1796, 129.0756), "제주": (33.4996, 126.5312)}
names = list(cities)
lat = np.radians([cities[c][0] for c in names]); lon = np.radians([cities[c][1] for c in names])

# ---- 대권거리 행렬 (km) ----
a = (np.sin((lat[:, None] - lat) / 2) ** 2
     + np.cos(lat[:, None]) * np.cos(lat) * np.sin((lon[:, None] - lon) / 2) ** 2)
D = 2 * 6371 * np.arcsin(np.sqrt(a))

# ---- 고전 MDS 직접 구현 ----
n = len(D)
J = np.eye(n) - np.ones((n, n)) / n
B = -0.5 * J @ (D ** 2) @ J
vals, vecs = np.linalg.eigh(B)
idx = np.argsort(vals)[::-1]
vals, vecs = vals[idx], vecs[:, idx]
Y = vecs[:, :2] * np.sqrt(vals[:2])
print("B 고유값 (상위 4):", vals[:4].round(1))

D_hat = np.linalg.norm(Y[:, None] - Y[None], axis=2)
stress = np.sqrt(((D - D_hat) ** 2).sum() / (D ** 2).sum())
print(f"Stress-1 = {stress:.5f}")
for c, (x, y) in zip(names, Y):
    print(f"  {c}: ({x:7.1f}, {y:7.1f})")

# ---- scikit-learn: 미리 계산한 거리로 SMACOF ----
mds = MDS(n_components=2, dissimilarity="precomputed", random_state=0, n_init=4)
Y2 = mds.fit_transform(D)
D2 = np.linalg.norm(Y2[:, None] - Y2[None], axis=2)
print(f"sklearn MDS Stress-1 = {np.sqrt(((D - D2) ** 2).sum() / (D ** 2).sum()):.5f}")

대응분석 (Correspondence Analysis)

대응분석은 범주형 변수 두 개의 교차표를 저차원 지도로 바꿉니다. 행 범주와 열 범주를 같은 평면에 찍어, 어떤 행과 어떤 열이 서로 "끌리는지"를 한눈에 보여 줍니다. PCA를 범주형 자료에 맞게 바꾼 것으로 볼 수 있습니다.

예제 · 연령대별 선호 여가활동 (설명용 가상 교차표, n = 650)

연령대게임운동여행독서TV
20대6235281510

핵심 공식

비율 행렬 $P=N/n$, 행 질량 $\mathbf{r}$, 열 질량 $\mathbf{c}$에 대해 표준화 잔차 행렬을 SVD합니다.

$$S=D_r^{-1/2}\big(P-\mathbf{r}\mathbf{c}^\top\big)D_c^{-1/2}=U\Sigma V^\top$$ $$\text{행 좌표 }F=D_r^{-1/2}U\Sigma,\qquad \text{열 좌표 }G=D_c^{-1/2}V\Sigma,\qquad \text{총 관성}=\sum_k\sigma_k^2=\frac{\chi^2}{n}$$

$S$의 원소 제곱합은 독립성 검정의 $\chi^2$ 통계량을 $n$으로 나눈 값입니다. 즉 대응분석은 "독립에서 벗어난 정도"를 분해해 그림으로 보여 줍니다.

이 표의 $\chi^2=118.87$ 이고 총 관성은 $118.87/650=0.1829$ 입니다. 첫 번째 차원이 관성의 92.0%, 두 번째 차원이 7.8%를 설명하므로 2차원 지도로 거의 모든 연관 구조를 볼 수 있습니다.

확장입력사용처
단순 대응분석 (CA)범주형 2개 교차표브랜드 × 이미지 속성, 지역 × 선호 상품
다중 대응분석 (MCA)범주형 3개 이상 (지시 행렬)설문 전체 응답 패턴 지도
FAMD연속형 + 범주형 혼합고객 프로파일링
ch7_correspondence.py
import numpy as np
from scipy.stats import chi2_contingency

rows = ["20대", "30대", "40대", "50대+"]
cols = ["게임", "운동", "여행", "독서", "TV"]
N = np.array([[62, 35, 28, 15, 10],
              [38, 45, 40, 20, 17],
              [20, 40, 45, 30, 35],
              [ 8, 30, 35, 38, 59]], dtype=float)

n = N.sum()
P = N / n
r, c = P.sum(1), P.sum(0)                                  # 행·열 질량
S = (P - np.outer(r, c)) / np.sqrt(np.outer(r, c))         # 표준화 잔차
U, s, Vt = np.linalg.svd(S, full_matrices=False)

inertia = s ** 2
chi2 = chi2_contingency(N)[0]
print(f"χ² = {chi2:.2f} | χ²/n = {chi2 / n:.4f} | 총 관성 Σσ² = {inertia.sum():.4f}")
print("차원별 관성 비율:", (inertia / inertia.sum()).round(4))

F = U * s / np.sqrt(r)[:, None]                            # 행 주좌표
G = Vt.T * s / np.sqrt(c)[:, None]                         # 열 주좌표
if F[0, 0] > 0:                                         # SVD 부호는 임의 → 20대가 왼쪽이 되도록
    F[:, 0] *= -1; G[:, 0] *= -1
for name, (d1, d2) in zip(rows, F[:, :2]):
    print(f"행 {name:4s}: 차원1 {d1:+.3f}  차원2 {d2:+.3f}")
for name, (d1, d2) in zip(cols, G[:, :2]):
    print(f"열 {name:4s}: 차원1 {d1:+.3f}  차원2 {d2:+.3f}")

비선형 차원축소

선형 기법은 데이터를 평평한 평면(초평면)에 사영합니다. 데이터가 동심원, 말린 종이(Swiss roll), 숫자 이미지처럼 휘어진 구조에 놓여 있으면 선형 사영은 서로 다른 그룹을 겹쳐 버립니다. 비선형 기법은 이 휘어진 매니폴드를 펼칩니다.

8.1Kernel PCA

데이터를 고차원 특성공간 $\phi(\mathbf{x})$로 보낸 뒤 그곳에서 PCA를 합니다. $\phi$를 직접 계산하지 않고 내적 $k(\mathbf{x}_i,\mathbf{x}_j)=\phi(\mathbf{x}_i)^\top\phi(\mathbf{x}_j)$만 쓰는 커널 트릭을 사용합니다.

$$K_{ij}=k(\mathbf{x}_i,\mathbf{x}_j),\qquad \tilde K=K-\mathbf{1}_nK-K\mathbf{1}_n+\mathbf{1}_nK\mathbf{1}_n,\qquad \tilde K\boldsymbol\alpha=n\lambda\boldsymbol\alpha$$
커널수식특징
선형$\mathbf{x}^\top\mathbf{y}$일반 PCA와 같음
다항$(\gamma\,\mathbf{x}^\top\mathbf{y}+c)^d$변수 간 $d$차 상호작용
RBF (가우시안)$\exp(-\gamma\|\mathbf{x}-\mathbf{y}\|^2)$가장 많이 사용. $\gamma$가 크면 국소적

8.2t-SNE

t-SNE는 고차원에서 가까운 점은 저차원에서도 가깝게 두는 데 집중하는 시각화 전용 기법입니다. 점 사이의 유사도를 확률분포로 바꾸고, 두 분포의 KL 발산을 최소화합니다.

핵심 공식 $$p_{j\mid i}=\frac{\exp(-\|\mathbf{x}_i-\mathbf{x}_j\|^2/2\sigma_i^2)}{\sum_{k\ne i}\exp(-\|\mathbf{x}_i-\mathbf{x}_k\|^2/2\sigma_i^2)},\qquad p_{ij}=\frac{p_{j\mid i}+p_{i\mid j}}{2n}$$ $$q_{ij}=\frac{(1+\|\mathbf{y}_i-\mathbf{y}_j\|^2)^{-1}}{\sum_{k\ne l}(1+\|\mathbf{y}_k-\mathbf{y}_l\|^2)^{-1}},\qquad C=D_{\text{KL}}(P\,\|\,Q)=\sum_{i\ne j}p_{ij}\log\frac{p_{ij}}{q_{ij}}$$
  • $\sigma_i$는 perplexity $=2^{H(P_i)}$가 지정값(보통 5~50)이 되도록 점마다 정합니다. "유효한 이웃 수"로 해석합니다.
  • 저차원에는 꼬리가 두꺼운 t분포(자유도 1)를 써서, 중간 거리의 점들이 한곳에 뭉치는 문제(crowding problem)를 줄입니다.
  • KL 발산은 비대칭이라 $p_{ij}$가 큰(가까운) 쌍을 멀리 두면 벌점이 크고, 먼 쌍을 가깝게 두는 데는 관대합니다 → 국소 구조 보존
t-SNE 해석 시 주의
  • 덩어리 크기와 덩어리 사이 거리는 의미가 없습니다. 국소 이웃만 보존하기 때문입니다.
  • perplexity와 난수 시드에 따라 모양이 크게 바뀝니다. 여러 설정으로 확인하세요.
  • transform이 없어 새 데이터를 같은 공간에 넣을 수 없습니다. 모델 입력용 전처리로는 쓰지 않습니다.
  • 계산량이 $O(n^2)$ (Barnes-Hut 근사 시 $O(n\log n)$)이라, 보통 PCA로 50차원 정도까지 줄인 뒤 적용합니다.

8.3UMAP · Isomap · LLE

기법원리보존 대상장단점
UMAPkNN 그래프를 퍼지 집합으로 보고, 저차원 그래프와의 교차엔트로피 최소화. 가중치 $w_{ij}=\exp\!\big(-(d_{ij}-\rho_i)/\sigma_i\big)$국소 + 어느 정도 전역 구조t-SNE보다 빠르고 전역 배치가 더 의미 있음. transform 지원. 별도 패키지 umap-learn
IsomapkNN 그래프의 최단 경로로 측지선 거리를 근사 → 고전 MDS매니폴드 위 거리 (전역)Swiss roll을 펼치는 데 탁월. 노이즈·구멍에 민감
LLE각 점을 이웃의 선형결합으로 표현하는 가중치 $W$를 찾고, 저차원에서도 같은 $W$를 만족하는 좌표를 고유분해로 구함국소 선형 구조빠름. 이웃 수에 민감, 군집 간 배치는 부정확
스펙트럼 임베딩그래프 라플라시안 $L=D-W$의 작은 고유벡터 사용그래프 연결 구조스펙트럼 군집의 기반

import numpy as np
from sklearn.datasets import make_circles, load_digits, make_swiss_roll
from sklearn.decomposition import PCA, KernelPCA
from sklearn.manifold import TSNE, Isomap, LocallyLinearEmbedding, trustworthiness
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.model_selection import cross_val_score

# ---- 1) Kernel PCA: 동심원 ----
X, y = make_circles(n_samples=400, factor=0.35, noise=0.06, random_state=1)
for name, model in [("PCA", PCA(2)), ("KernelPCA(rbf)", KernelPCA(2, kernel="rbf", gamma=4))]:
    Z = model.fit_transform(X)
    acc = LogisticRegression().fit(Z[:, :1], y).score(Z[:, :1], y)
    print(f"{name:15s} 첫 성분만으로 선형분류 정확도 {acc:.3f}")

# ---- 2) t-SNE vs PCA: 손글씨 숫자 ----
digits = load_digits()
rng = np.random.default_rng(0)
idx = rng.choice(len(digits.data), 900, replace=False)
Xd, yd = digits.data[idx], digits.target[idx]
for name, model in [("PCA", PCA(2)), ("t-SNE", TSNE(2, perplexity=30, init="pca", random_state=0))]:
    Z = model.fit_transform(Xd)
    tw = trustworthiness(Xd, Z, n_neighbors=10)
    acc = cross_val_score(KNeighborsClassifier(5), Z, yd, cv=5).mean()
    print(f"{name:6s} trustworthiness {tw:.3f} | 2D kNN 정확도 {acc:.3f}")

# ---- 3) Swiss roll: 측지선 거리를 보존하는가 ----
Xs, t = make_swiss_roll(n_samples=1000, noise=0.05, random_state=0)   # t = 말린 방향의 실제 좌표
for name, model in [("PCA", PCA(2)), ("Isomap", Isomap(n_neighbors=10, n_components=2)),
                    ("LLE", LocallyLinearEmbedding(n_neighbors=12, n_components=2, random_state=0))]:
    Z = model.fit_transform(Xs)
    r = max(abs(np.corrcoef(Z[:, 0], t)[0, 1]), abs(np.corrcoef(Z[:, 1], t)[0, 1]))
    print(f"{name:6s} 펼친 좌표와 실제 말린 위치 t의 |상관| {r:.3f}")

오토인코더 (Autoencoder)

오토인코더는 입력을 좁은 병목(bottleneck)으로 압축했다가 다시 복원하도록 신경망을 학습합니다. 복원이 잘 되려면 병목의 $z$가 입력의 핵심 정보를 담아야 하므로, $z$가 저차원 표현이 됩니다.

$$\min_{f,g}\;\frac1n\sum_{i=1}^{n}\big\|\mathbf{x}_i-g(f(\mathbf{x}_i))\big\|^2,\qquad \mathbf{z}=f(\mathbf{x})\in\mathbb{R}^k,\;k\ll p$$
PCA와의 관계

활성함수 없이 선형층만 쓰고 MSE로 학습한 오토인코더의 병목 공간은 PCA의 상위 $k$개 주성분이 만드는 공간과 같습니다(축이 직교하거나 분산 순서대로 정렬되지는 않습니다). 비선형 활성함수를 넣으면 PCA로 표현할 수 없는 휘어진 구조까지 압축할 수 있습니다.

변형아이디어쓰임
Denoising AE입력에 노이즈를 넣고 깨끗한 원본을 복원노이즈 제거, 강건한 표현
Sparse AE$z$의 활성에 L1 벌점해석 가능한 특성 (LLM 해석 연구의 SAE)
VAE$z$를 분포로 학습: ELBO $=\mathbb{E}_q[\log p(\mathbf{x}\mid\mathbf{z})]-D_{\text{KL}}(q(\mathbf{z}\mid\mathbf{x})\,\|\,\mathcal{N}(0,I))$생성 모델, 연속적인 잠재공간
Convolutional AE인코더·디코더를 CNN으로이미지 압축·이상탐지
임베딩도 차원축소다

Word2Vec, BERT·LLM 임베딩, CLIP 이미지 임베딩은 모두 수만~수백만 차원의 원-핫 단어나 픽셀을 수백 차원의 밀집 벡터로 바꾸는 학습된 차원축소입니다. 벡터 DB에서는 이 임베딩을 다시 PCA나 Matryoshka 표현(앞쪽 차원만 잘라 써도 되도록 학습)으로 줄여 저장 비용을 낮춥니다.

$$\text{SPE}=\|\mathbf{x}-\hat{\mathbf{x}}\|^2=\|(I-W_kW_k^\top)\mathbf{x}\|^2,\qquad T^2=\sum_{j=1}^{k}\frac{z_j^2}{\lambda_j}$$

import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

rng = np.random.default_rng(21)
T = 300
latent = rng.normal(size=(T, 2))                    # 실제 공정 상태 2개
W = rng.normal(size=(2, 8))
X = latent @ W + rng.normal(0, 0.15, (T, 8))         # 상관된 센서 8개
X[200:, 3] += np.linspace(0, 1.6, 100)               # t=200부터 센서4 드리프트

train = X[:150]                                      # 정상 구간으로만 학습 (누수 방지)
scaler = StandardScaler().fit(train)
pca = PCA(n_components=2).fit(scaler.transform(train))
print("학습 구간 설명분산:", pca.explained_variance_ratio_.sum().round(3))

def spe_t2(Xnew):
    Z = scaler.transform(Xnew)
    scores = pca.transform(Z)
    recon = pca.inverse_transform(scores)
    spe = ((Z - recon) ** 2).sum(axis=1)
    t2 = (scores ** 2 / pca.explained_variance_).sum(axis=1)
    return spe, t2

spe_tr, t2_tr = spe_t2(train)
spe_lim, t2_lim = np.quantile(spe_tr, 0.99), np.quantile(t2_tr, 0.99)
spe, t2 = spe_t2(X)
alarm = spe > spe_lim
print(f"SPE 한계 {spe_lim:.3f} | T² 한계 {t2_lim:.3f}")
print("드리프트 전 경보 수:", alarm[:200].sum(), "/ 200")
print("드리프트 후 경보 수:", alarm[200:].sum(), "/ 100 | 첫 경보 t =", 200 + np.argmax(alarm[200:]))
print("드리프트 후 T² 경보 수:", (t2[200:] > t2_lim).sum(), "← 상관 구조 붕괴는 SPE가 더 잘 잡음")

# 어느 센서가 원인인가: SPE 기여도
Z = scaler.transform(X[260:270])
contrib = ((Z - pca.inverse_transform(pca.transform(Z))) ** 2).mean(axis=0)
print("센서별 SPE 기여도:", contrib.round(3), "→ 최대 기여 센서 =", contrib.argmax() + 1)

import numpy as np
from sklearn.datasets import load_digits
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV, train_test_split

X, y = load_digits(return_X_y=True)                     # 64차원
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)

# 표준화 → PCA → 분류기를 하나로 묶어 교차검증 안에서 fit (누수 방지)
pipe = Pipeline([
    ("scale", StandardScaler()),
    ("pca", PCA(random_state=0)),
    ("clf", LogisticRegression(max_iter=3000)),
])
grid = GridSearchCV(pipe, {"pca__n_components": [5, 10, 20, 30, 40, 64]}, cv=5)
grid.fit(X_tr, y_tr)

for k, score in zip(grid.cv_results_["param_pca__n_components"], grid.cv_results_["mean_test_score"]):
    print(f"성분 {k:2d}개  CV 정확도 {score:.4f}")
# 최고 점수와 1%p 이내인 가장 작은 k를 선택 (간결한 모델 선호)
scores = grid.cv_results_["mean_test_score"]
ks = np.array(grid.cv_results_["param_pca__n_components"], dtype=int)
k_small = ks[scores >= scores.max() - 0.01].min()
final = grid.best_estimator_.set_params(pca__n_components=k_small).fit(X_tr, y_tr)
ratio = final.named_steps["pca"].explained_variance_ratio_.sum()
print(f"최고 CV 성분 수 {grid.best_params_['pca__n_components']} → 1%p 규칙으로 {k_small}개 선택")
print(f"테스트 정확도 {final.score(X_te, y_te):.4f} | 설명분산 {ratio:.3f} | 입력 차원 64 → {k_small}")

항목공식
VIF$1/(1-R_j^2)$, 10 이상이면 다중공선성
AIC / BIC$-2\ln\hat L+2k$ / $-2\ln\hat L+k\ln n$
Lasso$\min\frac{1}{2n}\|\mathbf{y}-X\boldsymbol\beta\|^2+\lambda\|\boldsymbol\beta\|_1$
PCA$\Sigma\mathbf{w}=\lambda\mathbf{w}$, 설명분산비 $\lambda_k/\sum\lambda$, 점수 $Z=XW_k$, 적재값 $w_{jk}\sqrt{\lambda_k}$
SVD ↔ PCA$X=U\Sigma V^\top$, $\lambda_k=\sigma_k^2/(n-1)$, $Z=U\Sigma$
Eckart–Young$\|X-X_k\|_F^2=\sum_{i>k}\sigma_i^2$
요인분석$\Sigma=\Lambda\Lambda^\top+\Psi$, 공통성 $h_j^2=\sum_k\lambda_{jk}^2$
Bartlett$\chi^2=-(n-1-\frac{2p+5}{6})\ln|R|$, df $=p(p-1)/2$
LDA$\max\frac{\mathbf{w}^\top S_B\mathbf{w}}{\mathbf{w}^\top S_W\mathbf{w}}$, 2클래스 $\mathbf{w}\propto S_W^{-1}(\boldsymbol\mu_1-\boldsymbol\mu_0)$
고전 MDS$B=-\frac12JD^{(2)}J$, $X=V_k\Lambda_k^{1/2}$
대응분석$S=D_r^{-1/2}(P-\mathbf{r}\mathbf{c}^\top)D_c^{-1/2}$, 총 관성 $=\chi^2/n$
t-SNE$\min D_{\text{KL}}(P\|Q)$, $q_{ij}\propto(1+\|\mathbf{y}_i-\mathbf{y}_j\|^2)^{-1}$
