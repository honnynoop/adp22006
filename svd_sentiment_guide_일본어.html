01概要とロードマップ

感情分析の結果は多くの場合、「誰が何に対してどれだけポジティブ/ネガティブか」という行列として蓄積されます。SVD はこの行列をいくつかの隠れた軸（潜在因子）に分解し、数十・数百のスコアの背後にある感情の構造を明らかにします。

この学習書の問い
レビュアー12人が5つの項目に −2（非常にネガティブ）～ +2（非常にポジティブ）で感情を示した。この60個の数値の中には何種類の「傾向」が含まれているのか？その傾向とは何で、各レビュアーはどの傾向に属するのか？

02SVD の定義

任意の実数行列 $A \in \mathbb{R}^{m\times n}$ は常に次のように分解されます。正方行列であってもなくても、ランク落ちしていてもいなくても例外がないことが、固有値分解との決定的な違いです。

$$A = U\,\Sigma\,V^{\mathsf T} = \sum_{i=1}^{r}\sigma_i\,\mathbf u_i\,\mathbf v_i^{\mathsf T},\qquad \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0$$

3つの行列はどこから来るのか

$A^{\mathsf T}A$ と $AA^{\mathsf T}$ に SVD を代入するとすぐに分かります。

$$A^{\mathsf T}A = V\Sigma^{\mathsf T}U^{\mathsf T}U\Sigma V^{\mathsf T} = V\,\Sigma^2\,V^{\mathsf T},\qquad AA^{\mathsf T} = U\,\Sigma^2\,U^{\mathsf T}$$
  • $V$ = $A^{\mathsf T}A$（5×5、項目×項目）の固有ベクトル、$U$ = $AA^{\mathsf T}$（12×12、レビュアー×レビュアー）の固有ベクトル
  • $\sigma_i = \sqrt{\lambda_i}$ — 2つの行列が共有する0でない固有値の平方根
  • 実務では小さい方（$A^{\mathsf T}A$、5×5）だけを分解し、$\mathbf u_i = A\mathbf v_i/\sigma_i$ で $U$ を得ます（8章）

必ず覚えておく性質

性質数式感情分析における意味
存在性すべての $A$ に存在レビュアー数 ≠ 項目数でも問題ない
直交性$U^{\mathsf T}U=V^{\mathsf T}V=I$潜在因子同士が重ならない（独立した傾向）
エネルギー保存$\|A\|_F^2=\sum\sigma_i^2$感情の「総量」が因子ごとに分けて格納される
ランクrank$(A)$ = 0でない σ の個数本当に独立した傾向の数
最適近似Eckart–Young の定理上位 k 個の因子が最良の要約（10章）

03幾何学的な意味 — 回転 · 伸縮 · 回転

行列 $A$ をベクトル $\mathbf x$ に掛けることは、3つの操作の合成です。単位円（あらゆる方向の長さ1のベクトル）に $A$ を適用すると楕円になり、その楕円の半軸の長さが特異値です。

感情分析の言葉に翻訳すると
Vᵀ: 5項目のスコアを「潜在傾向軸」の座標に読み替える · Σ: 傾向ごとにどれだけ強く表れるかの重み · U: その傾向を各レビュアーに配分。核心となる等式は $A\mathbf v_i = \sigma_i\mathbf u_i$ — 「項目方向 $\mathbf v_i$ を入れると、レビュアー方向 $\mathbf u_i$ が $\sigma_i$ 倍になって出てくる」。

05Step 1 · $A^{\mathsf T}A$ の計算

$A^{\mathsf T}A$ の $(j,k)$ 要素は、項目 $j$ 列と項目 $k$ 列の内積です。対角要素は各項目の感情の二乗和（エネルギー）、非対角要素は2つの項目が同じ方向に動く度合いです。

$$(A^{\mathsf T}A)_{jk} = \sum_{i=1}^{12} a_{ij}\,a_{ik}$$

手計算 ① 味・味（対角要素）

$$(A^{\mathsf T}A)_{11} = 2^2+2^2+1^2+1^2+1^2+2^2+(-2)^2+(-1)^2+1^2+1^2+(-1)^2+0^2 = 23$$

手計算 ② 味・価格（非対角要素）

$$\begin{aligned}(A^{\mathsf T}A)_{14} &= 2\cdot2+2\cdot1+1\cdot(-2)+1\cdot(-2)+1\cdot2+2\cdot2+(-2)(-2)+(-1)(-1)+1\cdot0+1\cdot1+(-1)(-2)+0\cdot1\\ &= 4+2-2-2+2+4+4+1+0+1+2+0 = 16\end{aligned}$$

手計算 ③ サービス・価格（負になる場合）

$$(A^{\mathsf T}A)_{24} = 4+1-4-4-2-2+4+2+0+1-2-1 = -3$$

06Step 2 · 固有値 → 特異値

$A^{\mathsf T}A\,\mathbf v=\lambda\mathbf v$ を解く必要があります。特性方程式 $\det(A^{\mathsf T}A-\lambda I)=0$ は5次式で解の公式がないため、実際には数値解法を使います。最も直感的な方法がべき乗法（Power Iteration）です。

べき乗法 — 最大の固有値を求める

$$\mathbf x^{(k+1)} = \frac{A^{\mathsf T}A\,\mathbf x^{(k)}}{\|A^{\mathsf T}A\,\mathbf x^{(k)}\|},\qquad \lambda^{(k)} = \mathbf x^{(k)\mathsf T}A^{\mathsf T}A\,\mathbf x^{(k)}\;\;(\text{レイリー商})$$

任意のベクトルに繰り返し掛けると、最大の固有値方向の成分だけが $(\lambda_1/\lambda_2)^k$ の比率で生き残ります。初期値 $\mathbf x^{(0)}=\frac{1}{\sqrt5}(1,1,1,1,1)$。

符号の曖昧さに注意
$\mathbf v_i$ と $\mathbf u_i$ を同時に −1 倍しても $\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T}$ はそのままです。ライブラリによって符号が異なって出ることがあるため、本書では「v₁ の合計が正」「v₂ の価格・量側が正」となるよう統一しました。解釈は符号ではなく成分間の相対的なパターンで行うべきです。

08Step 4 · U の計算 — レビュアー側の潜在因子

$A\mathbf v_i=\sigma_i\mathbf u_i$ なので、$AA^{\mathsf T}$（12×12）を別途分解する必要はありません。

$$\mathbf u_i = \frac{A\,\mathbf v_i}{\sigma_i}$$

09Step 5 · Σ と寄与率

各因子が全体の感情エネルギー $\|A\|_F^2=136$ のうちどれだけを担っているかが寄与率です。

$$\text{寄与率}_i = \frac{\sigma_i^2}{\sum_j\sigma_j^2}:\quad \frac{71.438}{136}=52.5\%,\quad \frac{54.816}{136}=40.3\%,\quad \frac{4.880}{136}=3.6\%,\;2.0\%,\;1.6\%$$
グラフの読み方
棒が2番目以降で急激に下がる「肘（elbow）」が見えます。σ₁・σ₂（8.45, 7.40）は大きく、σ₃~σ₅（2.2~1.5）は同程度に小さい → 本当の構造は2次元で、残りは個人差・測定ノイズ。累積 92.8% なので2因子で十分です。
sklearn と数値が異なる理由
TruncatedSVD.explained_variance_ratio_ は 0.5287, 0.4079 と上記と少し異なります。sklearn は射影された座標の分散（平均を引いた値）の比率を計算し、ここでは原点基準のエネルギー（σ²）の比率を使ったためです。特異値そのもの（8.4521, 7.4038）は完全に一致します。

10Step 6 · 低ランク近似（Truncated SVD）

SVD は行列をランク1の断片の和として表します。上位 $k$ 個だけを残すと最良の要約になります。

$$A_k=\sum_{i=1}^{k}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T},\qquad \min_{\operatorname{rank}(B)\le k}\|A-B\|_F=\|A-A_k\|_F=\sqrt{\sigma_{k+1}^2+\cdots+\sigma_r^2}\quad(\text{Eckart–Young})$$

手計算 — ランク1近似における R01 の「味」

$$(A_1)_{11}=\sigma_1u_{11}v_{11}=8.4521\times0.4366\times0.5025=1.854\quad(\text{元は } 2)$$

手計算 — ランク2近似における R03 の「価格」

$$\begin{aligned}(A_2)_{34}&=\sigma_1u_{31}v_{41}+\sigma_2u_{32}v_{42}\\&=8.4521(-0.0208)(0.5675)+7.4038(-0.4943)(0.3772)\\&=-0.0999-1.3805=-1.480\quad(\text{元は } -2)\end{aligned}$$

因子1だけでは R03 を「中立」（−0.1）としか描けませんが、因子2を加えると「価格にネガティブ」という核心が復元されます。

11バイプロットの解釈 — レビュアーと項目を同じ平面に

レビュアーは $(\sigma_1u_{i1},\sigma_2u_{i2})$ の点として、項目は $(\sigma_1v_{j1},\sigma_2v_{j2})$ の矢印として、同じ2次元潜在空間に描きます。点と矢印の内積がそのまま近似スコアになります: $(A_2)_{ij}\approx$（点の方向）·（矢印の方向）。

グラフを読むルール

  1. 横軸の位置 = 全体的な感情。 右に行くほどこの店全体をポジティブに評価。R01（+3.69）が最も満足、R07（−3.97）が最も不満。
  2. 縦軸の位置 = 何を基準に評価しているか。 上側は価格・量に寛容、下側はサービス・雰囲気に寛容。
  3. 矢印の方向と同じ側にある点はその項目を良く評価。R12 は価格・量の矢印側、サービス・雰囲気の矢印の反対側 → 実際に価格 +1・量 +2、サービス −1・雰囲気 −2。
  4. 矢印同士の角度が狭ければ連動する項目。 価格・量がほぼ重なり、サービス・雰囲気もほぼ重なる。2つのグループは約90° → 互いに独立（5章の AᵀA の −3, −1, 0 と一致）。
  5. 味は2つのグループの間の右側 → 味はどのタイプでも全体的な満足と一緒に動く「基本」項目。
  6. 原点に近い点（R09）は意見が弱いか中立 — セグメント判定での信頼度は低い。

12活用 — 新規レビュー · 類似度 · 欠損予測

① 新規レビュアーを潜在空間に入れる（Fold-in）

新しいレビュー「安くて量も多いです。味はまあまあですが、店員が本当に不親切でした。」→ ABSA の結果 $\mathbf a=(1,-2,0,2,2)$。SVD を再計算する必要はなく、すでに求めた $V_k$ に射影します。

$$\mathbf z=\mathbf a\,V_2=\big(\mathbf a\cdot\mathbf v_1,\;\mathbf a\cdot\mathbf v_2\big)$$ $$\mathbf a\cdot\mathbf v_1=0.5025-0.4624+0+1.1350+1.0932=2.2686,\qquad \mathbf a\cdot\mathbf v_2=-0.1833+1.2118+0+0.7544+0.6522=2.4351$$

座標 (2.269, 2.435) → バイプロットの ★、「満足 · コスパ派」の領域です。

③ 欠けた感情スコアの予測（反復 SVD 補完）

R04 が「価格」について何も言わなかったと仮定し、そのセルを隠してみます（実際の値は −2）。アルゴリズム:

  1. 空欄を残り11人の価格の平均 0.1818 で埋める。
  2. 埋めた行列に SVD → ランク2近似 $A_2$ を計算。
  3. 空欄だけを $A_2$ の該当値に置き換え、2に戻って反復。

0.18 → −0.67 → −1.10 → −1.32 → … → −1.615 に収束。単純平均（+0.18、「中立」）は完全に外れていますが、SVD は「R04 は体験派なので価格にネガティブだろう」という構造を利用して、実際の値（−2）に近く予測します。Netflix Prize で有名になった行列分解による推薦の原理がまさにこれです。

13テキスト感情分析への拡張 — LSA

ここまではすでに作られた感情スコア行列を分解しました。原文テキストに直接 SVD を使う古典的な方法が潜在意味解析（LSA, Latent Semantic Analysis）です。

項目本書（感情スコア行列）LSA（文書-単語行列）
行列レビュアー × 項目、値 = 感情スコア文書 × 単語、値 = TF-IDF
V が表すもの項目がまとまる感情の傾向一緒に出現する単語のまとまり（トピック・感情語）
U·Σ が表すものレビュアーの傾向座標文書の意味座標 → 分類器の入力
長所解釈が容易同義語問題を緩和（「不親切」・「無礼」が近づく）、疎→密
限界スコア化段階の品質に依存語順・否定語（「おいしくない」）の扱いが弱い → 現在は BERT 埋め込みが主流
from sklearn.pipeline import make_pipeline
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.decomposition import TruncatedSVD
from sklearn.linear_model import LogisticRegression

# texts: レビュー文字列のリスト、labels: 1=ポジティブ、0=ネガティブ
model = make_pipeline(TfidfVectorizer(), TruncatedSVD(n_components=100), LogisticRegression())
model.fit(texts, labels)
実務上の注意点
① 疎行列には np.linalg.svd ではなく TruncatedSVD（ランダム化/ARPACK）を — 完全分解はメモリが爆発する。② 平均の中心化を行うと PCA になり、行わないと第1因子が「全体的な水準」になる（本書のように）。③ 項目ごとに尺度が異なる場合は標準化してから分解。④ 符号は任意なので、解釈前に統一する。

感情・意見分析ユーザー × 属性の感情スコア感情傾向の軸を発見、顧客セグメント本書、ブランドレビュー分析

共通点をひとことで
すべての用途は結局「大きな行列の中の重要な方向（大きい σ）と重要でない方向（小さい σ）を分離する」というひとつのアイデアから生まれます。大きい σ を残せば圧縮・要約・推薦、小さい σ を捨てればノイズ除去、小さい σ を慎重に扱えば安定した逆行列になります。

svd_sentiment.py
import numpy as np
from sklearn.decomposition import TruncatedSVD

np.set_printoptions(precision=4, suppress=True)

# ── 1. 感情スコア行列（12人 × 5項目、-2=非常にネガティブ ~ +2=非常にポジティブ）
items = ["味", "サービス", "雰囲気", "価格", "量"]
A = np.array([
    [ 2,  2,  2,  2,  1],   # R01
    [ 2,  1,  2,  1,  1],   # R02
    [ 1,  2,  2, -2, -1],   # R03
    [ 1,  2,  1, -2, -2],   # R04
    [ 1, -1, -1,  2,  2],   # R05
    [ 2, -1,  0,  2,  2],   # R06
    [-2, -2, -1, -2, -2],   # R07
    [-1, -2, -2, -1, -2],   # R08
    [ 1,  0,  1,  0,  0],   # R09
    [ 1,  1,  1,  1,  1],   # R10
    [-1,  1,  1, -2, -1],   # R11
    [ 0, -1, -2,  1,  2],   # R12
], dtype=float)

# ── 2. 直接導出: AᵀA の固有値分解 → σ = √λ, V
AtA = A.T @ A
lam, V = np.linalg.eigh(AtA)
order = np.argsort(lam)[::-1]
lam, V = lam[order], V[:, order]
sigma = np.sqrt(lam)
print("AᵀA =\n", AtA)
print("固有値 λ =", lam)
print("特異値 σ =", sigma)
print("trace(AᵀA) =", np.trace(AtA), " ‖A‖_F² =", (A**2).sum())

# ── 3. numpy SVD（符号統一: v1 は合計が正、v2 は価格・量側が正）
U, s, Vt = np.linalg.svd(A, full_matrices=False)
if Vt[0].sum() < 0:
    Vt[0] *= -1; U[:, 0] *= -1
if Vt[1, 3] + Vt[1, 4] - Vt[1, 1] - Vt[1, 2] < 0:
    Vt[1] *= -1; U[:, 1] *= -1
print("\nnp.linalg.svd σ =", s)
print("v1 =", Vt[0])
print("v2 =", Vt[1])
energy = s**2 / (s**2).sum()
print("寄与率 =", energy, " 累積 =", np.cumsum(energy))

# ── 4. 低ランク近似と Eckart–Young 誤差
for k in range(1, 6):
    Ak = U[:, :k] @ np.diag(s[:k]) @ Vt[:k]
    print(f"k={k}  ‖A-A_k‖_F = {np.linalg.norm(A - Ak):.4f}"
          f"  √(Σ捨てたσ²) = {np.sqrt((s[k:]**2).sum()):.4f}")

# ── 5. レビュアーの潜在座標（σ·u）
US = U[:, :2] * s[:2]
for i, row in enumerate(US):
    print(f"R{i+1:02d}  因子1(全体感情)={row[0]:+.3f}  因子2(コスパ↔体験)={row[1]:+.3f}")

# ── 6. 新規レビュアーの fold-in:「安くて量も多いが店員が不親切」
new = np.array([1, -2, 0, 2, 2], dtype=float)
z = new @ Vt[:2].T                       # 潜在座標 = a·V_k
cos = US @ z / (np.linalg.norm(US, axis=1) * np.linalg.norm(z))
best = np.argsort(-cos)[:3]
print("\n新規レビュアーの潜在座標 =", z)
print("最も似ているレビュアー =", [(f"R{i+1:02d}", round(cos[i], 4)) for i in best])

# ── 7. 欠損補完: R04 の「価格」を隠し、反復SVD(k=2)で推定
X = A.copy()
X[3, 3] = np.delete(A[:, 3], 3).mean()
for _ in range(30):
    u, ss, vt = np.linalg.svd(X, full_matrices=False)
    X[3, 3] = (u[:, :2] @ np.diag(ss[:2]) @ vt[:2])[3, 3]
print(f"R04「価格」推定 = {X[3, 3]:.4f}  (実際 -2, 単純平均 {np.delete(A[:, 3], 3).mean():.4f})")

# ── 8. scikit-learn TruncatedSVD によるクロスチェック
tsvd = TruncatedSVD(n_components=2, algorithm="arpack").fit(A)
print("\nsklearn singular_values_ =", tsvd.singular_values_)
print("sklearn explained_variance_ratio_ =", tsvd.explained_variance_ratio_)

16チェックリスト · 確認問題

重要チェックリスト

  • $A=U\Sigma V^{\mathsf T}$ における U・Σ・V のサイズと意味（レビュアー/強さ/項目）を説明できる
  • $V$ は $A^{\mathsf T}A$ の固有ベクトル、$\sigma=\sqrt\lambda$、$\mathbf u_i=A\mathbf v_i/\sigma_i$ を導出できる
  • $\sum\sigma_i^2=\|A\|_F^2=\operatorname{tr}(A^{\mathsf T}A)$ で計算を検証できる
  • 5次以上ではべき乗法のような数値解法が必要であり、収束速度が $\lambda_2/\lambda_1$ に依存することを知っている
  • 負荷量（V）の符号パターンから因子に名前を付けられる（全体 vs 対比）
  • スクリープロットの肘と累積寄与率で k を決められる
  • Eckart–Young: ランク k 近似の誤差 $=\sqrt{\sum_{i>k}\sigma_i^2}$
  • バイプロットで点–矢印の方向、矢印間の角度を解釈できる
  • Fold-in（$\mathbf aV_k$）、コサイン類似度、反復 SVD 補完を説明できる
  • SVD の符号の曖昧さと、中心化の有無（SVD vs PCA）の違いを知っている

確認問題

このデータで rank(A) はいくつで、その根拠は？
5。特異値5個（8.452, 7.404, 2.209, 1.658, 1.456）がすべて0でないため。ただし「実質的な」ランクは σ が急減する手前までの2とみなします。
k=1 だけを残すと R03 と R04 の「価格への不満」が消えるのはなぜ？
ランク1近似ではすべての行が v₁（すべて正）の倍数です。あるレビュアーがある項目は +、ある項目は − というパターンを表現できません。その対比を担う v₂ があって初めて復元されます。
σ₁=8.4521 のとき、v₁ 方向だけを残した近似のフロベニウス誤差は？
$\sqrt{136-71.4376}=\sqrt{64.5624}=8.035$。全エネルギーから最初の σ² を引いて平方根を取る。
新しいレビュー a = (−1, 2, 2, −2, −1) の潜在座標と予想されるセグメントは？
a·v₁ = −0.5025+0.4624+0.5408−1.1350−0.5466 = −1.181、a·v₂ = 0.1833−1.2118−1.1842−0.7544−0.3261 = −3.293。左下 →「価格不満 · 体験派」（R03・R04・R11 と同じグループ）。
本書のように平均を引かずに SVD を行うと、PCA と何が変わる？
平均を引かないと、第1因子は原点からデータ中心への方向、すなわち「全体的な感情の水準」を捉えます。列平均を引くと（PCA）この水準が取り除かれ、項目間の相対的な差だけが残ります。感情スコアのように0が意味のある中立点である場合は、中心化しない方が解釈に有利です。
