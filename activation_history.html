활성화 함수의 역사
— 계단함수에서 SwiGLU까지 80년

신경망은 활성화 함수가 바뀔 때마다 한 단계씩 도약했습니다. 미분할 수 없던 계단함수는 역전파를 위해 시그모이드에 자리를 내줬고, 시그모이드의 기울기 소실은 ReLU가 해결하며 딥러닝 시대를 열었으며, 오늘날 LLM은 GELU·SwiGLU를 씁니다. 이 학습서는 각 함수가 어떤 문제를 풀기 위해 등장했고, 어떤 새 문제를 남겼는지를 따라갑니다.

CHAPTER 01활성화 함수란 무엇이고 왜 필요한가

뉴런은 입력의 가중합 \(z=\mathbf w^\top\mathbf x+b\)를 계산한 뒤, 이를 활성화 함수 \(f\)에 통과시켜 출력 \(a=f(z)\)를 냅니다. 활성화 함수는 "이 뉴런이 얼마나 켜질 것인가"를 결정하는 스위치이자, 신경망에 비선형성을 불어넣는 유일한 장치입니다.

비선형이 없으면 층을 쌓는 의미가 없다

활성화 함수가 항등함수(선형)라면 2층 망은

\[ \mathbf y = W_2(W_1\mathbf x+\mathbf b_1)+\mathbf b_2 = \underbrace{(W_2W_1)}_{W'}\mathbf x+\underbrace{(W_2\mathbf b_1+\mathbf b_2)}_{\mathbf b'} \]

로 단일 선형층과 똑같아집니다. 100층을 쌓아도 마찬가지입니다. 비선형 활성화가 있어야 망이 곡선 경계, 즉 XOR 같은 문제를 표현할 수 있고, 보편 근사 정리(Cybenko 1989, Hornik 1991)가 보장하는 "충분히 넓은 망은 어떤 연속함수든 근사한다"는 성질이 성립합니다.

좋은 활성화 함수의 조건 — 역사가 하나씩 발견한 것들

조건이유이 조건을 깨달은 계기
미분 가능 (거의 모든 곳)역전파로 기울기를 전달해야 함계단함수 → 시그모이드 (1986)
0 중심 출력다음 층 가중치 갱신이 한쪽으로 쏠리지 않음시그모이드 → tanh (LeCun 1998)
포화하지 않음 (기울기 ≈ 1 유지)깊은 망에서 기울기 소실 방지tanh → ReLU (2010~2012)
음수 영역에서도 기울기 존재죽은 뉴런(dead neuron) 방지ReLU → Leaky/ELU (2013~2015)
계산 비용이 낮음수십억 번 호출됨ReLU의 max(0,x)가 오래 살아남은 이유
매끄러움 (smooth)최적화 지형이 부드러워짐ReLU → GELU/SiLU (2016~2017)

CHAPTER 031막 · 계단함수 시대 (1943~1969)

ERA 1 · ALL OR NOTHING

계단함수 (Heaviside Step)

McCulloch & Pitts, 1943 · Rosenblatt, 1958
\[ f(z)=\begin{cases}1 & z\ge\theta\\0 & z<\theta\end{cases} \]

＋ 생물학적 뉴런의 "발화/비발화"(all-or-none)를 그대로 모델링. 논리게이트 AND·OR·NOT 구현 가능
－ 도함수가 거의 모든 곳에서 0, \(z=\theta\)에서 정의되지 않음 → 기울기 기반 학습 불가

McCulloch & Pitts (1943)는 뉴런을 임계값을 넘으면 1을 내는 논리소자로 모델링했습니다. 학습 규칙은 없었습니다. Rosenblatt (1958)의 퍼셉트론은 여기에 학습 규칙 \(w\leftarrow w+\eta(y-\hat y)x\)을 더했습니다. 출력이 틀렸을 때만 가중치를 고치는 이 규칙은 단층에서는 잘 작동하지만, 은닉층 뉴런이 "얼마나 틀렸는지"를 계단함수로는 전달할 방법이 없었습니다.

Widrow & Hoff (1960)의 ADALINE은 학습 시에는 계단 이전의 선형 출력 \(z\)로 오차를 계산(LMS, 델타 규칙)했습니다. 미분 가능한 신호로 학습한다는 아이디어의 시초입니다.

1969년, 첫 번째 AI 겨울
Minsky & Papert의 『Perceptrons』는 단층 퍼셉트론이 XOR을 풀 수 없음을 증명했습니다. 다층으로 쌓으면 풀 수 있다는 건 알려져 있었지만, 계단함수로는 다층망을 학습시킬 방법이 없었습니다. 이 "학습 불가능성"이 연구 침체로 이어졌습니다.

CHAPTER 042막 · S자 곡선 시대 (1986~2009)

ERA 2 · DIFFERENTIABLE

해결책은 계단을 매끄럽게 깎는 것이었습니다. 모양은 계단과 비슷하되 모든 곳에서 미분 가능한 S자 곡선을 쓰면 연쇄법칙으로 기울기를 은닉층까지 보낼 수 있습니다.

Sigmoid (로지스틱 함수)

함수 자체: Verhulst, 1838 (인구성장 모델) · 신경망 학습: Rumelhart, Hinton & Williams, 1986
\[ \sigma(z)=\frac{1}{1+e^{-z}},\qquad \sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)\le 0.25 \]

＋ 출력이 (0,1) → 확률 해석 가능. 도함수를 자기 자신으로 표현해 계산이 쉬움
－ 도함수 최댓값이 0.25 → 층마다 기울기가 최소 1/4로 줄어듦. 출력이 항상 양수(0 중심 아님). exp 연산 비용

1986년 Nature에 실린 역전파 논문은 이 로지스틱 함수를 썼고, 마침내 XOR을 은닉층으로 푸는 다층망 학습이 가능해졌습니다. 신경망 연구의 부흥기입니다.

tanh (쌍곡탄젠트)

LeCun 외 「Efficient BackProp」, 1998에서 권장
\[ \tanh(z)=\frac{e^z-e^{-z}}{e^z+e^{-z}}=2\sigma(2z)-1,\qquad \tanh'(z)=1-\tanh^2(z)\le 1 \]

＋ 출력 (−1,1)로 0 중심. 원점 기울기가 1로 sigmoid의 4배
－ 여전히 |z|가 커지면 포화(기울기 → 0)

0 중심이 왜 중요한가

다음 층 가중치의 기울기는 \(\partial L/\partial w_i=\delta\cdot a_i\)입니다. sigmoid 출력 \(a_i\)가 모두 양수면, 한 뉴런으로 들어오는 모든 가중치의 기울기 부호가 \(\delta\)의 부호로 똑같아집니다. 그러면 가중치들이 "모두 증가" 또는 "모두 감소"로만 움직일 수 있어 최적점까지 지그재그로 돌아가야 합니다. tanh는 출력이 양·음 섞여 이 문제가 완화됩니다. LeCun은 \(1.7159\tanh(\tfrac23 z)\) 형태를 권장했습니다(출력 분산 ≈ 1 유지).

지금도 살아있는 S자 곡선
은닉층에서는 밀려났지만 LSTM(Hochreiter & Schmidhuber, 1997)의 게이트는 sigmoid(0~1 개폐율)와 tanh(셀 후보값)를 그대로 씁니다. "얼마나 통과시킬까"라는 비율이 필요한 곳에서는 여전히 최적입니다.

CHAPTER 05기울기 소실 문제 — 2막을 끝낸 위기

역전파에서 \(L\)층 망의 1층 기울기는 각 층의 활성화 도함수를 모두 곱한 항을 포함합니다.

\[ \frac{\partial L}{\partial W^{(1)}}\ \propto\ \prod_{l=1}^{L} f'\big(z^{(l)}\big)\,W^{(l+1)} \qquad\text{sigmoid: } f'\le 0.25 \Rightarrow 0.25^{10}\approx 9.5\times10^{-7} \]

Hochreiter (1991)의 학위논문이 이 현상을 처음 체계적으로 분석했고, Bengio 외(1994)가 RNN에서 장기 의존성 학습이 어려운 이유로 정리했습니다. 결과적으로 2000년대 초반까지 "깊은 망은 학습이 안 된다"는 통념이 지배했고, SVM 같은 커널 방법이 주류가 됩니다.

CHAPTER 063막 · ReLU 혁명 (2010~2012)

ERA 3 · RECTIFIED

ReLU (Rectified Linear Unit)

Fukushima 1969(아이디어) · Hahnloser 외 2000 · Nair & Hinton 2010 · Glorot, Bordes & Bengio 2011 · Krizhevsky 외 2012
\[ \mathrm{ReLU}(z)=\max(0,z),\qquad \mathrm{ReLU}'(z)=\begin{cases}1&z>0\\0&z<0\end{cases} \]

＋ 양수 영역 기울기가 정확히 1 → 깊이에 따른 감쇠 없음. 비교 연산 하나로 매우 빠름. 약 절반이 0 → 희소 표현
－ 음수 입력의 기울기가 0 → 한 번 음수에 갇힌 뉴런은 영원히 죽음(Dying ReLU). 0 중심 아님. z=0에서 미분 불가(실무상 0으로 처리)

ReLU가 주류가 되기까지

연도연구기여
1969Fukushima — 시각 특징 추출 다층망정류(rectification) 형태의 뉴런을 최초로 사용
2000Hahnloser 외 (Nature) — 피질 모방 실리콘 회로정류 뉴런의 생물학적·수학적 근거 제시
2010Nair & Hinton (ICML) — RBM에 ReLU 적용이진 유닛보다 우수함을 보임, "ReLU" 명칭 대중화
2011Glorot, Bordes & Bengio (AISTATS) — Deep Sparse Rectifier Networks비지도 사전학습 없이도 깊은 망 학습 가능함을 입증
2012Krizhevsky, Sutskever & Hinton — AlexNetCIFAR-10에서 tanh 대비 약 6배 빠르게 목표 오차 도달. ImageNet 압승으로 딥러닝 시대 개막
왜 이렇게 단순한 함수가 혁명이었나
2006년 Hinton의 DBN 이후에도 깊은 망은 "층별 비지도 사전학습"이라는 복잡한 우회로가 필요했습니다. ReLU는 기울기를 그대로 통과시키는 것만으로 이 우회로를 불필요하게 만들었습니다. 같은 시기의 GPU, 대규모 데이터(ImageNet), Dropout, He 초기화와 결합해 현대 딥러닝의 기본 레시피가 되었습니다.

Softplus — ReLU의 매끄러운 사촌

Dugas 외, 2001
\[ \mathrm{softplus}(z)=\ln(1+e^z),\qquad \mathrm{softplus}'(z)=\sigma(z) \]

＋ 모든 곳에서 미분 가능, 도함수가 정확히 sigmoid
－ 실험적으로 ReLU보다 낫지 않고 느림 → 은닉층보다는 "양수 출력이 필요한 곳"(분산 예측 등)에 사용

CHAPTER 07ReLU의 후예들 — 죽은 뉴런을 살려라 (2013~2017)

ReLU의 가장 큰 약점은 Dying ReLU입니다. 큰 학습률이나 큰 음의 편향으로 어떤 뉴런의 입력이 모든 샘플에서 음수가 되면 기울기가 0이 되어 다시는 갱신되지 않습니다. 후속 연구들은 하나같이 음수 영역에 작은 기울기를 주는 방법을 고민했습니다.

Leaky ReLU

Maas, Hannun & Ng, 2013 (음성인식)
\[ f(z)=\begin{cases}z&z\ge0\\ \alpha z&z<0\end{cases},\quad \alpha=0.01 \]

＋ 음수에서도 기울기 α → 뉴런이 죽지 않음
－ α가 하이퍼파라미터, 성능 향상은 데이터에 따라 미미

PReLU (Parametric ReLU)

He, Zhang, Ren & Sun, 2015 「Delving Deep into Rectifiers」
\[ f(z)=\max(0,z)+a\min(0,z),\quad a \text{는 학습되는 파라미터} \]

＋ 기울기 a를 데이터로부터 학습. 같은 논문에서 He 초기화도 제안, ImageNet top-5 오류 4.94%로 보고된 인간 수준(5.1%)을 처음 넘음
－ 작은 데이터에서 과적합 가능

ELU (Exponential Linear Unit)

Clevert, Unterthiner & Hochreiter, 2015
\[ f(z)=\begin{cases}z&z>0\\ \alpha(e^z-1)&z\le0\end{cases} \]

＋ 음수 출력이 −α로 부드럽게 포화 → 평균 출력이 0에 가까워짐(0 중심 효과), 잡음에 강건
－ exp 연산으로 ReLU보다 느림

SELU (Scaled ELU)

Klambauer, Unterthiner, Mayr & Hochreiter, 2017 「Self-Normalizing Neural Networks」
\[ f(z)=\lambda\begin{cases}z&z>0\\ \alpha(e^z-1)&z\le0\end{cases},\quad \lambda\approx1.0507,\ \alpha\approx1.6733 \]

＋ 특정 λ, α에서 활성값이 층을 지나며 평균 0·분산 1로 스스로 수렴(BatchNorm 없이 정규화)
－ LeCun 정규 초기화 + 완전연결망 + AlphaDropout 등 조건이 까다로움

Maxout (Goodfellow 외, 2013)
\(f(\mathbf x)=\max_k(\mathbf w_k^\top\mathbf x+b_k)\). 정해진 모양 없이 여러 선형함수의 최댓값을 학습해 볼록 함수를 근사합니다. ReLU와 Leaky ReLU를 특수한 경우로 포함하지만, 파라미터가 k배로 늘어 널리 쓰이지는 않았습니다.

CHAPTER 084막 · 부드러운 게이트 시대 (2016~2019)

ERA 4 · SMOOTH & NON-MONOTONIC

새로운 발상은 "입력에 0~1 사이의 게이트 확률을 곱한다"는 것입니다. ReLU는 \(x\cdot\mathbb 1[x>0]\), 즉 입력을 0 또는 1로 딱 끊어 곱하는 함수로 볼 수 있습니다. 이 하드 게이트를 부드러운 확률로 바꾸면 GELU와 SiLU가 나옵니다.

GELU (Gaussian Error Linear Unit)

Hendrycks & Gimpel, 2016 · BERT(2018), GPT-2/3, ViT가 채택
\[ \mathrm{GELU}(x)=x\,\Phi(x)\approx 0.5x\Big(1+\tanh\big[\sqrt{2/\pi}\,(x+0.044715x^3)\big]\Big) \]

＋ 입력이 클수록 통과 확률이 높은 확률적 게이트(\(\Phi\)=표준정규 CDF). 매끄럽고, 작은 음수를 살짝 허용하는 비단조 곡선
－ 정확한 계산은 erf가 필요(근사식 사용). ReLU보다 느림

SiLU / Swish

SiLU: Hendrycks & Gimpel 2016, Elfwing 외 2017 · Swish: Ramachandran, Zoph & Le 2017 (자동 탐색으로 발견)
\[ \mathrm{SiLU}(x)=x\,\sigma(x),\qquad \mathrm{Swish}_\beta(x)=x\,\sigma(\beta x) \]

＋ GELU와 거의 같은 모양에 계산은 더 단순. β→∞이면 ReLU, β=0이면 x/2가 되는 ReLU와 선형 사이의 보간
－ 음수 영역 최솟값 ≈ −0.278 (x≈−1.28)

Swish는 Google Brain이 강화학습 기반 탐색으로 수많은 수식 조합을 시험해 "발견"한 함수입니다. 결과가 이미 제안되었던 SiLU와 같다는 사실이 밝혀져 오늘날 PyTorch에는 nn.SiLU라는 이름으로 들어 있습니다. EfficientNet, 그리고 5막의 SwiGLU 안에서 사용됩니다.

Mish

Misra, 2019 · YOLOv4가 채택
\[ \mathrm{Mish}(x)=x\tanh\big(\mathrm{softplus}(x)\big) \]

＋ Swish와 비슷하지만 더 매끄러운 곡률, 일부 비전 과제에서 소폭 향상
－ exp·log·tanh 조합으로 연산 비용이 큼

왜 '비단조(non-monotonic)'가 도움이 되나
작은 음수 입력에 대해 출력이 살짝 음수로 내려갔다 0으로 돌아오는 "움푹 파인 곳"이 있습니다. 이 영역에서 기울기가 0이 아니므로 죽은 뉴런이 없고, 곡선이 매끄러워 손실 지형도 부드러워집니다. 대규모 Transformer에서 ReLU 대비 일관된 소폭 향상이 보고되며 표준이 되었습니다.

CHAPTER 095막 · GLU 계열과 LLM (2016~현재)

ERA 5 · LEARNED GATES

4막의 게이트는 입력 자기 자신으로 게이트를 만들었습니다(\(x\cdot\sigma(x)\)). 5막은 게이트를 별도의 선형 변환으로 학습합니다.

\[ \mathrm{GLU}(\mathbf x)=(\mathbf xW+\mathbf b)\ \odot\ \sigma(\mathbf xV+\mathbf c) \qquad\text{(Dauphin 외, 2016 — 게이트 합성곱 언어모델)} \]

Shazeer (2020) 「GLU Variants Improve Transformer」는 Transformer의 FFN에서 게이트 쪽 활성화를 바꾼 변종들을 비교했습니다.

변종수식 (게이트 부분)채택 모델
GLU\(\sigma(\mathbf xW)\odot\mathbf xV\)게이트 CNN 언어모델
ReGLU\(\mathrm{ReLU}(\mathbf xW)\odot\mathbf xV\)—
GeGLU\(\mathrm{GELU}(\mathbf xW)\odot\mathbf xV\)T5 v1.1, Gemma
SwiGLU\(\mathrm{SiLU}(\mathbf xW)\odot\mathbf xV\)PaLM(2022), LLaMA(2023)과 그 후속 다수 오픈 LLM
그림 2. 활성화 함수가 "고정된 곡선"에서 "학습되는 게이트 블록"으로 진화
5막의 의미
활성화 함수의 역사는 "어떤 곡선을 쓸까"에서 "무엇을 얼마나 통과시킬지를 망이 스스로 배우게 하자"로 이동했습니다. LSTM 게이트(1997)에서 시작된 게이팅 아이디어가 Transformer의 FFN까지 들어온 셈입니다. 왜 이것이 잘 되는지에 대해 Shazeer는 논문에서 이론적 설명 없이 "신의 은총(divine benevolence) 덕분"이라고 농담처럼 적었는데, 지금도 완전히 해명된 것은 아닙니다.

import torch, torch.nn as nn
torch.manual_seed(0)
def grad_norms(act, depth=20, width=64):
    layers = []
    for _ in range(depth):
        lin = nn.Linear(width, width)
        if isinstance(act, nn.ReLU):
            nn.init.kaiming_normal_(lin.weight, nonlinearity="relu")
        else:
            nn.init.xavier_normal_(lin.weight)
        nn.init.zeros_(lin.bias)
        layers += [lin, act]
    net = nn.Sequential(*layers)
    x = torch.randn(256, width)
    net(x).pow(2).mean().backward()
    lins = [m for m in net if isinstance(m, nn.Linear)]
    return lins[0].weight.grad.norm().item(), lins[-1].weight.grad.norm().item()
for name, act in [("Sigmoid", nn.Sigmoid()), ("Tanh", nn.Tanh()), ("ReLU", nn.ReLU())]:
    first, last = grad_norms(act)
    print(f"{name:>8}  1층 grad={first:.2e}  20층 grad={last:.2e}  비율(1층/20층)={first/last:.2e}")

import torch, torch.nn as nn, torch.nn.functional as F

class FFN_ReLU(nn.Module):          # 2017 Transformer 원형
    def __init__(self, d, h):
        super().__init__()
        self.w1, self.w2 = nn.Linear(d, h, bias=False), nn.Linear(h, d, bias=False)
    def forward(self, x):
        return self.w2(F.relu(self.w1(x)))

class FFN_SwiGLU(nn.Module):        # LLaMA 스타일
    def __init__(self, d, h):
        super().__init__()
        self.w_gate = nn.Linear(d, h, bias=False)
        self.w_up   = nn.Linear(d, h, bias=False)
        self.w_down = nn.Linear(h, d, bias=False)
    def forward(self, x):
        return self.w_down(F.silu(self.w_gate(x)) * self.w_up(x))

d = 512
relu_ffn   = FFN_ReLU(d, 4 * d)
swiglu_ffn = FFN_SwiGLU(d, int(2 / 3 * 4 * d))   # 행렬 3개 → 은닉폭 2/3로 축소
count = lambda m: sum(p.numel() for p in m.parameters())
x = torch.randn(2, 10, d)
print("ReLU FFN   params:", f"{count(relu_ffn):,}", " out:", tuple(relu_ffn(x).shape))
print("SwiGLU FFN params:", f"{count(swiglu_ffn):,}", " out:", tuple(swiglu_ffn(x).shape))
