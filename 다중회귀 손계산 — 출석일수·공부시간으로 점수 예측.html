출석일수와 공부시간으로
과목 점수를 예측하는 다중회귀

학습 데이터 10개로 회귀계수를 손으로 구하고, 처음 보는 테스트 3개에 적용해 얼마나 잘 맞히는지 평가합니다. 모든 수치는 numpy·scipy·scikit-learn으로 실제 계산해 검증한 값입니다.

\[\hat y = 16.1325 + 1.4306\,x_1 + 2.4422\,x_2\]

1문제 설정

설명변수가 두 개인 선형 모형을 세웁니다. \(x_1\)은 학기 중 출석일수(30일 만점), \(x_2\)는 주당 평균 공부시간, \(y\)는 과목 점수입니다.

\[y_i=\beta_0+\beta_1x_{1i}+\beta_2x_{2i}+\varepsilon_i,\qquad \varepsilon_i\sim N(0,\sigma^2)\]

최소제곱법(OLS)은 잔차제곱합을 최소로 만드는 \(b_0,b_1,b_2\)를 찾습니다.

\[\text{SSE}(b_0,b_1,b_2)=\sum_{i=1}^{n}\bigl(y_i-b_0-b_1x_{1i}-b_2x_{2i}\bigr)^2\;\longrightarrow\;\min\]

세 계수로 각각 편미분해 0으로 두면 정규방정식이 나오고, 이를 풀면 계수가 결정됩니다. 이 노트는 두 가지 풀이를 모두 보여줍니다. 4장은 편차를 이용한 2×2 연립방정식 풀이(시험장 손계산용), 5장은 행렬식 \(\mathbf b=(X^\top X)^{-1}X^\top\mathbf y\) 풀이입니다.

3평균과 편차곱 합

먼저 세 변수의 평균을 구합니다.

\[\bar x_1=\frac{ 243 }{10}=24.3,\qquad \bar x_2=\frac{ 86 }{10}=8.6,\qquad \bar y=\frac{ 719 }{10}=71.9\]

\[S_{11}=\sum d_1^2=122.1,\quad S_{22}=\sum d_2^2=92.4,\quad S_{12}=\sum d_1d_2=41.2\]

4회귀계수 구하기

편차로 표현한 정규방정식은 기울기 두 개에 대한 2×2 연립방정식입니다.

\[\begin{cases} S_{11}\,b_1+S_{12}\,b_2=S_{1y}\\ S_{12}\,b_1+S_{22}\,b_2=S_{2y}\end{cases} \;\Longrightarrow\; \begin{cases} 122.1\,b_1+41.2\,b_2=275.3\\ 41.2\,b_1+92.4\,b_2=284.6\end{cases}\]

행렬식 D

\[D=S_{11}S_{22}-S_{12}^2=11282.04-1697.44=9584.6\]

크라메르 공식으로 b₁, b₂

\[b_1=\frac{S_{22}S_{1y}-S_{12}S_{2y}}{D}=\frac{ 25437.72-11725.52 }{ 9584.6 }=\frac{ 13712.20 }{ 9584.6 }=1.4306\]
\[b_2=\frac{S_{11}S_{2y}-S_{12}S_{1y}}{D}=\frac{ 34749.66-11342.36 }{ 9584.6 }=\frac{ 23407.30 }{ 9584.6 }=2.4422\]

절편 b₀

회귀평면은 반드시 평균점 \((\bar x_1,\bar x_2,\bar y)\)을 지나므로 절편은 다음과 같습니다.

\[b_0=\bar y-b_1\bar x_1-b_2\bar x_2=71.9-34.7648-21.0027=16.1325\]

추정된 회귀식

\[\hat y=16.1325+1.4306\,x_1+2.4422\,x_2\]

공부시간을 고정하면 출석이 하루 늘 때 점수가 약 1.4306점, 출석을 고정하면 공부시간이 1시간 늘 때 약 2.4422점 오른다고 해석합니다. 다른 변수를 통제한 상태의 효과이므로 "편회귀계수"라고 부릅니다.

5행렬 정규방정식 검증

같은 계수를 행렬로 구해 교차 확인합니다. 설계행렬 \(X\)의 첫 열은 절편을 위한 1입니다.

\[X=\begin{bmatrix}1&18&6\\1&20&10\\1&22&4\\1&23&8\\1&24&12\\1&25&5\\1&26&9\\1&27&14\\1&28&7\\1&30&11\end{bmatrix},\qquad \mathbf y=\begin{bmatrix}55\\72\\60\\65\\82\\61\\77\\85\\74\\88\end{bmatrix}\]
\[X^\top X=\begin{bmatrix} n&\sum x_1&\sum x_2\\ \sum x_1&\sum x_1^2&\sum x_1x_2\\ \sum x_2&\sum x_1x_2&\sum x_2^2\end{bmatrix}=\begin{bmatrix}10&243&86\\243&6027&2131\\86&2131&832\end{bmatrix},\qquad X^\top\mathbf y=\begin{bmatrix}719\\17747\\6468\end{bmatrix}\]
\[(X^\top X)^{-1}=\begin{bmatrix}4.938161&-0.197296&-0.005102\\-0.197296&0.009640&-0.004299\\-0.005102&-0.004299&0.012739\end{bmatrix}\]
\[\mathbf b=(X^\top X)^{-1}X^\top\mathbf y=\begin{bmatrix}16.1325\\1.4306\\2.4422\end{bmatrix}\]

4장의 편차 풀이와 소수점 넷째 자리까지 같습니다. 참고로 \((X^\top X)\)의 행렬식은 \(n\cdot D\)와 같고, 편차 풀이가 사실 이 3×3 문제에서 절편을 먼저 소거한 형태이기 때문입니다. 역행렬의 대각원소 \(c_{00}=4.938161\), \(c_{11}=0.009640\), \(c_{22}=0.012739\)는 7장에서 표준오차를 구할 때 다시 씁니다.

잔차의 합이 0이고 예측값의 합이 실제값의 합과 같은 것은 절편이 있는 OLS의 성질입니다.

제곱합 분해

\[\underbrace{\text{SST}}_{ 1156.9 }=\underbrace{\text{SSR}}_{ 1088.9016 }+\underbrace{\text{SSE}}_{ 67.9984 }\]

결정계수와 수정 결정계수

\[R^2=\frac{\text{SSR}}{\text{SST}}=\frac{ 1088.9016 }{ 1156.9 }=0.9412\]
\[R^2_{adj}=1-\frac{\text{SSE}/(n-p-1)}{\text{SST}/(n-1)}=1-\frac{ 67.9984/7}{ 1156.9/9}=0.9244\]

잔차 분산과 표준오차

\[\text{MSE}=s^2=\frac{\text{SSE}}{n-p-1}=\frac{ 67.9984 }{7}=9.7141,\qquad s=\sqrt{ 9.7141 }=3.1167\]

여기서 \(p=2\)는 설명변수의 개수입니다. 계수를 3개 추정했으므로 자유도는 \(10-3=7\)입니다. \(s\)는 "학습 데이터에서 예측이 평균적으로 약 3.1167점 빗나간다"는 뜻입니다.

7유의성 검정

모형 전체: F검정

\(H_0:\beta_1=\beta_2=0\) (두 변수 모두 점수와 무관)

\[F=\frac{\text{SSR}/p}{\text{SSE}/(n-p-1)}=\frac{ 1088.9016/2}{ 9.7141 }=56.05,\qquad F_{0.05}(2,7)=4.7374\]

\(F=56.05>4.7374\)이고 p값은 \(4.92\times10^{-5}\)이므로 \(H_0\)를 기각합니다. 회귀모형은 유의합니다.

개별 계수: t검정

계수의 표준오차는 \(\text{SE}(b_j)=\sqrt{s^2\,c_{jj}}\)이며 \(c_{jj}\)는 \((X^\top X)^{-1}\)의 대각원소입니다.

\[\text{SE}(b_1)=\sqrt{ 9.7141\times0.009640 }=0.3060,\qquad t_1=\frac{ 1.4306 }{ 0.3060 }=4.675\]
\[\text{SE}(b_2)=\sqrt{ 9.7141\times0.012739 }=0.3518,\qquad t_2=\frac{ 2.4422 }{ 0.3518 }=6.942\]

다중공선성 점검: VIF

설명변수가 두 개일 때 VIF는 두 변수의 상관계수로 바로 구할 수 있습니다.

\[r_{12}=\frac{S_{12}}{\sqrt{S_{11}S_{22}}}=0.3879,\qquad \text{VIF}=\frac{1}{1-r_{12}^2}=\frac{1}{1-0.1505}=1.177\]

VIF가 10은 물론 5보다도 훨씬 작으므로 다중공선성 문제는 없습니다.

9테스트 평가지표

8장 표의 오차 세 개로 대표적인 회귀 평가지표를 하나씩 계산합니다.

MAE — 평균절대오차

\[\text{MAE}=\frac1m\sum|y_i-\hat y_i|=\frac{ 2.7286+3.3205+2.6304 }{3}=2.8932\]

MSE — 평균제곱오차

\[\text{MSE}_{test}=\frac1m\sum(y_i-\hat y_i)^2=\frac{ 7.4454+11.0257+6.9188 }{3}=8.4633\]

RMSE — 평균제곱근오차

\[\text{RMSE}=\sqrt{\text{MSE}_{test}}=\sqrt{ 8.4633 }=2.9092\]

MAPE — 평균절대백분율오차

\[\text{MAPE}=\frac{100}{m}\sum\left|\frac{y_i-\hat y_i}{y_i}\right|=\frac{ 4.13+4.55+2.86 }{3}=3.85\%\]

테스트 R²

테스트 R²는 테스트 실제값의 평균 \(\bar y_{test}=77\)을 기준선으로 씁니다(scikit-learn의 r2_score와 같은 정의).

\[\text{SST}_{test}=121+16+225=362.0,\qquad \text{SSE}_{test}=25.3900\]
\[R^2_{test}=1-\frac{\text{SSE}_{test}}{\text{SST}_{test}}=1-\frac{ 25.3900 }{ 362.0 }=0.9299\]

11Python 검증

아래 코드를 그대로 실행하면 손계산 결과를 확인할 수 있습니다. numpy와 scikit-learn만 필요합니다.

import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# 학습 데이터 10개: [출석일수, 공부시간], 점수
X_train = np.array([[18, 6], [20, 10], [22, 4], [23, 8], [24, 12],
                    [25, 5], [26, 9], [27, 14], [28, 7], [30, 11]], dtype=float)
y_train = np.array([55, 72, 60, 65, 82, 61, 77, 85, 74, 88], dtype=float)

# 테스트 케이스 3개
X_test = np.array([[21, 7], [25, 10], [29, 13]], dtype=float)
y_test = np.array([66, 73, 92], dtype=float)

# 1) 정규방정식으로 직접 계산: beta = (X'X)^-1 X'y
X = np.column_stack([np.ones(len(X_train)), X_train])
beta = np.linalg.inv(X.T @ X) @ X.T @ y_train
print("정규방정식 beta :", np.round(beta, 4))

# 2) scikit-learn 교차 확인
model = LinearRegression().fit(X_train, y_train)
print("sklearn b0, b1, b2:", round(model.intercept_, 4), np.round(model.coef_, 4))
print("학습 R^2         :", round(model.score(X_train, y_train), 4))

# 3) 테스트 평가
y_pred = model.predict(X_test)
print("테스트 예측값    :", np.round(y_pred, 4))
print("오차 (y - y_hat) :", np.round(y_test - y_pred, 4))
print("MAE  :", round(mean_absolute_error(y_test, y_pred), 4))
print("MSE  :", round(mean_squared_error(y_test, y_pred), 4))
print("RMSE :", round(np.sqrt(mean_squared_error(y_test, y_pred)), 4))
print("MAPE :", round(np.mean(np.abs((y_test - y_pred) / y_test)) * 100, 4), "%")
print("테스트 R^2 :", round(r2_score(y_test, y_pred), 4))
