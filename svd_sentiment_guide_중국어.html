01概述与路线图

情感分析的结果通常会累积成一个“谁对什么持有多大程度的正面/负面态度”的矩阵。SVD 把这个矩阵分解为几个隐藏的轴（潜在因子），揭示出几十、几百个分数背后的情感结构。

本手册要回答的问题
12 位评论者对 5 个项目以 −2（非常负面）~ +2（非常正面）表达了情感。这 60 个数字里包含几种“倾向”？这些倾向是什么？每位评论者属于哪种倾向？

02SVD 的定义

任意实矩阵 $A \in \mathbb{R}^{m\times n}$ 都可以这样分解。无论是否为方阵、是否秩亏，都没有例外 —— 这是它与特征值分解的决定性区别。

$$A = U\,\Sigma\,V^{\mathsf T} = \sum_{i=1}^{r}\sigma_i\,\mathbf u_i\,\mathbf v_i^{\mathsf T},\qquad \sigma_1\ge\sigma_2\ge\cdots\ge\sigma_r>0$$

三个矩阵从何而来

把 SVD 代入 $A^{\mathsf T}A$ 和 $AA^{\mathsf T}$ 即可看出。

$$A^{\mathsf T}A = V\Sigma^{\mathsf T}U^{\mathsf T}U\Sigma V^{\mathsf T} = V\,\Sigma^2\,V^{\mathsf T},\qquad AA^{\mathsf T} = U\,\Sigma^2\,U^{\mathsf T}$$
  • $V$ = $A^{\mathsf T}A$（5×5，项目×项目）的特征向量，$U$ = $AA^{\mathsf T}$（12×12，评论者×评论者）的特征向量
  • $\sigma_i = \sqrt{\lambda_i}$ — 两个矩阵共有的非零特征值的平方根
  • 实践中只分解较小的那个（$A^{\mathsf T}A$，5×5），再用 $\mathbf u_i = A\mathbf v_i/\sigma_i$ 求出 $U$（第8章）

必须记住的性质

性质公式在情感分析中的含义
存在性任意 $A$ 都存在评论者数 ≠ 项目数也没问题
正交性$U^{\mathsf T}U=V^{\mathsf T}V=I$潜在因子之间互不重叠（相互独立的倾向）
能量守恒$\|A\|_F^2=\sum\sigma_i^2$情感“总量”按因子分别存放
秩rank$(A)$ = 非零 σ 的个数真正独立的倾向数量
最优近似Eckart–Young 定理前 k 个因子是最好的概括（第10章）

03几何意义 — 旋转 · 拉伸 · 旋转

用矩阵 $A$ 乘以向量 $\mathbf x$，等于三个动作的复合。把 $A$ 作用于单位圆（所有方向上长度为 1 的向量），就得到一个椭圆，椭圆的半轴长度就是奇异值。

翻译成情感分析的语言
Vᵀ：把 5 个项目的分数换算成“潜在倾向轴”上的坐标 · Σ：给每种倾向的显现强度加权 · U：把该倾向分配给每位评论者。核心等式是 $A\mathbf v_i = \sigma_i\mathbf u_i$ —— “输入项目方向 $\mathbf v_i$，输出评论者方向 $\mathbf u_i$ 并放大 $\sigma_i$ 倍。”

05Step 1 · 计算 $A^{\mathsf T}A$

$A^{\mathsf T}A$ 的 $(j,k)$ 元素是项目 $j$ 列与项目 $k$ 列的内积。对角元素是各项目情感的平方和（能量），非对角元素表示两个项目同向变化的程度。

$$(A^{\mathsf T}A)_{jk} = \sum_{i=1}^{12} a_{ij}\,a_{ik}$$

手算 ① 口味·口味（对角元素）

$$(A^{\mathsf T}A)_{11} = 2^2+2^2+1^2+1^2+1^2+2^2+(-2)^2+(-1)^2+1^2+1^2+(-1)^2+0^2 = 23$$

手算 ② 口味·价格（非对角元素）

$$\begin{aligned}(A^{\mathsf T}A)_{14} &= 2\cdot2+2\cdot1+1\cdot(-2)+1\cdot(-2)+1\cdot2+2\cdot2+(-2)(-2)+(-1)(-1)+1\cdot0+1\cdot1+(-1)(-2)+0\cdot1\\ &= 4+2-2-2+2+4+4+1+0+1+2+0 = 16\end{aligned}$$

手算 ③ 服务·价格（结果为负的情况）

$$(A^{\mathsf T}A)_{24} = 4+1-4-4-2-2+4+2+0+1-2-1 = -3$$

06Step 2 · 特征值 → 奇异值

需要求解 $A^{\mathsf T}A\,\mathbf v=\lambda\mathbf v$。特征方程 $\det(A^{\mathsf T}A-\lambda I)=0$ 是 5 次方程，没有求根公式，所以实际上使用数值方法。最直观的方法是幂迭代法（Power Iteration）。

幂迭代法 — 求最大特征值

$$\mathbf x^{(k+1)} = \frac{A^{\mathsf T}A\,\mathbf x^{(k)}}{\|A^{\mathsf T}A\,\mathbf x^{(k)}\|},\qquad \lambda^{(k)} = \mathbf x^{(k)\mathsf T}A^{\mathsf T}A\,\mathbf x^{(k)}\;\;(\text{瑞利商})$$

对任意向量反复相乘，只有最大特征值方向的分量会以 $(\lambda_1/\lambda_2)^k$ 的比例保留下来。初始值 $\mathbf x^{(0)}=\frac{1}{\sqrt5}(1,1,1,1,1)$。

09Step 5 · Σ 与解释率

每个因子承载了总情感能量 $\|A\|_F^2=136$ 中的多少，就是解释率。

$$\text{解释率}_i = \frac{\sigma_i^2}{\sum_j\sigma_j^2}:\quad \frac{71.438}{136}=52.5\%,\quad \frac{54.816}{136}=40.3\%,\quad \frac{4.880}{136}=3.6\%,\;2.0\%,\;1.6\%$$
如何读图
可以看到柱子在第 2 个之后急剧下降的“肘部（elbow）”。σ₁·σ₂（8.45, 7.40）很大，σ₃~σ₅（2.2~1.5）同样很小 → 真正的结构是二维，其余是个体差异和测量噪声。累计 92.8%，2 个因子已经足够。
为什么和 sklearn 的数字不同
TruncatedSVD.explained_variance_ratio_ 为 0.5287, 0.4079，与上面略有不同。这是因为 sklearn 计算的是投影坐标方差（减去均值后）的比例，而这里用的是以原点为基准的能量（σ²）比例。奇异值本身（8.4521, 7.4038）完全一致。

10Step 6 · 低秩近似（Truncated SVD）

SVD 把矩阵写成秩 1 片段之和。只保留前 $k$ 个，就是最好的概括。

$$A_k=\sum_{i=1}^{k}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T},\qquad \min_{\operatorname{rank}(B)\le k}\|A-B\|_F=\|A-A_k\|_F=\sqrt{\sigma_{k+1}^2+\cdots+\sigma_r^2}\quad(\text{Eckart–Young})$$

手算 — 秩 1 近似中 R01 的“口味”

$$(A_1)_{11}=\sigma_1u_{11}v_{11}=8.4521\times0.4366\times0.5025=1.854\quad(\text{原值 } 2)$$

手算 — 秩 2 近似中 R03 的“价格”

$$\begin{aligned}(A_2)_{34}&=\sigma_1u_{31}v_{41}+\sigma_2u_{32}v_{42}\\&=8.4521(-0.0208)(0.5675)+7.4038(-0.4943)(0.3772)\\&=-0.0999-1.3805=-1.480\quad(\text{原值 } -2)\end{aligned}$$

仅用因子 1 只能把 R03 描绘成“中立”（−0.1），加上因子 2 后，“对价格不满”这一核心信息才得以恢复。

11双标图解读 — 把评论者和项目放在同一平面

评论者画成点 $(\sigma_1u_{i1},\sigma_2u_{i2})$，项目画成箭头 $(\sigma_1v_{j1},\sigma_2v_{j2})$，放在同一个二维潜在空间中。点与箭头的内积就是近似分数：$(A_2)_{ij}\approx$（点的方向）·（箭头方向）。

读图规则

  1. 横轴位置 = 整体情感。 越靠右越认可这家餐厅整体。R01（+3.69）最满意，R07（−3.97）最不满。
  2. 纵轴位置 = 以什么为标准评价。 上方对价格·分量宽容，下方对服务·氛围宽容。
  3. 与箭头方向同侧的点对该项目评价好。R12 位于价格·分量箭头一侧、服务·氛围箭头的反侧 → 实际为价格 +1·分量 +2，服务 −1·氛围 −2。
  4. 箭头之间夹角越小，项目越同向变化。 价格·分量几乎重合，服务·氛围也几乎重合。两组约成 90° → 相互独立（与第5章 AᵀA 中的 −3, −1, 0 一致）。
  5. 口味位于两组之间的右侧 → 无论哪种类型，口味都与整体满意度同向变化，是“基础”项目。
  6. 靠近原点的点（R09）意见弱或中立 — 用于细分判断时可信度低。

③ 预测缺失的情感分数（迭代 SVD 插补）

假设 R04 没有提到“价格”，把这一格隐藏起来（真实值为 −2）。算法：

  1. 用其余 11 人价格的均值 0.1818 填充空格。
  2. 对填充后的矩阵做 SVD → 计算秩 2 近似 $A_2$。
  3. 只把空格替换为 $A_2$ 中的对应值，回到第 2 步重复。

0.18 → −0.67 → −1.10 → −1.32 → … → 收敛到 −1.615。简单均值（+0.18，“中立”）完全错了，而 SVD 利用了“R04 是体验派，所以对价格多半是负面的”这一结构，预测值接近真实值（−2）。因 Netflix Prize 而闻名的矩阵分解推荐，原理正是如此。

13扩展到文本情感分析 — LSA

到目前为止，我们分解的是已经构造好的情感分数矩阵。直接对原始文本使用 SVD 的经典方法是潜在语义分析（LSA, Latent Semantic Analysis）。

实务注意事项

领域分解什么SVD 的作用典型例子
情感·意见分析用户 × 属性情感分数发现情感倾向轴，用户细分本手册，品牌评论分析
文本挖掘（LSA）文档 × 词 TF-IDF合并同义词，文档语义向量搜索引擎（LSI），文档分类·聚类

数值稳定性诊断任意矩阵条件数 $\kappa=\sigma_{\max}/\sigma_{\min}$，数值秩检查回归的不稳定性
人脸识别人脸图像 × 像素提取特征脸（eigenfaces）Turk & Pentland 方法
深度学习轻量化权重矩阵 W用低秩分解减少参数LoRA 的思路，模型压缩
生物信息 · 信号处理基因 × 样本，时间序列轨迹分离表达模式，分离周期成分SSA（奇异谱分析）

一句话概括共同点
所有用途归根结底都来自同一个思想：“把大矩阵中的重要方向（大的 σ）与不重要方向（小的 σ）分开”。保留大的 σ 就是压缩·概括·推荐，舍弃小的 σ 就是降噪，谨慎处理小的 σ 就得到稳定的逆矩阵。

只需 NumPy 和 scikit-learn 即可直接运行。本手册中的所有数值都与下面的输出一致。

svd_sentiment.py
import numpy as np
from sklearn.decomposition import TruncatedSVD

np.set_printoptions(precision=4, suppress=True)

# ── 1. 情感分数矩阵（12人 × 5项，-2=非常负面 ~ +2=非常正面）
items = ["口味", "服务", "氛围", "价格", "分量"]
A = np.array([
    [ 2,  2,  2,  2,  1],   # R01
    [ 2,  1,  2,  1,  1],   # R02
    [ 1,  2,  2, -2, -1],   # R03
    [ 1,  2,  1, -2, -2],   # R04
    [ 1, -1, -1,  2,  2],   # R05
    [ 2, -1,  0,  2,  2],   # R06
    [-2, -2, -1, -2, -2],   # R07
    [-1, -2, -2, -1, -2],   # R08
    [ 1,  0,  1,  0,  0],   # R09
    [ 1,  1,  1,  1,  1],   # R10
    [-1,  1,  1, -2, -1],   # R11
    [ 0, -1, -2,  1,  2],   # R12
], dtype=float)

# ── 2. 直接推导: AᵀA 的特征分解 → σ = √λ, V
AtA = A.T @ A
lam, V = np.linalg.eigh(AtA)
order = np.argsort(lam)[::-1]
lam, V = lam[order], V[:, order]
sigma = np.sqrt(lam)
print("AᵀA =\n", AtA)
print("特征值 λ =", lam)
print("奇异值 σ =", sigma)
print("trace(AᵀA) =", np.trace(AtA), " ‖A‖_F² =", (A**2).sum())

# ── 3. numpy SVD（统一符号: v1 之和为正，v2 价格·分量一侧为正）
U, s, Vt = np.linalg.svd(A, full_matrices=False)
if Vt[0].sum() < 0:
    Vt[0] *= -1; U[:, 0] *= -1
if Vt[1, 3] + Vt[1, 4] - Vt[1, 1] - Vt[1, 2] < 0:
    Vt[1] *= -1; U[:, 1] *= -1
print("\nnp.linalg.svd σ =", s)
print("v1 =", Vt[0])
print("v2 =", Vt[1])
energy = s**2 / (s**2).sum()
print("解释率 =", energy, " 累计 =", np.cumsum(energy))

# ── 4. 低秩近似与 Eckart–Young 误差
for k in range(1, 6):
    Ak = U[:, :k] @ np.diag(s[:k]) @ Vt[:k]
    print(f"k={k}  ‖A-A_k‖_F = {np.linalg.norm(A - Ak):.4f}"
          f"  √(Σ舍弃σ²) = {np.sqrt((s[k:]**2).sum()):.4f}")

# ── 5. 评论者潜在坐标（σ·u）
US = U[:, :2] * s[:2]
for i, row in enumerate(US):
    print(f"R{i+1:02d}  因子1(整体情感)={row[0]:+.3f}  因子2(性价比↔体验)={row[1]:+.3f}")

# ── 6. 新评论者 fold-in：“便宜量又足，但店员态度差”
new = np.array([1, -2, 0, 2, 2], dtype=float)
z = new @ Vt[:2].T                       # 潜在坐标 = a·V_k
cos = US @ z / (np.linalg.norm(US, axis=1) * np.linalg.norm(z))
best = np.argsort(-cos)[:3]
print("\n新评论者潜在坐标 =", z)
print("最相似的评论者 =", [(f"R{i+1:02d}", round(cos[i], 4)) for i in best])

# ── 7. 缺失插补: 隐藏 R04 的“价格”，用迭代SVD(k=2)估计
X = A.copy()
X[3, 3] = np.delete(A[:, 3], 3).mean()
for _ in range(30):
    u, ss, vt = np.linalg.svd(X, full_matrices=False)
    X[3, 3] = (u[:, :2] @ np.diag(ss[:2]) @ vt[:2])[3, 3]
print(f"R04“价格”估计 = {X[3, 3]:.4f}  (真实 -2, 简单均值 {np.delete(A[:, 3], 3).mean():.4f})")

# ── 8. scikit-learn TruncatedSVD 交叉验证
tsvd = TruncatedSVD(n_components=2, algorithm="arpack").fit(A)
print("\nsklearn singular_values_ =", tsvd.singular_values_)
print("sklearn explained_variance_ratio_ =", tsvd.explained_variance_ratio_)

16检查清单 · 练习题

核心检查清单

  • 能说出 $A=U\Sigma V^{\mathsf T}$ 中 U·Σ·V 的大小和含义（评论者/强度/项目）
  • 能推导出 $V$ 是 $A^{\mathsf T}A$ 的特征向量、$\sigma=\sqrt\lambda$、$\mathbf u_i=A\mathbf v_i/\sigma_i$
  • 能用 $\sum\sigma_i^2=\|A\|_F^2=\operatorname{tr}(A^{\mathsf T}A)$ 验证计算
  • 知道 5 次及以上需要幂迭代等数值方法，且收敛速度取决于 $\lambda_2/\lambda_1$
  • 能根据载荷（V）的符号模式给因子命名（整体 vs 对比）
  • 能用碎石图的肘部和累计解释率确定 k
  • Eckart–Young：秩 k 近似误差 $=\sqrt{\sum_{i>k}\sigma_i^2}$
  • 能在双标图中解读点–箭头方向、箭头之间的夹角
  • 能解释 Fold-in（$\mathbf aV_k$）、余弦相似度、迭代 SVD 插补
  • 了解 SVD 符号的不确定性，以及是否中心化（SVD vs PCA）的区别

练习题

在这组数据中 rank(A) 是多少？依据是什么？
5。因为 5 个奇异值（8.452, 7.404, 2.209, 1.658, 1.456）都不为 0。不过“实质上的”秩可看作 σ 骤降之前的 2。
只保留 k=1 时，R03 和 R04 的“价格不满”为什么会消失？
秩 1 近似中每一行都是 v₁（全为正）的倍数，无法表示某位评论者对某些项目为 +、对另一些项目为 − 的模式。必须有承载这种对比的 v₂ 才能恢复。
σ₁=8.4521 时，只保留 v₁ 方向的近似的 Frobenius 误差是多少？
$\sqrt{136-71.4376}=\sqrt{64.5624}=8.035$。从总能量中减去第一个 σ² 再开平方。
新评论 a = (−1, 2, 2, −2, −1) 的潜在坐标和预计所属细分是什么？
a·v₁ = −0.5025+0.4624+0.5408−1.1350−0.5466 = −1.181，a·v₂ = 0.1833−1.2118−1.1842−0.7544−0.3261 = −3.293。位于左下方 → “价格不满 · 体验派”（与 R03·R04·R11 同组）。
像本手册这样不减均值直接做 SVD，与 PCA 有什么不同？
不减均值时，第一个因子捕捉的是从原点指向数据中心的方向，也就是“整体情感水平”。减去列均值（PCA）后，这一水平被移除，只剩下项目之间的相对差异。像情感分数这样 0 是有意义的中立点时，不做中心化更有利于解读。
