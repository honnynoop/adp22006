정의 · 내적과 노름

두 벡터 $\mathbf{a},\mathbf{b}\in\mathbb{R}^n$의 내적(dot product)은 같은 위치 원소의 곱을 모두 더한 값이며, 기하학적으로는 길이와 사이각으로 표현됩니다.

$$\mathbf{a}\cdot\mathbf{b}=\mathbf{a}^\top\mathbf{b}=\sum_{i=1}^{n}a_ib_i=\|\mathbf{a}\|\,\|\mathbf{b}\|\cos\theta$$

노름(norm)은 벡터의 크기입니다. 일반적인 $L_p$ 노름은 $\|\mathbf{x}\|_p=\left(\sum_i |x_i|^p\right)^{1/p}$ 입니다.

노름공식$\mathbf{x}=(3,-4)$ 일 때AI 사용처
$L_1$$\sum_i |x_i|$7Lasso 규제, 희소성 유도, MAE
$L_2$$\sqrt{\sum_i x_i^2}$5Ridge·weight decay, 유클리드 거리, 그래디언트 클리핑
$L_\infty$$\max_i |x_i|$4적대적 공격(FGSM)의 섭동 크기 제한

내적을 두 벡터의 길이로 나누면 길이와 무관하게 방향만 비교하는 코사인 유사도가 됩니다. 값은 −1(정반대)부터 1(같은 방향)까지입니다. 그리고 $\mathbf{b}$를 $\mathbf{a}$ 방향으로 떨어뜨린 그림자가 투영(projection)입니다.

$$\cos(\mathbf{a},\mathbf{b})=\frac{\mathbf{a}^\top\mathbf{b}}{\|\mathbf{a}\|\,\|\mathbf{b}\|}$$
$$\operatorname{proj}_{\mathbf{a}}\mathbf{b}=\frac{\mathbf{a}^\top\mathbf{b}}{\mathbf{a}^\top\mathbf{a}}\,\mathbf{a}$$

임베딩 기반 검색(RAG, 추천)은 질의 벡터와 문서 벡터의 코사인 유사도가 큰 순서로 결과를 고릅니다. 벡터를 미리 $L_2$ 정규화해 두면 코사인 유사도는 그냥 내적이 되어 행렬 곱 한 번으로 수백만 개를 비교할 수 있습니다.

1.2행렬 곱과 선형변환

행렬 $A\in\mathbb{R}^{m\times n}$와 $B\in\mathbb{R}^{n\times p}$의 곱 $C=AB\in\mathbb{R}^{m\times p}$의 각 원소는 $A$의 행과 $B$의 열의 내적입니다. 안쪽 차원 $n$이 같아야 곱할 수 있습니다.

$$C_{ij}=\sum_{k=1}^{n}A_{ik}B_{kj}\qquad (m\times \underline{n})\,(\underline{n}\times p)\;\to\;(m\times p)$$

행렬은 공간을 바꾸는 함수, 곧 선형변환입니다. $A$의 각 열은 기저벡터 $\mathbf{e}_1,\mathbf{e}_2$가 옮겨 가는 위치입니다.

개념정의 / 공식의미
전치$(A^\top)_{ij}=A_{ji}$, $\;(AB)^\top=B^\top A^\top$행과 열을 바꿈. 곱의 전치는 순서가 뒤집힘
단위행렬$I\mathbf{x}=\mathbf{x}$아무것도 하지 않는 변환. ResNet의 skip connection과 같은 역할
역행렬$AA^{-1}=A^{-1}A=I$변환을 되돌림. $\det A\neq0$일 때만 존재
행렬식$\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$부피 배율. 0이면 차원이 찌그러져 정보 손실
랭크선형독립인 열(행)의 최대 개수변환 결과가 실제로 차지하는 차원 수
대각합(trace)$\operatorname{tr}(A)=\sum_i A_{ii}=\sum_i\lambda_i$고유값의 합. 행렬 미분에서 자주 등장
직교행렬$Q^\top Q=I$, $\;Q^{-1}=Q^\top$회전·반사. 길이와 각도를 보존
주의

행렬 곱은 교환법칙이 성립하지 않습니다($AB\neq BA$). 또 원소별 곱 $A\odot B$(NumPy의 A*B)와 행렬 곱 $AB$(A@B)는 전혀 다른 연산입니다. shape 오류의 대부분이 여기서 생깁니다.

1.3고유값과 고유벡터

정의 · 고유값 분해

정사각행렬 $A$에 대해 $\mathbf{v}\neq\mathbf{0}$이고 다음을 만족하면 $\lambda$를 고유값, $\mathbf{v}$를 고유벡터라 합니다. 고유값은 특성방정식의 근입니다.

$$A\mathbf{v}=\lambda\mathbf{v}\quad\Longleftrightarrow\quad\det(A-\lambda I)=0$$

$A$가 대칭행렬($A=A^\top$)이면 고유값은 모두 실수이고 고유벡터는 서로 직교합니다(스펙트럼 정리).

$$A=Q\Lambda Q^\top=\sum_{i}\lambda_i\,\mathbf{q}_i\mathbf{q}_i^\top$$

예제: $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$의 고유값

$$\det\begin{bmatrix}2-\lambda&1\\1&2-\lambda\end{bmatrix}=(2-\lambda)^2-1=0\;\Rightarrow\;\lambda_1=3,\;\lambda_2=1$$

$\lambda=3$이면 $(A-3I)\mathbf{v}=0$에서 $\mathbf{v}_1\propto(1,1)$, $\lambda=1$이면 $\mathbf{v}_2\propto(1,-1)$. 검산: $\operatorname{tr}A=4=3+1$, $\det A=3=3\times1$.

성질조건AI에서의 의미
양정치 (positive definite)모든 $\mathbf{x}\neq0$에 대해 $\mathbf{x}^\top A\mathbf{x}>0$ ⇔ 모든 $\lambda_i>0$헤시안이 양정치면 그 점은 극소점. 공분산 행렬은 양반정치 → 부록 A.1
조건수 (condition number)$\kappa=\lambda_{\max}/\lambda_{\min}$클수록 등고선이 길쭉해져 경사하강이 지그재그(그림 3-1) → 부록 A.2
스펙트럼 반경$\max_i|\lambda_i|$RNN에서 1보다 크면 기울기 폭발, 작으면 소실 → 부록 A.3

1.4특이값 분해 (SVD)

고유값 분해는 정사각행렬에만 쓸 수 있지만 SVD는 모든 행렬에 쓸 수 있습니다. 어떤 선형변환이든 "회전 → 축 방향 늘이기 → 회전"으로 분해된다는 뜻입니다.

핵심 공식 · SVD $$A=U\Sigma V^\top,\qquad A\in\mathbb{R}^{m\times n},\;U\in\mathbb{R}^{m\times m},\;\Sigma\in\mathbb{R}^{m\times n},\;V\in\mathbb{R}^{n\times n}$$
  • $U$, $V$는 직교행렬, $\Sigma$는 대각에 특이값 $\sigma_1\ge\sigma_2\ge\dots\ge0$
  • $\sigma_i^2$는 $A^\top A$의 고유값, $V$의 열은 $A^\top A$의 고유벡터
  • $\operatorname{rank}(A)$ = 0이 아닌 특이값의 개수
핵심 정리 · 저랭크 근사 (Eckart–Young)

큰 특이값 $k$개만 남긴 행렬이 랭크 $k$ 행렬 중 원래 행렬에 가장 가깝습니다(프로베니우스 노름 기준).

$$A_k=\sum_{i=1}^{k}\sigma_i\,\mathbf{u}_i\mathbf{v}_i^\top,\qquad \|A-A_k\|_F=\sqrt{\sum_{i>k}\sigma_i^2}$$
AI 연결

LoRA는 대형 모델의 가중치 변화량 $\Delta W\in\mathbb{R}^{d\times d}$를 $BA$ ($B\in\mathbb{R}^{d\times r},A\in\mathbb{R}^{r\times d}$, $r\ll d$)로 저랭크 근사하여 학습 파라미터를 수백 배 줄입니다. 추천 시스템의 행렬분해, 이미지 압축, LSA 토픽 모델도 같은 원리입니다.

1.5주성분 분석 (PCA)

PCA는 데이터의 분산이 가장 큰 방향을 찾아 그 축으로 좌표를 다시 잡는 방법입니다. 그 방향은 공분산 행렬의 고유벡터이고, 그 방향의 분산이 고유값입니다.

핵심 공식 · PCA $$\Sigma=\frac{1}{n-1}X_c^\top X_c,\qquad \Sigma\mathbf{w}_k=\lambda_k\mathbf{w}_k,\qquad \text{설명분산비}_k=\frac{\lambda_k}{\sum_j\lambda_j}$$

$X_c$는 열마다 평균을 뺀 데이터. 첫 번째 주성분은 $\displaystyle\mathbf{w}_1=\operatorname*{argmax}_{\|\mathbf{w}\|=1}\mathbf{w}^\top\Sigma\mathbf{w}$ 의 해입니다.

ch1_linear_algebra.py
import numpy as np

# ---- 벡터: 내적, 코사인 유사도, 투영 ----
a = np.array([4.0, 1.0])
b = np.array([2.0, 3.0])
dot = a @ b
cos = dot / (np.linalg.norm(a) * np.linalg.norm(b))
proj = dot / (a @ a) * a
print("내적:", dot, "| 코사인 유사도:", round(cos, 4), "| 투영:", proj.round(3))

# ---- 행렬: 행렬식, 고유값 분해, SVD ----
A = np.array([[2.0, 1.0], [1.0, 2.0]])
vals, vecs = np.linalg.eigh(A)            # 대칭행렬은 eigh (오름차순)
print("det:", round(np.linalg.det(A), 3), "| 고유값:", vals)
print("재구성 오차 |A - QΛQᵀ|:", np.abs(A - vecs @ np.diag(vals) @ vecs.T).max())

B = np.array([[1.6, 0.9], [0.3, 1.1]])
U, S, Vt = np.linalg.svd(B)
print("특이값:", S.round(4))

# ---- PCA: 공분산 고유분해 vs SVD ----
rng = np.random.default_rng(0)
X = rng.multivariate_normal([0, 0], [[3.0, 1.8], [1.8, 1.6]], size=500)
Xc = X - X.mean(axis=0)                     # 1) 중심화
C = Xc.T @ Xc / (len(X) - 1)                # 2) 공분산 행렬
lam, W = np.linalg.eigh(C)                  # 3) 고유분해
order = np.argsort(lam)[::-1]
lam, W = lam[order], W[:, order]
Z = Xc @ W[:, :1]                           # 4) PC1로 사영 (2D → 1D)
print("설명분산비:", (lam / lam.sum()).round(3), "| 축소 후 shape:", Z.shape)

_, s, _ = np.linalg.svd(Xc, full_matrices=False)
print("SVD로 구한 분산:", (s**2 / (len(X) - 1)).round(4), "| 고유값:", lam.round(4))

2.2편미분과 그래디언트

변수가 여러 개인 함수에서 하나만 움직이고 나머지는 고정한 채 미분한 것이 편미분입니다. 편미분을 모두 모은 벡터가 그래디언트입니다.

$$\nabla f(\mathbf{x})=\left(\frac{\partial f}{\partial x_1},\frac{\partial f}{\partial x_2},\dots,\frac{\partial f}{\partial x_n}\right)^\top$$

예: $f(x,y)=x^2+5y^2$ 이면 $\nabla f=(2x,\;10y)^\top$, 점 $(1,1)$에서 $(2,10)^\top$.

핵심 정리 · 그래디언트의 방향

단위벡터 $\mathbf{u}$ 방향의 변화율(방향도함수)은 $D_{\mathbf{u}}f=\nabla f^\top\mathbf{u}=\|\nabla f\|\cos\theta$ 입니다. 따라서

  • $\theta=0$, 곧 그래디언트 방향이 가장 가파르게 증가하는 방향
  • $-\nabla f$가 가장 가파르게 감소하는 방향 → 경사하강법의 근거
  • 그래디언트는 등고선과 항상 수직

2.3연쇄법칙 (Chain Rule)

합성함수의 미분은 각 단계의 미분을 곱한 것입니다. 신경망은 함수를 수십~수백 번 합성한 것이므로, 역전파는 연쇄법칙을 효율적으로 계산하는 알고리즘일 뿐입니다.

$$\frac{dz}{dx}=\frac{dz}{dy}\cdot\frac{dy}{dx}$$
$$\frac{\partial L}{\partial x_i}=\sum_{j}\frac{\partial L}{\partial y_j}\,\frac{\partial y_j}{\partial x_i}$$

오른쪽은 다변수 버전입니다. $x_i$가 여러 경로($y_1,y_2,\dots$)를 통해 $L$에 영향을 주면, 경로별 기여를 모두 더합니다. 행렬로 쓰면 $\nabla_{\mathbf{x}}L=J^\top\nabla_{\mathbf{y}}L$ 이고 $J$는 야코비안입니다(2.5절).

예제: $L=(\sigma(wx+b)-y)^2$ 을 $w$로 미분

$$\frac{\partial L}{\partial w}=\underbrace{2(a-y)}_{\partial L/\partial a}\cdot\underbrace{a(1-a)}_{\partial a/\partial z}\cdot\underbrace{x}_{\partial z/\partial w},\qquad z=wx+b,\;a=\sigma(z)$$

숫자를 넣은 전체 계산은 그림 7-3에 있습니다.

2.5야코비안·헤시안·테일러 전개

야코비안 $J$

벡터 함수 $\mathbf{f}:\mathbb{R}^n\to\mathbb{R}^m$의 1차 미분 행렬

$$J_{ij}=\frac{\partial f_i}{\partial x_j}\in\mathbb{R}^{m\times n}$$
헤시안 $H$

스칼라 함수의 2차 편미분 행렬 (곡률 정보)

$$H_{ij}=\frac{\partial^2 f}{\partial x_i\,\partial x_j}\in\mathbb{R}^{n\times n}$$

임계점($\nabla f=0$)에서 헤시안의 고유값이 모두 양수면 극소, 모두 음수면 극대, 부호가 섞이면 안장점(saddle point)입니다. 고차원 딥러닝 손실 지형에서는 지역 최솟값보다 안장점이 훨씬 흔합니다.

핵심 공식 · 다변수 테일러 전개 $$f(\mathbf{x}+\boldsymbol{\delta})\approx f(\mathbf{x})+\nabla f(\mathbf{x})^\top\boldsymbol{\delta}+\tfrac12\,\boldsymbol{\delta}^\top H(\mathbf{x})\,\boldsymbol{\delta}$$
  • 1차 근사만 쓰고 $\boldsymbol\delta=-\eta\nabla f$ 로 두면 → 경사하강법
  • 2차 근사를 $\boldsymbol\delta$에 대해 최소화하면 $\boldsymbol\delta=-H^{-1}\nabla f$ → 뉴턴법

적분과 확률의 연결

연속 확률변수에서 확률은 밀도함수 아래 넓이이고, 기대값은 가중 적분입니다. $\displaystyle P(a\le X\le b)=\int_a^b p(x)\,dx$, $\displaystyle\mathbb{E}[g(X)]=\int g(x)\,p(x)\,dx$. 딥러닝에서는 이 적분을 표본 평균으로 근사합니다(몬테카를로). 미니배치 손실이 바로 기대 손실의 몬테카를로 추정치입니다.

import numpy as np

# f(w) = Σ(w-3)² + w0·w1  의 그래디언트를 손으로 유도하고 수치 미분으로 검증
def f(w):
    return np.sum((w - 3.0) ** 2) + w[0] * w[1]

def grad_f(w):
    g = 2 * (w - 3.0)
    g[0] += w[1]
    g[1] += w[0]
    return g

def numerical_grad(f, w, h=1e-5):
    g = np.zeros_like(w)
    for i in range(len(w)):
        e = np.zeros_like(w)
        e[i] = h
        g[i] = (f(w + e) - f(w - e)) / (2 * h)   # 중앙차분: 오차 O(h²)
    return g

w = np.array([1.0, 2.0, -0.5])
print("해석적 그래디언트:", grad_f(w))
print("수치적 그래디언트:", numerical_grad(f, w).round(6))
print("최대 오차:", np.abs(grad_f(w) - numerical_grad(f, w)).max())

# 시그모이드 도함수 확인: σ'(x) = σ(x)(1-σ(x)), 최댓값 0.25
sig = lambda x: 1 / (1 + np.exp(-x))
xs = np.linspace(-6, 6, 1201)
d = sig(xs) * (1 - sig(xs))
print("σ'(x) 최댓값:", d.max().round(4), "at x =", xs[d.argmax()].round(3))

최적화

머신러닝 학습은 하나의 최적화 문제입니다. 데이터에서 계산한 손실 $L(\theta)$를 가장 작게 만드는 파라미터 $\theta^*$를 찾는 것이며, 거의 모든 딥러닝 모델은 이 문제를 경사하강법 계열로 풉니다.

$$\theta^*=\operatorname*{argmin}_{\theta}\;\underbrace{\frac1n\sum_{i=1}^{n}\ell\big(f_\theta(\mathbf{x}_i),\,y_i\big)}_{\text{경험적 위험 (empirical risk)}}+\underbrace{\lambda\,R(\theta)}_{\text{규제}}$$

3.1경사하강법 (Gradient Descent)

핵심 공식 · 경사하강 갱신 $$\theta_{t+1}=\theta_t-\eta\,\nabla_\theta L(\theta_t)$$

$\eta$는 학습률(learning rate). 2.5절의 1차 테일러 근사에서 $L(\theta-\eta\nabla L)\approx L(\theta)-\eta\|\nabla L\|^2$ 이므로 $\eta$가 충분히 작으면 손실은 항상 줄어듭니다.

주의 · 학습률 진단

손실이 NaN이 되거나 튀면 학습률이 너무 큰 것이고, 손실이 아주 천천히만 줄면 너무 작은 것입니다. 실무에서는 워밍업(warmup) 후 코사인 감쇠(cosine decay) 같은 학습률 스케줄을 함께 씁니다.

3.3볼록성 (Convexity)

정의 · 볼록 함수

모든 $\mathbf{x},\mathbf{y}$와 $t\in[0,1]$에 대해 다음이 성립하면 $f$는 볼록입니다. 두 점을 잇는 선분(할선)이 항상 그래프 위에 있다는 뜻입니다.

$$f\big(t\mathbf{x}+(1-t)\mathbf{y}\big)\le t\,f(\mathbf{x})+(1-t)\,f(\mathbf{y})$$

두 번 미분 가능하면 헤시안이 모든 점에서 양반정치($H\succeq0$)인 것과 같습니다.

문제볼록 여부결과
선형회귀 (MSE), Ridge볼록 (Ridge는 강볼록)닫힌 해 존재, 유일한 최적해
로지스틱 회귀, Lasso, SVM볼록전역 최적해 보장
심층 신경망비볼록보장 없음. 하지만 고차원에서는 대부분의 지역 최솟값이 전역과 비슷한 성능

3.4제약 최적화와 규제

"$g(\mathbf{x})=0$을 지키면서 $f(\mathbf{x})$를 최소화"하는 문제는 라그랑주 승수 $\lambda$를 도입한 라그랑지안의 임계점을 찾아 풉니다. 최적점에서 두 함수의 그래디언트는 평행합니다.

$$\mathcal{L}(\mathbf{x},\lambda)=f(\mathbf{x})+\lambda\,g(\mathbf{x}),\qquad \nabla f(\mathbf{x}^*)=-\lambda\,\nabla g(\mathbf{x}^*)$$

예: $x+y=1$ 위에서 $x^2+y^2$ 최소화 → $2x=-\lambda,\ 2y=-\lambda$ 이므로 $x=y=\tfrac12$. 부등식 제약이 있으면 KKT 조건으로 일반화되며, SVM의 쌍대 문제가 대표적인 예입니다.

핵심 · 규제 = 제약 최적화

"$\|\mathbf{w}\|\le t$ 안에서 손실 최소화"는 라그랑주 승수를 통해 "손실 $+\lambda\|\mathbf{w}\|$ 최소화"와 동등합니다.

$$\text{Ridge: }\min_{\mathbf{w}}\|X\mathbf{w}-\mathbf{y}\|^2+\lambda\|\mathbf{w}\|_2^2\qquad\text{Lasso: }\min_{\mathbf{w}}\|X\mathbf{w}-\mathbf{y}\|^2+\lambda\|\mathbf{w}\|_1$$
ch3_optimizers.py
import numpy as np

rng = np.random.default_rng(1)
n = 200
X = np.c_[np.ones(n), rng.uniform(-2, 2, (n, 2))]      # 절편 열 포함
true_w = np.array([0.5, 2.0, -1.0])
y = X @ true_w + rng.normal(0, 0.3, n)

def loss_grad(w, Xb, yb):
    r = Xb @ w - yb
    return (r @ r) / len(yb), 2 * Xb.T @ r / len(yb)     # MSE와 그 그래디언트

# 1) 미니배치 SGD + Momentum
w, v = np.zeros(3), np.zeros(3)
lr, beta, B = 0.02, 0.9, 32
for epoch in range(60):
    idx = rng.permutation(n)
    for s in range(0, n, B):
        b = idx[s:s + B]
        _, g = loss_grad(w, X[b], y[b])
        v = beta * v + g
        w -= lr * v
print("SGD+Momentum :", w.round(3), " loss:", round(loss_grad(w, X, y)[0], 4))

# 2) Adam (전체 배치)
w, m, s2 = np.zeros(3), np.zeros(3), np.zeros(3)
lr, b1, b2, eps = 0.05, 0.9, 0.999, 1e-8
for t in range(1, 1001):
    _, g = loss_grad(w, X, y)
    m = b1 * m + (1 - b1) * g
    s2 = b2 * s2 + (1 - b2) * g * g
    m_hat, s_hat = m / (1 - b1 ** t), s2 / (1 - b2 ** t)
    w -= lr * m_hat / (np.sqrt(s_hat) + eps)
print("Adam         :", w.round(3), " loss:", round(loss_grad(w, X, y)[0], 4))

# 3) 정규방정식 (닫힌 해) 및 Ridge
w_ols = np.linalg.solve(X.T @ X, X.T @ y)
lam = 10.0
w_ridge = np.linalg.solve(X.T @ X + lam * np.eye(3), X.T @ y)
print("정규방정식   :", w_ols.round(3))
print("Ridge(λ=10)  :", w_ridge.round(3), " ← 가중치가 0 쪽으로 수축")

CHAPTER 04

확률

분류 모델의 출력은 "고양이일 확률 0.93"이고, 생성 모델은 데이터의 확률분포 자체를 배웁니다. 확률은 AI가 불확실성을 표현하고 계산하는 공용어입니다.

4.1확률의 기초

정의 · 확률의 공리 (Kolmogorov)

표본공간 $\Omega$의 사건 $A$에 대해 (1) $P(A)\ge0$, (2) $P(\Omega)=1$, (3) 서로소인 사건들에 대해 $P\left(\bigcup_i A_i\right)=\sum_iP(A_i)$.

법칙공식설명
여사건$P(A^c)=1-P(A)$"적어도 하나"를 계산할 때 유용
덧셈 법칙$P(A\cup B)=P(A)+P(B)-P(A\cap B)$겹치는 부분은 한 번 뺌
조건부확률$P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}$$B$가 일어난 세계로 범위를 좁힘
곱셈 법칙$P(A\cap B)=P(A\mid B)\,P(B)$연쇄 규칙: $P(x_1,\dots,x_n)=\prod_iP(x_i\mid x_{\lt i})$ → 언어 모델의 기본식
독립$P(A\cap B)=P(A)P(B)$나이브 베이즈의 핵심 가정
전확률 법칙$P(B)=\sum_iP(B\mid A_i)P(A_i)$$A_i$는 $\Omega$의 분할
AI 연결

GPT 같은 자기회귀 언어 모델은 곱셈 법칙의 연쇄 규칙 $P(w_1,\dots,w_T)=\prod_{t}P(w_t\mid w_1,\dots,w_{t-1})$을 그대로 구현합니다. 매 스텝 "다음 토큰의 조건부 분포"를 소프트맥스로 출력합니다.

4.2베이즈 정리

핵심 공식 · 베이즈 정리 $$\underbrace{P(\theta\mid D)}_{\text{사후확률}}=\frac{\overbrace{P(D\mid\theta)}^{\text{가능도}}\;\overbrace{P(\theta)}^{\text{사전확률}}}{\underbrace{P(D)}_{\text{증거}}}\;\propto\;P(D\mid\theta)\,P(\theta)$$

관측(데이터) $D$를 보고 믿음(가설 $\theta$)을 갱신하는 규칙입니다.

$$P(D\mid +)=\frac{0.99\times0.01}{0.99\times0.01+0.05\times0.99}=\frac{0.0099}{0.0594}\approx0.167$$

검사가 99% 정확해도 사후확률은 16.7%에 불과합니다. 사전확률(1%)이 매우 낮기 때문입니다. 이를 기저율 무시(base rate fallacy)라 하며, 불균형 데이터에서 정밀도(precision)가 낮게 나오는 이유와 같습니다.

통계적 추론

확률이 "모델을 알 때 데이터가 어떻게 나올까"를 묻는다면, 통계는 거꾸로 "데이터를 봤을 때 모델은 무엇일까"를 묻습니다. 모델 학습 자체가 통계적 추정입니다.

5.1모집단, 표본, 추정량

모수 (모집단)추정량 (표본)공식불편성
평균 $\mu$표본평균 $\bar x$$\frac1n\sum_ix_i$불편 ($\mathbb{E}[\bar x]=\mu$)
분산 $\sigma^2$표본분산 $s^2$$\frac{1}{n-1}\sum_i(x_i-\bar x)^2$불편
분산 $\sigma^2$MLE 분산 $\hat\sigma^2$$\frac1n\sum_i(x_i-\bar x)^2$편향 ($\mathbb{E}=\frac{n-1}{n}\sigma^2$)
평균의 불확실성표준오차 SE$s/\sqrt n$—
왜 $n-1$로 나누는가

$\bar x$는 데이터에 가장 가깝게 맞춘 값이라 $\sum(x_i-\bar x)^2$는 참 평균을 쓴 $\sum(x_i-\mu)^2$보다 항상 작거나 같습니다. 그 결과 $\mathbb{E}\left[\sum(x_i-\bar x)^2\right]=(n-1)\sigma^2$ 이 되며, $\bar x$를 추정하느라 자유도 1개를 썼다고 해석합니다. NumPy var()의 기본값은 ddof=0(MLE), pandas var()는 ddof=1(불편)입니다.

정의 · 추정량의 평균제곱오차 $$\operatorname{MSE}(\hat\theta)=\mathbb{E}\big[(\hat\theta-\theta)^2\big]=\underbrace{\big(\mathbb{E}[\hat\theta]-\theta\big)^2}_{\text{편향}^2}+\underbrace{\operatorname{Var}(\hat\theta)}_{\text{분산}}$$

5.2대수의 법칙과 중심극한정리

대수의 법칙 (LLN)

표본이 많아지면 표본평균은 모평균으로 수렴합니다.

$$\bar X_n\xrightarrow{n\to\infty}\mu$$

미니배치 손실, 몬테카를로 추정이 작동하는 근거입니다.

중심극한정리 (CLT)

원래 분포가 무엇이든(분산이 유한하면) 표본평균의 분포는 정규분포에 가까워집니다.

$$\frac{\bar X_n-\mu}{\sigma/\sqrt n}\xrightarrow{d}\mathcal{N}(0,1)$$

5.3최대우도추정(MLE)과 최대사후확률(MAP)

핵심 공식 · MLE

관측된 데이터가 나올 확률(가능도)을 최대로 만드는 파라미터를 고릅니다. 곱을 다루기 어려우므로 로그를 취해 합으로 바꿉니다.

$$\hat\theta_{\text{MLE}}=\operatorname*{argmax}_\theta\prod_{i=1}^{n}p(x_i\mid\theta)=\operatorname*{argmax}_\theta\sum_{i=1}^{n}\log p(x_i\mid\theta)=\operatorname*{argmin}_\theta\Big(-\sum_i\log p(x_i\mid\theta)\Big)$$

마지막 항 음의 로그우도(NLL)가 딥러닝 손실함수의 정체입니다.

유도 1 · 베르누이 MLE → 이진 교차엔트로피

$y_i\in\{0,1\}$, 모델 출력 $p_i=P(y_i=1)$ 일 때

$$-\log\prod_ip_i^{y_i}(1-p_i)^{1-y_i}=-\sum_i\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]=\text{BCE}$$

파라미터가 상수 하나 $p$라면 미분해서 0으로 두어 $\hat p=\frac1n\sum y_i$ (성공 비율)을 얻습니다.

유도 2 · 가우시안 MLE → 평균제곱오차

$y_i=f_\theta(\mathbf{x}_i)+\epsilon_i,\;\epsilon_i\sim\mathcal{N}(0,\sigma^2)$ 라고 가정하면

$$-\sum_i\log\mathcal{N}(y_i\mid f_\theta(\mathbf{x}_i),\sigma^2)=\frac{1}{2\sigma^2}\sum_i\big(y_i-f_\theta(\mathbf{x}_i)\big)^2+\frac n2\log(2\pi\sigma^2)$$

$\sigma$가 상수이므로 $\theta$에 대해 최소화하는 것은 MSE 최소화와 같습니다. 같은 방식으로 $\hat\mu=\bar x$, $\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2$ 을 얻습니다.

핵심 공식 · MAP와 규제 $$\hat\theta_{\text{MAP}}=\operatorname*{argmax}_\theta\,p(\theta\mid D)=\operatorname*{argmin}_\theta\Big(\underbrace{-\log p(D\mid\theta)}_{\text{NLL (손실)}}\;\underbrace{-\log p(\theta)}_{\text{규제항}}\Big)$$
사전분포 $p(\theta)$$-\log p(\theta)$대응하는 규제
가우시안 $\mathcal{N}(0,\tau^2)$$\frac{1}{2\tau^2}\|\theta\|_2^2+C$L2 (Ridge, weight decay)
라플라스 $\text{Laplace}(0,b)$$\frac1b\|\theta\|_1+C$L1 (Lasso)
균등 (평평한 사전)상수규제 없음 → MAP = MLE

5.4편향-분산 트레이드오프

모델 $\hat f$의 기대 테스트 오차는 세 부분으로 나뉩니다. 기대값은 서로 다른 학습 데이터셋에 대한 평균입니다.

$$\mathbb{E}\big[(y-\hat f(\mathbf{x}))^2\big]=\underbrace{\big(f(\mathbf{x})-\mathbb{E}[\hat f(\mathbf{x})]\big)^2}_{\text{편향}^2}+\underbrace{\operatorname{Var}\big(\hat f(\mathbf{x})\big)}_{\text{분산}}+\underbrace{\sigma^2}_{\text{노이즈}}$$
상태증상처방
고편향 (과소적합)학습·검증 오차 모두 높음모델 키우기, 특성 추가, 규제 완화, 더 오래 학습
고분산 (과대적합)학습 오차는 낮고 검증 오차는 높음데이터 늘리기·증강, 규제(L2, 드롭아웃), 조기 종료, 앙상블

5.5신뢰구간과 가설검정

정의 · 신뢰구간 $$\bar x\pm z_{\alpha/2}\frac{\sigma}{\sqrt n}\quad(\sigma\text{ 알 때}),\qquad \bar x\pm t_{\alpha/2,\,n-1}\frac{s}{\sqrt n}\quad(\sigma\text{ 모를 때})$$

95% 신뢰구간의 뜻: 같은 절차로 구간을 100번 만들면 약 95번은 참값을 포함합니다. "참값이 이 구간에 있을 확률이 95%"가 아닙니다(빈도주의에서 참값은 고정된 상수).

  • 유의수준 $\alpha$(보통 0.05)를 정하고 검정통계량을 계산 (예: $z=\dfrac{\bar x-\mu_0}{\sigma/\sqrt n}$)

se = x.std(ddof=1) / np.sqrt(len(x))
t_crit = stats.t.ppf(0.975, df=len(x) - 1)
print(f"95% CI: [{x.mean() - t_crit * se:.3f}, {x.mean() + t_crit * se:.3f}]  (t임계값 {t_crit:.3f})")

# ---- 신뢰구간 의미 확인: 1000번 반복하면 약 95%가 참값 5.0을 포함 ----
hits = 0
for _ in range(1000):
    s = rng.normal(5.0, 2.0, 40)
    h = t_crit * s.std(ddof=1) / np.sqrt(40)
    hits += (s.mean() - h <= 5.0 <= s.mean() + h)
print("참값 포함 비율:", hits / 1000)

# ---- 모델 비교: 같은 10개 fold에서 측정한 정확도 → 대응표본 t검정 ----

print(f"(잘못된) 독립 t검정 p = {p2:.4f}  ← fold 간 변동이 섞여 검정력이 떨어짐")

6.1정보량과 엔트로피

정의 · 정보량과 엔트로피

확률 $p$인 사건이 일어났을 때의 정보량(놀라움)은 $I(x)=-\log p(x)$ 입니다. 드문 사건일수록 정보량이 큽니다. 엔트로피는 정보량의 기대값, 곧 분포의 평균적인 불확실성입니다.

$$H(p)=\mathbb{E}_{x\sim p}\big[-\log p(x)\big]=-\sum_xp(x)\log p(x)$$

로그 밑이 2이면 단위는 bit, 자연로그면 nat. $K$개 범주에서 엔트로피는 $0\le H\le\log K$ 이고, 균등분포일 때 최대입니다.

AI 연결

결정트리는 분할 전후의 엔트로피 감소량(정보 이득)이 가장 큰 특성으로 나눕니다. 강화학습의 엔트로피 보너스는 정책이 너무 빨리 한 행동으로 굳지 않도록 탐험을 장려합니다. LLM의 퍼플렉시티 $\text{PPL}=\exp(\text{평균 CE})$ 는 "평균적으로 몇 개의 후보 사이에서 망설이는가"로 해석됩니다.

6.2교차엔트로피와 KL 발산

핵심 공식 $$\underbrace{H(p,q)=-\sum_xp(x)\log q(x)}_{\text{교차엔트로피}}\qquad \underbrace{D_{\text{KL}}(p\,\|\,q)=\sum_xp(x)\log\frac{p(x)}{q(x)}}_{\text{KL 발산}}$$ $$H(p,q)=H(p)+D_{\text{KL}}(p\,\|\,q)$$

$p$는 정답 분포, $q$는 모델 분포. 정답 분포의 엔트로피 $H(p)$는 모델과 무관한 상수이므로, 교차엔트로피를 최소화하는 것은 KL 발산을 최소화하는 것과 같습니다. 또 이것은 범주형 분포의 MLE(5.3절)와도 같습니다.

성질내용
비음수성 (Gibbs 부등식)$D_{\text{KL}}(p\|q)\ge0$, 등호는 $p=q$일 때만
비대칭$D_{\text{KL}}(p\|q)\neq D_{\text{KL}}(q\|p)$ → 거리(metric)가 아님
Forward KL $D(p\|q)$$p\gt0$인 곳에 $q$가 0이면 무한대 → $q$가 모든 모드를 덮으려 함 (mode-covering)
Reverse KL $D(q\|p)$$q$가 $p$의 한 모드에 집중 (mode-seeking) → 변분 추론, VAE
대칭 버전JS 발산 $\tfrac12D(p\|m)+\tfrac12D(q\|m)$, $m=\tfrac12(p+q)$ → 원조 GAN의 목적함수
두 정규분포 사이$D_{\text{KL}}\big(\mathcal{N}(\mu,\sigma^2)\,\|\,\mathcal{N}(0,1)\big)=\tfrac12\left(\mu^2+\sigma^2-1-\ln\sigma^2\right)$ → VAE의 KL 항

예제: 원-핫 정답의 교차엔트로피

정답이 클래스 1인 원-핫 $p=(1,0,0)$ 이고 모델 출력 $q=(0.7,0.2,0.1)$ 이면 $H(p,q)=-\log0.7\approx0.357$ nat. 원-핫에서는 $H(p)=0$ 이라 CE와 KL이 같고, 결국 정답 클래스 확률의 음의 로그만 남습니다.

6.3상호정보량

$$I(X;Y)=D_{\text{KL}}\big(p(x,y)\,\|\,p(x)p(y)\big)=H(X)-H(X\mid Y)$$

import numpy as np

def entropy(p, base=2):
    p = np.asarray(p, float)
    p = p[p > 0]
    return -np.sum(p * np.log(p)) / np.log(base)

def cross_entropy(p, q):
    return -np.sum(p * np.log(q))

def kl(p, q):
    return np.sum(p * np.log(p / q))

p = np.array([0.7, 0.2, 0.1])
q = np.array([0.5, 0.3, 0.2])
print("H(p) =", entropy(p).round(4), "bits | 균등분포 최대 =", np.log2(3).round(4))
print("H(p,q) =", cross_entropy(p, q).round(4), "= H(p) + KL =", (cross_entropy(p, p) + kl(p, q)).round(4))
print("KL(p||q) =", kl(p, q).round(4), "| KL(q||p) =", kl(q, p).round(4), "← 비대칭")

# ---- softmax + CE 의 그래디언트는 softmax(z) - y ----
def softmax(z):
    e = np.exp(z - z.max())          # 오버플로 방지 (값은 동일)
    return e / e.sum()

z = np.array([2.0, 1.0, -1.0])
y = np.array([1.0, 0.0, 0.0])
loss = lambda z: -np.sum(y * np.log(softmax(z)))
h, I = 1e-5, np.eye(3)
num = np.array([(loss(z + h * I[i]) - loss(z - h * I[i])) / (2 * h) for i in range(3)])

print("해석적 ∂L/∂z:", (softmax(z) - y).round(5), "| 수치적:", num.round(5))

closed = 0.5 * (mu**2 + sig**2 - 1 - np.log(sig**2))

7.1선형회귀

핵심 공식 · 정규방정식

모델 $\hat{\mathbf{y}}=X\mathbf{w}$, 손실 $L(\mathbf{w})=\|X\mathbf{w}-\mathbf{y}\|^2$. 2.4절 공식으로 미분해 0으로 두면

$$\nabla_{\mathbf{w}}L=2X^\top(X\mathbf{w}-\mathbf{y})=0\;\Longrightarrow\;\hat{\mathbf{w}}=(X^\top X)^{-1}X^\top\mathbf{y}$$

Ridge는 $\hat{\mathbf{w}}=(X^\top X+\lambda I)^{-1}X^\top\mathbf{y}$. $\lambda I$를 더하면 $X^\top X$가 특이(역행렬 없음)여도 항상 역행렬이 존재합니다.

지표공식해석
결정계수 $R^2$$1-\dfrac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$평균만 쓰는 모델 대비 설명한 분산 비율
조정 $R^2$$1-(1-R^2)\dfrac{n-1}{n-p-1}$특성 수 $p$ 증가에 대한 페널티
계수의 분산$\operatorname{Var}(\hat{\mathbf{w}})=\sigma^2(X^\top X)^{-1}$다중공선성이면 $X^\top X$가 특이에 가까워져 분산 폭발

7.2로지스틱 회귀와 소프트맥스 회귀

이진 · 로지스틱 회귀 $$p=\sigma(\mathbf{w}^\top\mathbf{x}+b)$$ $$L=-\big[y\log p+(1-y)\log(1-p)\big]$$ $$\frac{\partial L}{\partial\mathbf{w}}=(p-y)\,\mathbf{x}$$
다중 · 소프트맥스 회귀 $$p_k=\frac{e^{z_k}}{\sum_je^{z_j}},\;\;\mathbf{z}=W\mathbf{x}+\mathbf{b}$$ $$L=-\sum_ky_k\log p_k$$ $$\frac{\partial L}{\partial\mathbf{z}}=\mathbf{p}-\mathbf{y}$$

두 경우 모두 그래디언트가 "예측 − 정답"이라는 매우 깔끔한 형태입니다. 시그모이드·소프트맥스의 미분이 로그 손실의 미분과 상쇄되기 때문이며, 이 조합이 표준이 된 이유입니다. 로지스틱 회귀의 로짓 $\mathbf{w}^\top\mathbf{x}+b$는 로그 오즈 $\log\frac{p}{1-p}$이고, 결정 경계 $\mathbf{w}^\top\mathbf{x}+b=0$은 초평면입니다.

유도 · 소프트맥스 + CE 그래디언트

소프트맥스의 야코비안은 $\dfrac{\partial p_k}{\partial z_j}=p_k(\delta_{kj}-p_j)$. 연쇄법칙과 $\sum_ky_k=1$을 쓰면

$$\frac{\partial L}{\partial z_j}=-\sum_k\frac{y_k}{p_k}\,p_k(\delta_{kj}-p_j)=-y_j+p_j\sum_ky_k=p_j-y_j$$
주의 · 수치 안정성

$e^{z}$는 $z=1000$이면 오버플로가 납니다. 소프트맥스는 모든 $z_k$에서 $\max_j z_j$를 빼도 값이 같으므로 항상 빼고 계산합니다. 로그 소프트맥스는 $\log p_k=z_k-\operatorname{logsumexp}(\mathbf{z})$ 로 계산합니다. 프레임워크의 CrossEntropyLoss가 확률이 아닌 로짓을 입력받는 이유입니다.

7.3신경망과 역전파

$L$층 신경망의 순전파는 선형변환과 비선형 활성함수의 반복입니다. 활성함수가 없으면 아무리 쌓아도 하나의 선형변환($W_L\cdots W_1$)일 뿐입니다.

$$\mathbf{z}^{(l)}=W^{(l)}\mathbf{a}^{(l-1)}+\mathbf{b}^{(l)},\qquad\mathbf{a}^{(l)}=\phi\big(\mathbf{z}^{(l)}\big),\qquad \mathbf{a}^{(0)}=\mathbf{x}$$
핵심 공식 · 역전파 4개 식

오차 신호 $\boldsymbol\delta^{(l)}=\partial L/\partial\mathbf{z}^{(l)}$ 을 출력층부터 거꾸로 전달합니다.

$$\begin{aligned} \boldsymbol\delta^{(L)}&=\nabla_{\mathbf{a}^{(L)}}L\odot\phi'\big(\mathbf{z}^{(L)}\big)\\ \boldsymbol\delta^{(l)}&=\big(W^{(l+1)\top}\boldsymbol\delta^{(l+1)}\big)\odot\phi'\big(\mathbf{z}^{(l)}\big)\\ \frac{\partial L}{\partial W^{(l)}}&=\boldsymbol\delta^{(l)}\,\mathbf{a}^{(l-1)\top},\qquad \frac{\partial L}{\partial\mathbf{b}^{(l)}}=\boldsymbol\delta^{(l)} \end{aligned}$$

순전파에서 저장한 $\mathbf{a}^{(l)}$을 재사용하므로 계산량은 순전파의 약 2배입니다(학습 시 메모리를 많이 쓰는 이유).

노드순전파역전파 규칙
덧셈 $z=x+y$합상위 기울기를 양쪽에 그대로 복사
곱셈 $z=xy$곱상위 기울기 × 상대편 입력 (스위치)

행렬곱 $Y=XW$$XW$$\partial X=\partial Y\,W^\top$, $\;\partial W=X^\top\partial Y$
ReLU$\max(0,x)$$x>0$인 위치만 기울기 통과

import numpy as np

rng = np.random.default_rng(0)

# 데이터: 원 안쪽(1) / 바깥쪽(0) 이진분류 — 선형 모델로는 풀 수 없음
X = rng.uniform(-1, 1, (400, 2))
y = (np.sum(X ** 2, axis=1) < 0.5).astype(float).reshape(-1, 1)

# 2 → 16 → 1 신경망, He 초기화: Var(w) = 2 / fan_in
W1 = rng.normal(0, np.sqrt(2 / 2), (2, 16));  b1 = np.zeros((1, 16))
W2 = rng.normal(0, np.sqrt(2 / 16), (16, 1)); b2 = np.zeros((1, 1))
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 0.5

for step in range(3001):
    # ---- 순전파 ----
    Z1 = X @ W1 + b1
    A1 = np.maximum(0, Z1)                       # ReLU
    Z2 = A1 @ W2 + b2
    P = sigmoid(Z2)
    loss = -np.mean(y * np.log(P + 1e-12) + (1 - y) * np.log(1 - P + 1e-12))

    # ---- 역전파 (연쇄법칙) ----
    dZ2 = (P - y) / len(X)                       # BCE + sigmoid 결합 미분: p - y
    dW2 = A1.T @ dZ2
    db2 = dZ2.sum(axis=0, keepdims=True)
    dA1 = dZ2 @ W2.T
    dZ1 = dA1 * (Z1 > 0)                         # ReLU 미분
    dW1 = X.T @ dZ1
    db1 = dZ1.sum(axis=0, keepdims=True)

    # ---- 경사하강 갱신 ----
    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2

    if step % 500 == 0:
        acc = ((P > 0.5) == y).mean()
        print(f"step {step:4d} | loss {loss:.4f} | acc {acc:.3f}")

import numpy as np

def softmax(x, axis=-1):
    e = np.exp(x - x.max(axis=axis, keepdims=True))
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, mask=None):
    d_k = Q.shape[-1]
    scores = Q @ K.swapaxes(-1, -2) / np.sqrt(d_k)      # (n, n) 유사도
    if mask is not None:
        scores = np.where(mask, scores, -1e9)             # 가려진 위치 → 확률 0
    W = softmax(scores, axis=-1)
    return W @ V, W

Wq, Wk, Wv = (rng.normal(size=(d_model, d_k)) / np.sqrt(d_model) for _ in range(3))

out, W = attention(X @ Wq, X @ Wk, X @ Wv, mask=causal)
print("출력 shape:", out.shape, "| 가중치 행 합:", W.sum(-1).round(6))
print(W.round(3))

Momentum은 진동 방향의 성분을 상쇄해 수렴 비율을 대략 $\frac{\sqrt\kappa-1}{\sqrt\kappa+1}$로 개선합니다. 이론상 $\kappa=100$에서 0.980이 0.818로 바뀝니다.

A.3스펙트럼 반경: 반복해서 곱하면 크기가 $\rho^T$로 변한다

단순화한 선형 RNN $\mathbf{h}_t=W\mathbf{h}_{t-1}$ 을 보면, $T$ 스텝 뒤의 상태와 처음 상태에 대한 기울기가 모두 $W$를 $T$번 곱한 것입니다.

$$\mathbf{h}_T=W^T\mathbf{h}_0,\qquad \frac{\partial\mathbf{h}_T}{\partial\mathbf{h}_0}=W^T,\qquad \frac{\partial L}{\partial\mathbf{h}_0}=(W^\top)^T\frac{\partial L}{\partial\mathbf{h}_T}$$

$W=Q\Lambda Q^{-1}$로 대각화되면 $W^T=Q\Lambda^TQ^{-1}$ 이므로 각 고유방향 성분은 $\lambda_i^T$배가 됩니다. $T$가 커지면 절댓값이 가장 큰 고유값, 곧 스펙트럼 반경 $\rho(W)=\max_i|\lambda_i|$ 가 전체 크기를 지배합니다.

$$\|W^T\|\approx C\,\rho(W)^T\quad\Longrightarrow\quad\rho\lt1:\ \text{지수적 소실},\qquad \rho>1:\ \text{지수적 폭발}$$

예제 · 회전 + 스케일 행렬

$W=\rho\,R(25^\circ)$ 로 두면 $W$의 고유값은 복소수 $\rho e^{\pm i\,25^\circ}$ 이고 크기는 정확히 $\rho$ 입니다. 매 스텝 25°씩 돌면서 길이가 $\rho$배가 되므로 $\|\mathbf{h}_T\|=\rho^T\|\mathbf{h}_0\|$ 가 정확히 성립합니다.

AI 연결 · 실제 RNN과 해결책

실제 RNN은 $\mathbf{h}_t=\tanh(W\mathbf{h}_{t-1}+U\mathbf{x}_t)$ 이므로 야코비안은 $\operatorname{diag}(1-\mathbf{h}_t^2)\,W$ 입니다. tanh의 미분은 1 이하라 매 스텝 추가로 줄어들므로, 실무에서는 폭발보다 소실이 더 흔합니다.

  • 그래디언트 클리핑: $\|\mathbf{g}\|>c$ 이면 $\mathbf{g}\leftarrow c\,\mathbf{g}/\|\mathbf{g}\|$. 방향은 유지하고 크기만 잘라 폭발을 막습니다.
  • 직교 초기화: $W$를 직교행렬로 시작해 모든 $|\lambda_i|=1$ 로 만듭니다.
  • LSTM·GRU: 셀 상태를 곱셈이 아닌 덧셈 경로($\mathbf{c}_t=\mathbf{f}_t\odot\mathbf{c}_{t-1}+\dots$)로 전달해, 망각 게이트가 1에 가까우면 기울기가 거의 그대로 흐릅니다.
  • 잔차 연결·트랜스포머: 야코비안이 $I+\partial F/\partial\mathbf{x}$ 형태라 고유값이 1 근처에 머물고, 어텐션은 시간 방향의 반복 곱셈 자체를 없앴습니다.

# ===== A.1 양정치 판정: 고유값 · 이차형식 · 촐레스키 =====
mats = {
    "A1 [[2,1],[1,2]]": np.array([[2.0, 1.0], [1.0, 2.0]]),
    "A2 [[1,2],[2,1]]": np.array([[1.0, 2.0], [2.0, 1.0]]),
    "A3 [[1,1],[1,1]]": np.array([[1.0, 1.0], [1.0, 1.0]]),
}
test_x = [np.array(v, float) for v in [(1, 0), (1, 1), (1, -1), (2, -1)]]

def classify(lam, tol=1e-12):
    if np.all(lam > tol):  return "양정치"
    if np.all(lam >= -tol): return "양반정치"
    if np.all(lam < -tol): return "음정치"
    return "부정치"

for name, A in mats.items():
    lam = np.linalg.eigvalsh(A)
    q = [float(x @ A @ x) for x in test_x]
    try:
        np.linalg.cholesky(A); chol = "성공"
    except np.linalg.LinAlgError:
        chol = "실패"
    print(f"{name}: λ={lam.round(3)}  f(x)={q}  촐레스키 {chol} → {classify(lam)}")

def gd_steps(kappa, x0=(-5.0, 1.5), tol=1e-6):
    eta = 2 / (1 + kappa)                  # 최적 고정 학습률
    x = np.array(x0); d = np.array([1.0, kappa]); n = 0
    while 0.5 * np.sum(d * x * x) > tol:
        x = x - eta * d * x                # 그래디언트 = diag(1, κ) x
        n += 1
    return n

for k in [1, 10, 50, 100, 1000]:
    print(f"κ={k:5d}  수렴비율 {(k - 1) / (k + 1):.4f}  스텝 {gd_steps(k)}")
