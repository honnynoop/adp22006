다중회귀 손계산에
표준화는 효과가 있을까

출석일수·공부시간·점수 데이터 10개로 표준화 전후를 나란히 계산합니다. 예측과 검정 결과는 하나도 바뀌지 않고, 계수의 의미와 계산의 형태만 바뀐다는 것을 수식과 숫자로 확인합니다.

\[\beta_j^*=b_j\cdot\frac{s_{x_j}}{s_y}\qquad\Longleftrightarrow\qquad b_j=\beta_j^*\cdot\frac{s_y}{s_{x_j}}\]

표준화는 모형의 성능을 바꾸지 않습니다. 바뀌는 것은 계수의 해석(변수끼리 영향력 비교 가능)과 계산의 형태(상관계수만으로 풀림, 수치적으로 안정)입니다. 경사하강법으로 학습하는 MLP와 달리, 닫힌 해를 쓰는 OLS에서는 표준화가 결과에 영향을 주지 않습니다.

2원자료 회귀 복습

앞의 손계산에서 구한 평균과 편차 제곱합·곱의 합입니다.

\[\bar x_1=24.3,\quad \bar x_2=8.6,\quad \bar y=71.9\]
\[S_{11}=122.1,\;S_{22}=92.4,\;S_{12}=41.2,\;S_{1y}=275.3,\;S_{2y}=284.6,\;S_{yy}=1156.9\]

이 값으로 구한 회귀식은 다음과 같았습니다.

\[\hat y=16.1325+1.4306\,x_1+2.4422\,x_2\]

편차를 쓰는 풀이는 이미 평균을 빼서 절편을 소거한 방식입니다. 표준화는 여기서 한 걸음 더 나아가 표준편차로 나누는 것입니다.

3데이터 표준화

\[z_{1i}=\frac{x_{1i}-\bar x_1}{s_{x_1}},\qquad z_{2i}=\frac{x_{2i}-\bar x_2}{s_{x_2}},\qquad z_{yi}=\frac{y_i-\bar y}{s_y}\]

4상관행렬 방정식

표준화된 변수끼리의 편차곱 합을 \(n-1\)로 나누면 그대로 상관계수가 됩니다. 그래서 정규방정식이 상관계수 3개만으로 표현됩니다.

\[r_{12}=\frac{S_{12}}{\sqrt{S_{11}S_{22}}}=\frac{ 41.2 }{\sqrt{ 122.1\times92.4 }}=0.3879\]
\[r_{1y}=\frac{S_{1y}}{\sqrt{S_{11}S_{yy}}}=\frac{ 275.3 }{\sqrt{ 122.1\times1156.9 }}=0.7325,\qquad r_{2y}=\frac{S_{2y}}{\sqrt{S_{22}S_{yy}}}=\frac{ 284.6 }{\sqrt{ 92.4\times1156.9 }}=0.8705\]

표준화 후에는 모든 평균이 0이므로 절편 \(\beta_0^*=0\)이고, 풀 식은 2×2 하나뿐입니다.

\[\begin{bmatrix}1&r_{12}\\ r_{12}&1\end{bmatrix}\begin{bmatrix}\beta_1^*\\ \beta_2^*\end{bmatrix}=\begin{bmatrix}r_{1y}\\ r_{2y}\end{bmatrix} \;\Longrightarrow\; \begin{bmatrix}1&0.3879\\ 0.3879&1\end{bmatrix}\begin{bmatrix}\beta_1^*\\ \beta_2^*\end{bmatrix}=\begin{bmatrix}0.7325\\ 0.8705\end{bmatrix}\]

풀이

\[1-r_{12}^2=1-0.1505=0.8495\]
\[\beta_1^*=\frac{r_{1y}-r_{12}r_{2y}}{1-r_{12}^2}=\frac{ 0.7325-0.3376 }{ 0.8495 }=\frac{ 0.3948 }{ 0.8495 }=0.4648\]
\[\beta_2^*=\frac{r_{2y}-r_{12}r_{1y}}{1-r_{12}^2}=\frac{ 0.8705-0.2841 }{ 0.8495 }=\frac{ 0.5863 }{ 0.8495 }=0.6902\]

상관행렬의 역행렬로 써도 같습니다.

\[\boldsymbol\beta^*=R^{-1}\mathbf r_{xy},\qquad R^{-1}=\begin{bmatrix}1.1771&-0.4566\\-0.4566&1.1771\end{bmatrix}\]

결정계수도 상관계수로

\[R^2=\beta_1^*r_{1y}+\beta_2^*r_{2y}=0.3404+0.6008=0.9412\]

원자료에서 SSR/SST로 구한 값과 같습니다.

5원래 단위로 복원

표준화 계수에 \(s_y/s_{x_j}\)를 곱하면 원래 계수로 돌아옵니다.

\[b_1=\beta_1^*\cdot\frac{s_y}{s_{x_1}}=0.4648\times3.0782=1.4306,\qquad b_2=\beta_2^*\cdot\frac{s_y}{s_{x_2}}=0.6902\times3.5384=2.4422\]
\[b_0=\bar y-b_1\bar x_1-b_2\bar x_2=71.9-34.7648-21.0027=16.1325\]

원자료로 직접 푼 회귀식과 소수점 넷째 자리까지 일치합니다. 두 풀이는 같은 식을 다른 단위로 적은 것일 뿐입니다.

6바뀌지 않는 값

SSE와 R²

표준화 공간의 잔차는 원래 잔차를 \(s_y\)로 나눈 것이므로, SSE는 \(s_y^2\)배 차이만 납니다.

\[\text{SSE}^*=0.5290,\qquad \text{SSE}^*\times s_y^2=67.9984=\text{SSE}_{원자료}=67.9984\]

R²는 SSE와 SST가 같은 비율로 커지거나 작아지므로 비율이 그대로입니다.

t값

계수와 표준오차가 똑같이 \(s_{x_j}/s_y\)배가 되므로 둘의 비율인 t값은 변하지 않습니다.

\[t_1=\frac{b_1}{\text{SE}(b_1)}=\frac{ 1.4306 }{ 0.3060 }=4.6750,\qquad t_1^*=\frac{\beta_1^*}{\text{SE}(\beta_1^*)}=\frac{ 0.4648 }{ 0.0994 }=4.6750\]
\[t_2=\frac{ 2.4422 }{ 0.3518 }=6.9423,\qquad t_2^*=\frac{ 0.6902 }{ 0.0994 }=6.9423\]

t값이 같으니 p값과 유의성 판단도 같습니다. F값도 SSR과 SSE의 비율이라 그대로입니다.

7테스트 예측 비교

테스트 데이터는 학습 데이터의 평균·표준편차로 표준화하고, 예측한 뒤 점수 단위로 되돌립니다.

테스트 T1 — 출석 21일, 공부 7시간

\[z_1=\frac{21-24.3}{3.6833}=-0.8959,\qquad z_2=\frac{7-8.6}{3.2042}=-0.4994\]
\[\hat z_y=0.4648\times(-0.8959)+0.6902\times(-0.4994)=-0.7611\]
\[\hat y=\hat z_y\cdot s_y+\bar y=-0.7611\times11.3377+71.9=63.2714\]

테스트 T2 — 출석 25일, 공부 10시간

\[z_1=\frac{25-24.3}{3.6833}=0.1900,\qquad z_2=\frac{10-8.6}{3.2042}=0.4369\]
\[\hat z_y=0.4648\times(0.1900)+0.6902\times(0.4369)=0.3899\]
\[\hat y=\hat z_y\cdot s_y+\bar y=0.3899\times11.3377+71.9=76.3205\]

테스트 T3 — 출석 29일, 공부 13시간

\[z_1=\frac{29-24.3}{3.6833}=1.2760,\qquad z_2=\frac{13-8.6}{3.2042}=1.3732\]
\[\hat z_y=0.4648\times(1.2760)+0.6902\times(1.3732)=1.5408\]
\[\hat y=\hat z_y\cdot s_y+\bar y=1.5408\times11.3377+71.9=89.3696\]

8변수 중요도 비교

표준화의 가장 실질적인 효과입니다. 원자료 계수는 "출석 1일당 1.4306점", "공부 1시간당 2.4422점"이라 단위가 달라서 크기를 직접 비교할 수 없습니다.

단위를 바꾸면 원자료 계수는 흔들린다

공부시간을 "시간" 대신 "분"으로 기록했다고 해 봅시다.

공부시간 단위원자료 계수 b₂표준편차 s_x₂표준화 계수 β₂*
시간2.44223.20420.6902

원자료 계수만 보면 분 단위일 때 공부시간이 출석(1.4306)보다 훨씬 덜 중요해 보이지만, 표준화 계수는 단위와 무관하게 0.6902로 그대로입니다. 이번 데이터에서는 공부시간(0.6902)이 출석(0.4648)보다 점수에 더 큰 영향을 줍니다.

주의 — 표준화 계수 비교는 설명변수끼리 상관이 약할 때 믿을 만합니다. 이번 데이터는 \(r_{12}=0.3879\)로 약한 편이라 해석해도 무리가 없지만, 다중공선성이 심하면 표준화 계수도 불안정해집니다.

9수치 안정성

조건수는 행렬의 가장 큰 고유값과 가장 작은 고유값의 비율로, 클수록 역행렬 계산에서 반올림 오차가 크게 증폭됩니다.

\[\kappa(X^\top X)=33628.6\qquad\longrightarrow\qquad \kappa(R)=2.2674\]

원자료의 \(X^\top X\)에는 10 같은 작은 값과 6027 같은 큰 값이 섞여 있어 조건수가 큽니다. 상관행렬은 모든 원소가 −1~1 사이라 조건수가 작습니다. 손계산에서는 소수점을 몇 자리까지 들고 가느냐에 따라 원자료 역행렬 결과가 흔들릴 수 있지만, 상관행렬 풀이는 반올림에 훨씬 덜 민감합니다.

10Python 검증

numpy와 statsmodels로 원자료 회귀와 표준화 회귀를 나란히 실행합니다.

import numpy as np
import statsmodels.api as sm

# 학습 데이터 10개: [출석일수, 공부시간], 점수
X = np.array([[18, 6], [20, 10], [22, 4], [23, 8], [24, 12],
              [25, 5], [26, 9], [27, 14], [28, 7], [30, 11]], dtype=float)
y = np.array([55, 72, 60, 65, 82, 61, 77, 85, 74, 88], dtype=float)
X_test = np.array([[21, 7], [25, 10], [29, 13]], dtype=float)

# 1) 원자료 회귀
raw = sm.OLS(y, sm.add_constant(X)).fit()

# 2) 표준화 회귀 (학습 데이터의 평균·표본표준편차 사용)
mx, sx = X.mean(0), X.std(0, ddof=1)
my, sy = y.mean(), y.std(ddof=1)
Zx, zy = (X - mx) / sx, (y - my) / sy
std = sm.OLS(zy, sm.add_constant(Zx)).fit()

print("원자료 계수 b0,b1,b2 :", np.round(raw.params, 4))
print("표준화 계수 b0*,b1*,b2*:", np.round(std.params, 4) + 0.0)
print("상관행렬로 직접 계산   :", np.round(np.linalg.solve(np.corrcoef(X.T), np.corrcoef(X.T, y)[:2, 2]), 4))

# 3) 표준화 계수 → 원래 단위로 복원
b = std.params[1:] * sy / sx
b0 = my - (b * mx).sum()
print("복원한 b0,b1,b2       :", np.round([b0, *b], 4))

# 4) 바뀌지 않는 값들
print("R^2      원자료 / 표준화:", round(raw.rsquared, 4), round(std.rsquared, 4))
print("F        원자료 / 표준화:", round(raw.fvalue, 4), round(std.fvalue, 4))
print("t(b1,b2) 원자료 :", np.round(raw.tvalues[1:], 4))
print("t(b1,b2) 표준화 :", np.round(std.tvalues[1:], 4))

# 5) 테스트 예측: 표준화 공간에서 예측 후 되돌리기
zt = (X_test - mx) / sx
pred_std = std.predict(sm.add_constant(zt, has_constant="add")) * sy + my
pred_raw = raw.predict(sm.add_constant(X_test, has_constant="add"))
print("테스트 예측 원자료:", np.round(pred_raw, 4))
print("테스트 예측 표준화:", np.round(pred_std, 4))

# 6) 조건수 비교
Xd = sm.add_constant(X)
print("조건수 X'X  :", round(np.linalg.cond(Xd.T @ Xd), 1))
print("조건수 상관행렬:", round(np.linalg.cond(np.corrcoef(X.T)), 4))

11언제 표준화할까

상황표준화이유
예측값만 필요불필요결과가 같고 원자료 풀이가 더 간단
"어느 변수가 더 중요한가"필요표준화 계수라야 단위 없이 비교 가능
문제에 상관계수만 주어짐유리β* 공식에 바로 대입
변수 크기 차이가 매우 큼유리조건수가 줄어 반올림 오차 감소
Ridge, Lasso필수벌점이 계수 크기에 걸려 단위에 따라 결과가 달라짐
경사하강법, MLP필수에 가까움학습 속도와 안정성에 직접 영향

손계산 자체는 쉬워지지 않습니다. 편차 풀이도 이미 2×2 문제였고, 표준화는 상관계수를 구하는 제곱근 계산이 더해질 뿐입니다. 표준화의 가치는 계산의 편의가 아니라 계수를 비교 가능한 척도로 바꿔 준다는 데 있습니다.
