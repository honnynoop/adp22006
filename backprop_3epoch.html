0. 문제 설정

선 색은 도착 뉴런 기준(첫째 뉴런 / 둘째 뉴런). w⁽ˡ⁾ⱼᵢ = 앞 층 i번째 → l층 j번째 뉴런, 즉 행렬 W⁽ˡ⁾의 (j행, i열) 원소. b = 각 뉴런의 편향.

학습 데이터(샘플 1개): \(x = (x_1,x_2,x_3) = (1.0,\ 0.5,\ -1.0),\quad y = 1.0\),  학습률 \(\eta = 0.1\)

표기: \(w^{(l)}_{ji}\) = 앞 층 i번째 뉴런 → l층 j번째 뉴런으로 가는 가중치. 초기 파라미터:

\(W^{(1)} = \begin{bmatrix}0.5 & 0.2 & -0.3 \\ -0.2 & 0.4 & -0.1\end{bmatrix}\)
\(b^{(1)} = \begin{bmatrix}0.1 \\ 0.1\end{bmatrix}\)
\(W^{(2)} = \begin{bmatrix}0.3 & -0.2 \\ 0.4 & 0.1\end{bmatrix}\)
\(b^{(2)} = \begin{bmatrix}0.05 \\ -0.05\end{bmatrix}\)
\(w^{(3)\top} = \begin{bmatrix}0.5 & 0.4\end{bmatrix}\)
\(b^{(3)} = 0.1\)

반올림 규칙. 모든 곱셈·제곱 결과는 소수 6자리 반올림(사사오입)하여 표시하고, 다음 단계에서는 표시된 그 값을 그대로 사용합니다. 덧셈·뺄셈은 반올림이 필요 없으므로, 페이지에 적힌 숫자로 손계산하면 결과가 마지막 자리까지 일치합니다.

수식 정리

순전파

\[z^{(1)} = W^{(1)}x + b^{(1)},\qquad a^{(1)} = \mathrm{ReLU}(z^{(1)})\]
\[z^{(2)} = W^{(2)}a^{(1)} + b^{(2)},\qquad a^{(2)} = \mathrm{ReLU}(z^{(2)})\]
\[\hat y = z^{(3)} = w^{(3)\top}a^{(2)} + b^{(3)},\qquad L = \tfrac12 (y-\hat y)^2\]
\[\mathrm{ReLU}(z)=\max(0,z),\qquad \mathrm{ReLU}'(z)=\begin{cases}1 & z>0\\ 0 & z\le 0\end{cases}\]

역전파 (연쇄법칙)

\[\delta^{(3)} = \frac{\partial L}{\partial z^{(3)}} = \hat y - y,\qquad \frac{\partial L}{\partial w^{(3)}_j} = \delta^{(3)}a^{(2)}_j,\qquad \frac{\partial L}{\partial b^{(3)}} = \delta^{(3)}\]
\[\delta^{(2)}_j = \frac{\partial L}{\partial z^{(2)}_j} = w^{(3)}_j\,\delta^{(3)}\,\mathrm{ReLU}'(z^{(2)}_j),\qquad \frac{\partial L}{\partial w^{(2)}_{jk}} = \delta^{(2)}_j a^{(1)}_k,\qquad \frac{\partial L}{\partial b^{(2)}_j} = \delta^{(2)}_j\]
\[\delta^{(1)}_k = \frac{\partial L}{\partial z^{(1)}_k} = \Big(\sum_{j} w^{(2)}_{jk}\,\delta^{(2)}_j\Big)\mathrm{ReLU}'(z^{(1)}_k),\qquad \frac{\partial L}{\partial w^{(1)}_{ki}} = \delta^{(1)}_k x_i,\qquad \frac{\partial L}{\partial b^{(1)}_k} = \delta^{(1)}_k\]

행렬 형태로 쓰면

\[\delta^{(2)} = (w^{(3)}\delta^{(3)})\odot \mathrm{ReLU}'(z^{(2)}),\quad \delta^{(1)} = (W^{(2)\top}\delta^{(2)})\odot \mathrm{ReLU}'(z^{(1)}),\quad \frac{\partial L}{\partial W^{(l)}} = \delta^{(l)}\,a^{(l-1)\top}\]

예) 첫 번째 가중치 하나를 끝까지 풀어 쓰면 모든 경로의 합이 됩니다.

\[\frac{\partial L}{\partial w^{(1)}_{11}} = \sum_{j=1}^{2}\underbrace{\frac{\partial L}{\partial \hat y}}_{\hat y-y}\underbrace{\frac{\partial \hat y}{\partial a^{(2)}_j}}_{w^{(3)}_j}\underbrace{\frac{\partial a^{(2)}_j}{\partial z^{(2)}_j}}_{\mathrm{ReLU}'}\underbrace{\frac{\partial z^{(2)}_j}{\partial a^{(1)}_1}}_{w^{(2)}_{j1}}\underbrace{\frac{\partial a^{(1)}_1}{\partial z^{(1)}_1}}_{\mathrm{ReLU}'}\underbrace{\frac{\partial z^{(1)}_1}{\partial w^{(1)}_{11}}}_{x_1}\]

갱신

\[\theta \leftarrow \theta - \eta\,\frac{\partial L}{\partial \theta}\]

δ 식이 어떻게 나오는지는 역전파 유도에서 한 단계씩 풀었습니다.

역전파 유도 — δ는 어디서 나오는가

0. δ를 정의하는 이유

각 층의 가중합 z에 대한 손실의 미분을 오차 신호 δ라고 정의합니다.

\[\delta^{(l)}_j \;\equiv\; \frac{\partial L}{\partial z^{(l)}_j}\]

δ만 알면 가중치 기울기는 바로 나옵니다. \(z^{(l)}_j = \sum_i w^{(l)}_{ji}\,a^{(l-1)}_i + b^{(l)}_j\) 이므로 \(z^{(l)}_j\)를 \(w^{(l)}_{ji}\)로 미분하면 그 가중치에 곱해진 입력만 남습니다.

\[\frac{\partial L}{\partial w^{(l)}_{ji}} = \frac{\partial L}{\partial z^{(l)}_j}\cdot\frac{\partial z^{(l)}_j}{\partial w^{(l)}_{ji}} = \delta^{(l)}_j\, a^{(l-1)}_i,\qquad \frac{\partial L}{\partial b^{(l)}_j} = \delta^{(l)}_j\cdot 1\]

그래서 역전파는 출력층부터 δ를 하나씩 뒤로 구해 가는 과정입니다.

1. 재료가 되는 국소 미분

\[\frac{\partial L}{\partial \hat y} = \frac{\partial}{\partial \hat y}\tfrac12(y-\hat y)^2 = (y-\hat y)\cdot(-1) = \hat y - y\]
\[z^{(3)} = w^{(3)}_1 a^{(2)}_1 + w^{(3)}_2 a^{(2)}_2 + b^{(3)} \;\Rightarrow\; \frac{\partial z^{(3)}}{\partial a^{(2)}_j} = w^{(3)}_j\]
\[z^{(2)}_j = w^{(2)}_{j1}a^{(1)}_1 + w^{(2)}_{j2}a^{(1)}_2 + b^{(2)}_j \;\Rightarrow\; \frac{\partial z^{(2)}_j}{\partial a^{(1)}_k} = w^{(2)}_{jk}\]
\[a = \mathrm{ReLU}(z) = \max(0,z) \;\Rightarrow\; \frac{\partial a}{\partial z} = \mathrm{ReLU}'(z) = \begin{cases}1 & z>0 \\ 0 & z\le 0\end{cases}\]

z=0에서는 미분이 정의되지 않지만, 관례상 0으로 둡니다(PyTorch도 동일).

2. 출력층 δ⁽³⁾

출력층은 선형이라 \(\hat y = z^{(3)}\), 즉 \(\partial \hat y/\partial z^{(3)} = 1\)입니다.

\[\delta^{(3)} = \frac{\partial L}{\partial z^{(3)}} = \frac{\partial L}{\partial \hat y}\cdot\frac{\partial \hat y}{\partial z^{(3)}} = (\hat y - y)\cdot 1 = \hat y - y\]

3. 은닉층 2의 δ⁽²⁾ — 경로가 하나

\(z^{(2)}_j\)가 손실에 닿는 길은 \(z^{(2)}_j \to a^{(2)}_j \to z^{(3)} \to L\) 하나뿐입니다(출력 뉴런이 1개). 이 길을 따라 국소 미분을 곱합니다.

\[\delta^{(2)}_j = \frac{\partial L}{\partial z^{(2)}_j} = \underbrace{\frac{\partial L}{\partial z^{(3)}}}_{\delta^{(3)}}\cdot\underbrace{\frac{\partial z^{(3)}}{\partial a^{(2)}_j}}_{w^{(3)}_j}\cdot\underbrace{\frac{\partial a^{(2)}_j}{\partial z^{(2)}_j}}_{\mathrm{ReLU}'(z^{(2)}_j)} = w^{(3)}_j\,\delta^{(3)}\,\mathrm{ReLU}'(z^{(2)}_j)\]

뉴런별로 쓰면

\[\delta^{(2)}_1 = w^{(3)}_1\,\delta^{(3)}\,\mathrm{ReLU}'(z^{(2)}_1),\qquad \delta^{(2)}_2 = w^{(3)}_2\,\delta^{(3)}\,\mathrm{ReLU}'(z^{(2)}_2)\]

핵심은 \(\partial L/\partial z^{(3)}\)를 다시 계산하지 않고 이미 구한 δ⁽³⁾를 재사용한다는 점입니다.

4. 은닉층 1의 δ⁽¹⁾ — 경로가 둘 (다변수 연쇄법칙)

\(a^{(1)}_k\)는 은닉층 2의 두 뉴런 모두에 들어갑니다. 그래서 손실에 닿는 길이 두 개이고, 다변수 연쇄법칙에 따라 각 경로의 기여를 더해야 합니다. 아래 그림은 k=1인 경우의 두 경로입니다.

\[\frac{\partial L}{\partial a^{(1)}_k} = \frac{\partial L}{\partial z^{(2)}_1}\cdot\frac{\partial z^{(2)}_1}{\partial a^{(1)}_k} + \frac{\partial L}{\partial z^{(2)}_2}\cdot\frac{\partial z^{(2)}_2}{\partial a^{(1)}_k} = \delta^{(2)}_1\,w^{(2)}_{1k} + \delta^{(2)}_2\,w^{(2)}_{2k}\]

마지막으로 ReLU 한 칸을 더 거슬러 올라갑니다.

\[\delta^{(1)}_k = \frac{\partial L}{\partial z^{(1)}_k} = \frac{\partial L}{\partial a^{(1)}_k}\cdot\frac{\partial a^{(1)}_k}{\partial z^{(1)}_k} = \Big(w^{(2)}_{1k}\,\delta^{(2)}_1 + w^{(2)}_{2k}\,\delta^{(2)}_2\Big)\,\mathrm{ReLU}'(z^{(1)}_k)\]

여기서도 \(\partial L/\partial z^{(2)}_j\)는 앞 단계에서 구한 δ⁽²⁾를 그대로 씁니다. δ⁽²⁾를 대입해 끝까지 풀면 그림의 두 경로가 그대로 보입니다.

\[\delta^{(1)}_1 = \Big[\underbrace{(\hat y-y)\,w^{(3)}_1\,\mathrm{ReLU}'(z^{(2)}_1)\,w^{(2)}_{11}}_{\text{위쪽 경로}} + \underbrace{(\hat y-y)\,w^{(3)}_2\,\mathrm{ReLU}'(z^{(2)}_2)\,w^{(2)}_{21}}_{\text{아래쪽 경로}}\Big]\mathrm{ReLU}'(z^{(1)}_1)\]

5. 행렬로 묶으면 왜 전치(ᵀ)가 붙는가

\(\delta^{(1)}_k\)의 합은 \(\sum_j w^{(2)}_{jk}\delta^{(2)}_j\), 즉 W⁽²⁾의 k번째 열과 δ⁽²⁾의 내적입니다. 열을 행처럼 쓰려면 전치가 필요합니다.

\[\begin{bmatrix}\delta^{(1)}_1\\ \delta^{(1)}_2\end{bmatrix} = \left(\begin{bmatrix} w^{(2)}_{11} & w^{(2)}_{21}\\ w^{(2)}_{12} & w^{(2)}_{22}\end{bmatrix}\begin{bmatrix}\delta^{(2)}_1\\ \delta^{(2)}_2\end{bmatrix}\right)\odot\begin{bmatrix}\mathrm{ReLU}'(z^{(1)}_1)\\ \mathrm{ReLU}'(z^{(1)}_2)\end{bmatrix} = \big(W^{(2)\top}\delta^{(2)}\big)\odot \mathrm{ReLU}'(z^{(1)})\]

정리: δ(현재 층) = [다음 층 δ를 연결 가중치로 거꾸로 모은 값] × ReLU′(현재 층 z). 이 한 줄을 출력 쪽부터 반복하는 것이 역전파입니다.

x = torch.tensor([1.0, 0.5, -1.0]); y = torch.tensor(1.0); lr = 0.1
W1 = torch.tensor([[0.5, 0.2, -0.3], [-0.2, 0.4, -0.1]], requires_grad=True)
b1 = torch.tensor([0.1, 0.1], requires_grad=True)
W2 = torch.tensor([[0.3, -0.2], [0.4, 0.1]], requires_grad=True)
b2 = torch.tensor([0.05, -0.05], requires_grad=True)
w3 = torch.tensor([0.5, 0.4], requires_grad=True)
b3 = torch.tensor(0.1, requires_grad=True)
params = [W1, b1, W2, b2, w3, b3]

for epoch in range(1, 4):
    a1 = torch.relu(W1 @ x + b1)
    a2 = torch.relu(W2 @ a1 + b2)
    y_hat = w3 @ a2 + b3
    loss = 0.5 * (y - y_hat) ** 2
    loss.backward()
    print(f"epoch {epoch}: y_hat={y_hat.item():.6f}, L={loss.item():.6f}")
    print("  dL/dW1 =", W1.grad.tolist())
    with torch.no_grad():
        for p in params:
            p -= lr * p.grad
            p.grad.zero_()

같은 초기값·학습률(η=0.1)로 학습을 20 에포크까지 이어간 결과입니다. 주황 점은 위에서 손으로 푼 에포크 1~3입니다. 20 에포크 동안 ReLU 뉴런은 모두 활성 상태로 유지되었습니다.
